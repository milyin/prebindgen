Compiles the JNI bindings build.rs emits for myflat, and does nothing else — see build.rs for why (#269).

There is no test here on purpose. Success is cargo build: if the generated file does not type-check against myflat’s definitions, this crate fails to compile, and CI’s cargo build at the workspace root is already the gate.
