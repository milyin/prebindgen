Module leaf 

Source
Expand description

The leaves a decomposed value crosses as, and the walk over them.

A leaf is one value that crosses once a returned struct has been taken apart as far as it goes. Here are the leaf model — where a leaf is reached from, which arms it is live inside, what it converts through — and the walk grouping a leaf list into the arms an emitter renders as a match. Which delivery those leaves take, a returned value against a foreign callback, is deliberately not here: that follows from what the target language can receive, so it is the adapter’s (#680 review).

Identity of the deconstructor declaration a plan’s records came from. A run-signature artifact (e.g. a generated callback interface) is fully determined by the declaration, so adapters key such artifacts on this — functions selecting the same declaration share one artifact; differently declared decompositions of the same type get distinct ones.
