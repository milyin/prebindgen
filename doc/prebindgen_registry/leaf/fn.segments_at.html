pub fn segments_at<L: DecomposedLeaf>(
    leaves: &[L],
    depth: usize,
) -> Vec<Range<usize>>
Expand description

segments one nesting level down: the selectors whose arm path is exactly depth long, with the leaves nested under each.

depth is how many arms the caller has already entered, so a leaf deeper than that belongs to the segment it follows rather than opening one.
