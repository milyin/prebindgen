Return a clone of the first stored payload, or None if the storage is empty (by value; crosses by reinterpret, the label becoming a fresh owned string_t * the C caller must drop). Across the C ABI an Option<Payload> lowers to bool storage_get(const storage_t *, payload_t *out) (true + writes *out if present); in Kotlin it surfaces as a nullable Payload?.
