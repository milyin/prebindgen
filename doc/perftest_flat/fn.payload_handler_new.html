pub fn payload_handler_new(
    f: impl Fn(&Payload) + Send + Sync + 'static,
) -> PayloadHandler
Expand description

Prepare a reusable PayloadHandler from a callback f. The (foreign) closure is decoded into the handler once here — reuse the handler across many storage_callback calls instead of passing a fresh callback each time. This is the “declare the subscriber once” step (its trampoline + per-call setup are built here, amortized over every later delivery).
