pub fn storage_get_vec(s: &Storage) -> Option<Vec<Payload>>
Expand description

Return a clone of the whole stored batch, or None if the storage is empty (each label becoming a fresh owned string_t * the C caller must drop). A returned Some is always non-empty (empty storage is None). storage_get is the first-element case of this. Across the C ABI Option<Vec<Payload>> lowers to bool storage_get_vec(const storage_t *, payload_t **out, size_t *out_len); in Kotlin it surfaces as a nullable List<Payload>?.
