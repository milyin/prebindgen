Boxed error type, mirroring zenoh-flat’s Error. It is the E of every fallible Result and never crosses the FFI boundary as a value; the adapter marshals it to C as a char* message obtained from error_get_message.

Marked, because that is how a type whose contents do not cross gets a name in the flat API: the alias declares Error as an opaque handle, which is what lets every Result<_, Error> below resolve.
