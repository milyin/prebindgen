## Input

The immutable Generation retains the wrapper body, primitive descriptions, source views, public declarations and helpers.

## Owner

The common Rust writer emits the wrapper; cbindgen or the Kotlin writer supplies the corresponding foreign declaration.

## Result

The language pages contain the concrete native wrapper and foreign callable. Local names are writer allocations. The source call, conversion order, branching and terminal action are registry instructions. Runtime/member expressions are implementations of adapter-selected primitives.

## Checks

For `(12, 34)`, the successful binding returns 46. Integer overflow follows the source's wrapping addition. JNI input failure must not call the source. These are observable requirements; formatting changes are permitted. The example snippets are expected output, not generated by the current scaffold.
