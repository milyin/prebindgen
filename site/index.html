prebindgen

Generate idiomatic multi-language FFI bindings (C, Kotlin/JNI, …) from a single annotated Rust source.

  • prebindgen Separate FFI implementation and language-specific binding into different crates
  • prebindgen-proc-macro Procedural macros for prebindgen - export FFI definitions for binding generation
  • prebindgen-flat Source model, conversion contracts, representation schemas and call assembly
  • prebindgen-conversions Reusable value and boxed-allocation conversions and their wire metadata
  • prebindgen-declarations Declaration language, defaults, overrides and composition into conversion slots
  • prebindgen-registry Build-script declaration types and macros, re-exported from prebindgen-declarations
  • prebindgen-c Generate Rust wrappers and C declarations from conversion slots
  • prebindgen-jni Generate Rust/JNI wrappers and Kotlin bindings from conversion slots
  • prebindgen-runtime Panic containment and pointer validation for generated bindings
  • prebindgen-jni-runtime String, byte, integer and allocation operations used by generated JNI bindings
