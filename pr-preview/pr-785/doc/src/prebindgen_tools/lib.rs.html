4//! # prebindgen-tools
5//!
6//! Building blocks for a prebindgen **language adapter**. Applications that
7//! only want bindings normally use the `prebindgen-c` or `prebindgen-jni`
8//! adapter crate instead.
9//!
10//! An adapter reads what `#[prebindgen]` captured as [`Flat`](prebindgen_flat::Flat), the
11//! source model from `prebindgen-flat`, a dependency of the adapter's own. It turns
12//! its build script's declarations into a plan of the elements to bind, then writes each
13//! element: the Rust wrapper through a generator here, and whatever the
14//! destination language needs beside it (Kotlin text, for the JNI adapter)
15//! itself. The generators hold no shared plan: each writes one element from
16//! what it is given. [`RustFile`] only collects the resulting Rust items.
17//! The adapter decides which source items to bind, their names, wire types,
18//! and error policy.
19//!
20//! ## Follow one element
21//!
22//! 1. Read the captured model as [`Flat`](prebindgen_flat::Flat). Reject unsupported source
23//!    items with [`check_supported`]. Use [`Qualifier`] when generated Rust
24//!    refers back to a source item.
25//! 2. For each declared item, choose a generator below. Its callback trait
26//!    asks the adapter how values cross the boundary. [`shape()`] and
27//!    [`Shape`] help a callback walk a type one layer at a time.
28//! 3. Describe incoming values with [`Input`] and outgoing values with
29//!    [`Output`]. Each contains its [`Wire`] slots and conversion expression.
30//!    [`Stage`] can wrap either direction in a declared conversion.
31//! 4. Push the generated Rust items into [`RustFile`], then
32//!    [`RustFile::write`] them. The adapter writes any destination-language
33//!    files itself.
34//!
35//! ## Generators
36//!
37//! One generator per kind of Rust item. Each takes the flat element it
38//! wraps and header customizations through a builder, and asks for the
39//! boundary of each value through a small callback trait:
40//!
41//! | Generator | Writes | Callbacks |
42//! |---|---|---|
43//! | [`FunctionWriter`] | an exported wrapper around a [`Function`](prebindgen_flat::flat::Function) | [`FunctionCallbacks`]: the result's return type, out-wires and body; each parameter's wires and wire→value [`Input`]; the failure fragment |
44//! | [`StructWriter`] | a mirror struct of a [`Struct`](prebindgen_flat::flat::Struct), with both conversions | [`FieldCallbacks`]: each field's wires, both directions |
45//! | [`SumWriter`] | a mirror enum of a [`Variant`](prebindgen_flat::flat::Variant), with both conversions | [`FieldCallbacks`] |
46//! | [`ClosureWriter`] | an `impl Fn(..)` closure over a foreign callback | [`ClosureCallbacks`]: each argument's wires ([`Output`]) |
47//!
48//! The generators expect **final** wire types: how a `Vec<Payload>` becomes
49//! a pointer and a length, or a count and a column per field, is the
50//! adapter's answer in its callback. Start at a generator's module page for
51//! the shape it writes and a worked example: [`function`], [`record`],
52//! [`closure`].
53//!
54//! ## Recursion
55//!
56//! A callback answers for a whole type by recursing over its structure.
57//! [`shape()`] reads one layer — an `Option`, a borrow, a sequence, a named
58//! type with the adapter's own setting for it — so every adapter's recursion
59//! is one `match` over [`Shape`]. The answers compose: [`Input`] and
60//! [`Output`] carry an expression plus the wires it reads or produces;
61//! [`record_in`] / [`record_out`] take a struct or a sum alternative apart
62//! into its fields; [`Input::optional`], [`Input::combine`] and
63//! [`Output::concat`] build the rest; [`Stage::decode`] / [`Stage::encode`]
64//! wrap a representation in a declared conversion. A conversion that can
65//! fail uses `?` on `Result<_, String>`, and whoever places it decides where
66//! the error goes.
67//!
68//! ## Everything else
69//!
70//! * [`Qualifier`] — names a flat item from generated code
71//!   (`Payload` → `perftest_flat::Payload`).
72//! * [`names`] — case conversion and identifier helpers.
73//! * [`mod@convert`] — the `convert!` vocabulary: a source type that crosses as
74//!   another type through functions or `From`/`TryFrom` impls.
75//! * [`RustFile`] — the generated file: items in order, formatted, written
76//!   only when changed.
77//!
78//! ## Small complete example
79//!
80//! This toy adapter keeps scalar parameters unchanged. Real C and JNI
81//! adapters provide different [`FunctionCallbacks`] and handle more
82//! [`Shape`] variants. The example uses an in-memory model so the path from
83//! a flat function to generated Rust is visible without a build script.
84//!
85//! ```
86//! use prebindgen::SourceLocation;
87//! use prebindgen_flat::{flat::TypeRef, Flat};
88//! use prebindgen_tools::{FunctionCallbacks, FunctionWriter,
89//!     Input, Qualifier, Return, RustFile, Wire, check_supported};
90//! use proc_macro2::TokenStream;
91//! use quote::quote;
92//!
93//! let source = syn::parse_file("pub fn double(n: i64) -> i64 { n * 2 }").unwrap();
94//! let location = SourceLocation {
95//!     crate_name: Some("source_crate".into()),
96//!     ..Default::default()
97//! };
98//! let flat = Flat::builder()
99//!     .items(source.items.into_iter().map(|item| (item, location.clone())))
100//!     .build().unwrap();
101//! check_supported(&flat).unwrap();
102//!
103//! struct Scalar;
104//! impl FunctionCallbacks for Scalar {
105//!     type Error = String;
106//!     fn param(&mut self, name: &syn::Ident, ty: &TypeRef) -> Result<Input, String> {
107//!         Ok(Input::identity(Wire::new(name.clone(), ty.spell())))
108//!     }
109//!     fn ret(&mut self, ret: &TypeRef) -> Result<Return, String> {
110//!         Ok(Return { ty: Some(ret.spell()), wires: vec![], body: quote!(__result) })
111//!     }
112//!     fn fail(&mut self, _: &Return) -> TokenStream {
113//!         quote!(panic!("{__err}"))
114//!     }
115//! }
116//!
117//! let function = flat.function("double").unwrap();
118//! let qualifier = Qualifier::new(&flat);
119//! let wrapper = FunctionWriter::new(function, qualifier.path(&function.name))
120//!     .abi(None).unsafety(false)
121//!     .write(&mut Scalar).unwrap();
122//! let mut file = RustFile::new();
123//! file.push(wrapper);
124//! let generated = file.render();
125//! assert!(generated.contains("fn double(n: i64) -> i64"));
126//! assert!(generated.contains("source_crate::double(n)"));
127//! ```

138/// The closure writer: a Rust `impl Fn(..)` built over a foreign callback.
139///
140/// A source function taking `impl Fn(A, B) + Send + Sync + 'static` needs a
141/// Rust closure that, on every call, turns `A` and `B` into wires and hands
142/// them to the foreign side. The shape is fixed; the adapter supplies the
143/// pieces:
144///
145/// ```text
146/// {
147///     <setup>                                  // once, when the closure is built
148///     move |__a0: A, __a1: B| {
149///         let __res = (|| -> Result<(), String> {
150///             <invoke>                         // binds each argument's wires, calls the foreign side
151///             Ok(())
152///         })();
153///         if let Err(__err) = __res { <on_error> }
154///     }
155/// }
156/// ```
157///
158/// `invoke` receives the arguments' bindings rather than having them placed
159/// ahead of it, so an adapter can run them inside a scope of its own — a
160/// JNI frame whose environment the conversions use.
161///
162/// For instance, a callback taking `i64` can use
163/// [`Output::single`](crate::Output::single) to pass one integer wire. The
164/// adapter's `invoke` closure then emits the foreign call using that wire;
165/// the writer supplies the Rust `move` closure, per-call error scope, and
166/// [`ClosureWriter::on_error`] path.
167///
168/// ```
169/// use prebindgen::SourceLocation;
170/// use prebindgen_flat::{Flat, flat::{TypeKind, TypeRef}};
171/// use prebindgen_tools::{ClosureCallbacks, ClosureWriter, Output, Qualifier, Wire};
172/// use proc_macro2::TokenStream;
173/// use quote::{format_ident, quote};
174///
175/// let source = syn::parse_file(
176///     "pub fn register(callback: impl Fn(i64) + Send + Sync + 'static) {}"
177/// ).unwrap();
178/// let flat = Flat::builder()
179///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
180///     .build().unwrap();
181/// let ty = &flat.function("register").unwrap().params[0].ty;
182/// let TypeKind::Callback { args } = ty.kind() else { panic!("expected callback") };
183///
184/// struct Scalar;
185/// impl ClosureCallbacks for Scalar {
186///     type Error = String;
187///     fn arg(&mut self, index: usize, _: &TypeRef, value: &TokenStream)
188///         -> Result<Output, String> {
189///         Ok(Output::single(Wire::new(format_ident!("w{index}"), quote!(i64)), value))
190///     }
191/// }
192/// let closure = ClosureWriter::new(args)
193///     .on_error(quote!(panic!("{__err}")))
194///     .write(&Qualifier::new(&flat), &mut Scalar, |bindings, outputs| {
195///         let wire = &outputs[0].wires[0].name;
196///         quote!(#bindings foreign_callback(#wire);)
197///     }).unwrap();
198/// assert!(closure.to_string().contains("foreign_callback (w0)"));
199/// ```
200pub mod closure {
201    pub use crate::api::closure::{ClosureCallbacks, ClosureWriter};
202}

204/// Custom conversions: a source type that crosses as another type.
205///
206/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
207/// says that `Millis` never crosses as itself: it crosses as `u64` — the
208/// **representation** — and these two functions convert. The adapter lowers
209/// the representation like any other type and wraps the resulting wires in
210/// the conversion's stages ([`Stage::apply`]).
211///
212/// A stage is a function (a flat item, or a binding-local path with a
213/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
214/// `TryInto`). A function returning `Result` makes its stage fallible; the
215/// error is reported through its `Display`.
216///
217/// For example, given source functions `millis_from_raw(u64) -> Millis` and
218/// `millis_to_raw(&Millis) -> Result<u64, String>`, an adapter can resolve
219/// both directions before lowering a use of `Millis`:
220///
221/// ```
222/// use prebindgen::SourceLocation;
223/// use prebindgen_flat::Flat;
224/// use prebindgen_tools::{convert, fun, Input, Output, Qualifier, Wire, ident};
225/// use quote::quote;
226/// let source = syn::parse_file(r#"
227///     pub struct Millis(pub u64);
228///     pub fn millis_from_raw(raw: u64) -> Millis { Millis(raw) }
229///     pub fn millis_to_raw(value: &Millis) -> Result<u64, String> { Ok(value.0) }
230/// "#).unwrap();
231/// let flat = Flat::builder()
232///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
233///     .build().unwrap();
234/// let conversion = convert!(Millis)
235///     .input(fun!(millis_from_raw))
236///     .output(fun!(millis_to_raw))
237///     .resolve(&flat).unwrap();
238/// let input = conversion.input.as_ref().unwrap();
239/// let output = conversion.output.as_ref().unwrap();
240/// // Each stage's `repr` is u64; `output.fallible` is true.
241/// assert_eq!(input.repr.spell().to_string(), "u64");
242/// assert!(output.fallible);
243/// let q = Qualifier::new(&flat);
244/// let decoded = input.decode(&q, &conversion.target,
245///     Input::identity(Wire::new(ident!(raw), quote!(u64))),
246///     &ident!(r), quote!());
247/// assert_eq!(decoded.wires.len(), 1);
248/// let encoded = output.encode(&q, &conversion.target, &quote!(value),
249///     &ident!(r), quote!(),
250///     Output::single(Wire::new(ident!(raw), quote!(u64)), quote!(r)));
251/// assert!(encoded.fallible);
252/// ```
253///
254/// An [`Input`] for `u64` is wrapped with [`Stage::decode`]
255/// before the source call; an [`Output`] for `u64` is wrapped
256/// with [`Stage::encode`] after it. A binding-local function can be named
257/// with [`fun!`](crate::fun!) plus [`FnRef::sig`]. See [`Via`] for trait-based alternatives.
258pub mod convert {
259    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Stage, Via};
260}

283/// The function wrapper writer.
284///
285/// A wrapper is one exported function that receives wires, converts them to
286/// the source function's arguments, calls it, and hands the result back as
287/// wires:
288///
289/// ```text
290/// <attrs>
291/// pub unsafe extern "C" fn <name><generics>(<leading>, <param wires>, <return wires>, <trailing>) -> <return type> {
292///     <prologue>
293///     let <param> = <param input>;          // on failure: <fail>
294///     ...
295///     let __result = <callee>(<params>);
296///     <return body>
297/// }
298/// ```
299///
300/// The writer owns the shape; the adapter owns every decision, through
301/// [`FunctionCallbacks`]: which wires a parameter becomes and how they turn
302/// back into the argument, which wires the result leaves on, and what the
303/// wrapper does when a conversion fails. The builder methods customize the
304/// header and the fixed parts of the body.
305///
306/// The [crate example](crate#small-complete-example) builds one wrapper from
307/// an in-memory [`Flat`](prebindgen_flat::Flat). In an adapter, the
308/// callback's [`FunctionCallbacks::param`] can call
309/// [`shape()`](crate::shape()), convert its result into an [`Input`], and let
310/// [`FunctionWriter::write`] place the wires and conversion at the call site.
311pub mod function {
312    pub use crate::api::function::{
313        error_ident, result_ident, FunctionCallbacks, FunctionWriter, Return, ERROR, RESULT,
314    };
315}

322/// Naming source items from generated Rust code.
323///
324/// The flat model identifies a source item by its flat name, such as
325/// `Payload` or `make`. A binding's generated Rust usually lives in a
326/// different crate, where those names are not automatically in scope.
327/// [`Qualifier`] uses each item's source location to spell a path such as
328/// `source_crate::Payload` or `source_crate::make`. Use it when a wrapper
329/// calls a source function or a conversion names a source type.
330///
331/// ## Choosing a path
332///
333/// [`Qualifier::new`] borrows the model. For each known item,
334/// [`Qualifier::module_of`] reads the crate name recorded in its
335/// [`SourceLocation`](prebindgen::SourceLocation), converting hyphens to
336/// underscores for a Rust path. Items captured from different crates can
337/// therefore receive different prefixes from the same qualifier.
338///
339/// [`Qualifier::with_default_module`] supplies a fallback for **known items
340/// without a recorded crate name**, for example a model assembled directly
341/// from parsed syntax in a test. A recorded crate name takes precedence.
342/// A name absent from the model is left unchanged even when a fallback is
343/// configured; a known item with neither a crate name nor a fallback also
344/// keeps its bare name. The generated crate must be able to resolve the
345/// emitted paths: qualification does not add dependencies or imports, or
346/// discover Cargo dependency aliases.
347///
348/// ## Item paths and type expressions
349///
350/// * [`Qualifier::path`] qualifies one item name, such as the function a
351///   [`FunctionWriter`] will call.
352/// * [`Qualifier::ty`] walks a complete model type. For example,
353///   `Option<Vec<Payload>>` becomes
354///   `::core::option::Option<::std::vec::Vec<source_crate::Payload>>`.
355///   It qualifies named types inside generic arguments and containers, and
356///   named constants used as array lengths. Standard containers receive
357///   absolute `::core` or `::std` paths; scalar names such as `u32` stay as is.
358/// * [`Qualifier::ty_elided`] provides the same naming for positions such as
359///   closure arguments that cannot refer to a source lifetime parameter.
360///   Its method documentation lists which shapes it elides.
361///
362/// These methods return Rust tokens for the source value's type or path.
363/// The adapter still chooses the wire representation: qualifying
364/// `Payload` does not turn it into a pointer, handle, or mirror struct.
365///
366/// ```
367/// use prebindgen::SourceLocation;
368/// use prebindgen_flat::Flat;
369/// use prebindgen_tools::Qualifier;
370/// use quote::quote;
371///
372/// let source = syn::parse_file(
373///     "pub struct Payload; pub fn make() -> Option<Vec<Payload>> { None }",
374/// ).unwrap();
375/// let location = SourceLocation {
376///     crate_name: Some("source-crate".into()), ..Default::default()
377/// };
378/// let flat = Flat::builder()
379///     .items(source.items.into_iter().map(|item| (item, location.clone())))
380///     .build().unwrap();
381/// let q = Qualifier::new(&flat);
382/// let function = flat.function("make").unwrap();
383/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
384/// let expected: syn::Type = syn::parse_quote!(
385///     ::core::option::Option<::std::vec::Vec<source_crate::Payload>>
386/// );
387/// assert_eq!(syn::parse2::<syn::Type>(q.ty(&function.ret)).unwrap(), expected);
388///
389/// // The fallback does not override the recorded source crate.
390/// let q = q.with_default_module(Some(syn::parse_quote!(crate::source)));
391/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
392/// // A binding-local helper absent from the model stays unqualified.
393/// assert_eq!(q.path(&syn::parse_quote!(local_helper)).to_string(), "local_helper");
394/// ```
395pub mod qualify {
396    pub use crate::api::qualify::Qualifier;
397}

399/// Records — structs and the alternatives of a sum — taken apart into their
400/// fields and put back together.
401///
402/// Two uses, one mechanism:
403///
404/// * **Decomposition** ([`record_in`], [`record_out`]): the record crosses as
405///   the concatenation of its fields' wires, with no type of its own on the
406///   boundary. Recursing into a field that is itself a record gives the
407///   leaf-by-leaf crossing a JVM binding uses.
408/// * **Mirrors** ([`StructWriter`], [`SumWriter`]): the record crosses as a
409///   generated type whose fields are the wires — a `#[repr(C)]` struct or
410///   enum for C — plus the two conversions between it and the source type.
411///
412/// Either way the adapter decides, per field, through [`FieldCallbacks`];
413/// the helpers here only handle the Rust shape of the record: named or
414/// positional fields, the delimiters the source wrote, the order.
415///
416/// ## Example: decompose a record
417///
418/// [`record_in`] combines field inputs in source order and reconstructs the
419/// source's named or tuple form. A callback would normally produce the field
420/// inputs while recursing through [`shape()`](crate::shape()).
421///
422/// ```
423/// use prebindgen::SourceLocation;
424/// use prebindgen_flat::{Flat, flat::{Field, Type}};
425/// use prebindgen_tools::{FieldCallbacks, Input, Output, Record, StructWriter, Wire,
426///     ident, record_in};
427/// use proc_macro2::TokenStream;
428/// use quote::quote;
429///
430/// let item = syn::parse_quote!(pub struct Point { pub x: i32, pub y: i32 });
431/// let flat = Flat::builder()
432///     .items([(item, SourceLocation::default())])
433///     .build().unwrap();
434/// let Some(Type::Struct(point)) = flat.declared_type("Point") else { panic!() };
435/// let fields = vec![
436///     Input::identity(Wire::new(ident!(x_wire), quote!(i32))),
437///     Input::identity(Wire::new(ident!(y_wire), quote!(i32))),
438/// ];
439/// let input = record_in(Record::Struct(point), &quote!(Point), fields);
440/// assert_eq!(input.wires.len(), 2);
441/// assert_eq!(input.expr.to_string(), "Point { x : x_wire , y : y_wire }");
442///
443/// // A mirror uses the same field decisions to define a boundary struct
444/// // and the two conversions. Each conversion expression reads a local `v`.
445/// struct Scalar;
446/// impl FieldCallbacks for Scalar {
447///     type Error = String;
448///     fn field_in(&mut self, field: &Field) -> Result<Input, String> {
449///         Ok(Input::identity(Wire::new(field.name.clone().unwrap(), quote!(i32))))
450///     }
451///     fn field_out(&mut self, field: &Field, value: &TokenStream)
452///         -> Result<Output, String> {
453///         Ok(Output::single(
454///             Wire::new(field.name.clone().unwrap(), quote!(i32)), value
455///         ))
456///     }
457/// }
458/// let mirror = StructWriter::new(point, quote!(Point), ident!(PointWire))
459///     .attr(quote!(#[repr(C)]))
460///     .write(&mut Scalar).unwrap();
461/// assert_eq!(mirror.wires.len(), 2);
462/// assert!(mirror.def.to_string().contains("struct PointWire"));
463/// assert!(mirror.input.expr.to_string().contains("let PointWire"));
464/// ```
465pub mod record {
466    pub use crate::api::record::{
467        record_in, record_out, FieldCallbacks, Record, StructMirror, StructWriter, SumMirror,
468        SumWriter,
469    };
470}

472/// One level of a type's structure, read against the adapter's own settings.
473///
474/// An adapter lowers a type by recursion: it looks at the outermost layer,
475/// decides what that layer becomes on its boundary, and recurses into what
476/// the layer holds. [`shape()`] answers the first question the same way for
477/// every adapter — which layer this is, and, for a named type, the setting
478/// the adapter gave that type — so each adapter's recursion is one `match`
479/// over [`Shape`].
480///
481/// For example, if the adapter has declared a binding for `Payload`, then
482/// `shape(&payload_type, |name| settings.get(name))` returns
483/// [`Shape::Declared`] with that setting. For `Option<Payload>`, it returns
484/// [`Shape::Option`] with the inner type; the adapter calls [`shape()`] again
485/// for that inner type. This keeps the adapter's policy in one recursive
486/// match rather than in the flat model.
487///
488/// A shape describes source structure; the adapter uses it to build an
489/// [`Input`] or [`Output`] for its chosen wire representation. A named type
490/// can use an adapter-specific setting (for example, an opaque handle
491/// declaration), while containers expose child types for further calls.
492/// [`Access`] describes ownership or borrowing of a value; [`Holding`]
493/// distinguishes owned sequences, slices, borrowed vectors, and `Cow`.
494///
495/// [`shape()`] documents when it checks adapter declarations, the special
496/// handling of `String` and common borrows, and which unsupported forms
497/// return errors.
498/// A successful call only classifies the current layer: an adapter must
499/// still handle undeclared names and errors encountered in its children.
500///
501/// ```
502/// use prebindgen::SourceLocation;
503/// use prebindgen_flat::Flat;
504/// use prebindgen_tools::{shape, Access, Shape};
505/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
506/// let flat = Flat::builder()
507///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
508///     .build().unwrap();
509/// let ty = &flat.function("send").unwrap().params[0].ty;
510/// // The Option layer exposes its child without consulting adapter declarations.
511/// let Shape::Option(inner) = shape::<&str>(ty, |_| panic!("no declaration check at this layer"))
512///     .unwrap() else { panic!("expected Option") };
513/// // The child is &Payload: its declaration and borrow are reported together.
514/// assert!(matches!(
515///     shape(inner, |name| (name == "Payload").then_some("handle")).unwrap(),
516///     Shape::Declared { setting: "handle", access: Access::Shared, .. }
517/// ));
518/// // Missing adapter configuration is a shape the adapter must handle.
519/// assert!(matches!(
520///     shape::<()>(inner, |_| None).unwrap(),
521///     Shape::Undeclared("Payload")
522/// ));
523/// ```
524pub mod shape {
525    pub use crate::api::shape::{shape, Access, Holding, Shape};
526}

528/// Wires and the conversions between wires and source values.
529///
530/// A **wire** is one parameter, field or return slot of the generated
531/// boundary, typed in the generated Rust file: `jlong`, `*const c_char`,
532/// `payload_t`. A source value crosses as zero or more wires, and which
533/// ones is the adapter's decision; these types only carry the decision and
534/// compose it.
535///
536/// * [`Input`] turns wires into a source value — a parameter on its way into
537///   the source function, a field of a struct arriving from the foreign side.
538/// * [`Output`] turns a source value into wires — a return value, a callback
539///   argument, a field of a struct leaving.
540///
541/// Both carry an expression. A **fallible** one may use `?` on a
542/// `Result<_, String>`; whoever places it decides where the error goes (see
543/// [`Input::result`]). Generated conversion helpers follow the same
544/// convention, so a converter written for one position composes into another.
545///
546/// ## Example: one value on two wires
547///
548/// A `u64` can arrive as two `u32` words. [`Input`] keeps the expression together with
549/// the two [`Wire`] declarations so [`FunctionWriter`]
550/// can place and evaluate them in the right order:
551///
552/// ```
553/// use prebindgen_tools::{Input, Output, Wire, ident};
554/// use quote::quote;
555///
556/// let hi = Wire::new(ident!(hi), quote!(u32));
557/// let lo = Wire::new(ident!(lo), quote!(u32));
558/// let input = Input::new(vec![hi, lo], quote!(((hi as u64) << 32) | lo as u64));
559/// assert_eq!(input.wires.len(), 2);
560/// assert!(input.result().to_string().contains("Ok"));
561///
562/// let output = Output::new(
563///     vec![Wire::new(ident!(hi), quote!(u32)),
564///          Wire::new(ident!(lo), quote!(u32))],
565///     quote!(((value >> 32) as u32, value as u32)),
566/// );
567/// assert_eq!(output.pattern().to_string(), "(hi , lo)");
568/// ```
569///
570/// For a fallible step, use [`Input::and_then`] or [`Output::fallible`]
571/// and place [`Input::result`] or [`Output::result`] at the point whose
572/// error policy applies. The writer only understands `Result<_, String>`;
573/// the adapter supplies the actual fallback in
574/// [`FunctionCallbacks::fail`].
575pub mod wire {
576    pub use crate::api::wire::{result_expr, Input, Output, Wire};
577}
