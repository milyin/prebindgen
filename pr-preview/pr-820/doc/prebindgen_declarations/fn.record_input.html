Expand description

Construct a named Rust record from field conversion plans in declaration order. Group hooks describe the collection and each named field in adapter metadata, preserving empty fields and fields represented by multiple physical wires.

Adapters can use this when a single language-level leaf represents a record. The caller supplies every field exactly once, with the correct source type, and chooses a fresh var identifier. Child plans must use the same context and activation condition and must not have been finalized with finish_input. Validation, acquisition, resources, acknowledgements and construction remain in their respective phases. Field paths are prepended through the codec. Finalize only the complete occurrence with Codec::finish_input.
