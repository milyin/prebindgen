Expand description

Observe a named Rust record through shared field references, evaluating it once. Group hooks preserve field boundaries as in record_input.

The caller validates the field count and types against the source record. fields supplies source field names in declaration order. convert receives each field’s index and a shared-reference expression; it must convert that borrowed field without consuming it. Choose a fresh var identifier and use the same context for all children. Field paths are prepended through the codec. Child delivery must remain unset; finalize only the complete occurrence with Codec::finish_output. Commit phases are preserved until successful delivery.
