Expand description

A source callable to export, with optional destination name and occurrence overrides.

Result expansion override, replacing the type default.

Source

pub fn callback_return(self) -> Self

Add callback delivery alongside the ordinary sequence return.

C emits <function>_each, whose visitor receives each element’s converted fields. Kotlin emits <function>Fold(initial, ..., fold), whose folder receives an accumulator and each element’s converted Kotlin values. Supports one projected sequence, optionally inside Option and an outer Result. Existing buffer/list returns are preserved. Adapter builders validate the return shape and generated-name collisions.

Source

pub fn callback_return_only(self) -> Self

Expose only callback delivery, without generating an ordinary return.

This explicitly permits decomposed multi-value Kotlin elements without requiring a Kotlin data class. Generated names are the same as for callback_return: C _each and Kotlin Fold.

Source

pub fn on_error(self, mapper: FunctionDecl) -> Self

Map the error of a top-level Result<T, E> return with a source function.

The helper must take exactly E or &E and return String. Only its source name is accepted; it is selected for capture but is not exported. The success value uses normal return defaults and expand_return overrides. Replaces any previously selected mapper. Non-Result returns reject this option.

Source

pub fn name(self, name: impl Into<String>) -> Self

Set a literal destination name, subject to adapter validation.

The JNI adapter uses it instead of its default camel-case name.

Source

pub fn expand_param(self, name: impl AsRef<str>, decl: ExpandParamDecl) -> Self

Replace the expansion for one source parameter.

§Arguments
  • name — the parameter’s name, as written in the source.
  • decl — how to build that argument instead of its type’s default.
§Panics

Panics if that parameter already has an override. Resolution checks that the parameter exists and the expansion type matches.

pub fn expand_return(self, decl: ExpandReturnDecl) -> Self

Replace the result expansion, including any previously assigned override.
