Source
Expand description

Source types, occurrence slots, and generator-defined conversion interfaces. Preparation fills slots; language generators interpret their request protocols. Named objects must have nonzero Rust size, including opaque aliases. Their layout is checked by the emitted compile-time guards, independently of the slot data types. Unit remains available for absence of a value.
