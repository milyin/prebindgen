Struct WireLayout 

Source 
pub struct WireLayout<W: WireKind, G = ()> { /* private fields */ }
Expand description

Authoritative wire order and structure for one conversion slot.

Wires are visited depth first, left to right. Inline containers expose their control wires then their element wires. Carried containers expose only the carrier; their element layouts have independent positions. This order also defines ConversionExt::wires() and position-based code requests, including inactive alternatives. Empty groups and inline elements are allowed.

Build/edit the tree before emission; positions must not survive structural edits. Emission borrows it immutably so every request sees the same order.
