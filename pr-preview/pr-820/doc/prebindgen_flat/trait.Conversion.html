Expand description

Prepared slot conversion with a generator-defined request protocol.

Input and output slots share this emission interface. Their payload types may define different wire kinds and request enums. InputConversion adds an input value description; OutputConversion adds output completion channels. An output request can carry the source-result identifier without imposing a shared context type.

Every successful request returns one Rust expression, including () for a no-op. Statements may appear inside a block expression. The caller decides how expressions are combined and binds any values needed by later requests. expected_type is the caller’s expectation, not a type-checking guarantee: the implementation may use it to configure emission or reject a request. Rust compilation performs the final type check. No implicit casts are required.

Request enums belong to the generator. Each variant can carry only the names, settings or other data it needs; no common context or phase order is imposed. Their lifetime parameter allows requests to borrow that data.

The tree describes logical values. Generators choose transport, runtime repetition and branch selection. A leaf traversal index is not an ABI parameter position. Requests needing an element/branch context carry it in the generator-defined request enum; no per-wire ABI protocol is mandatory.

A reusable owned-box converter can define its own small request vocabulary. The pointee is preparation data, not a hardcoded application type. The slot request borrows an error message only for validation; acquisition needs no context. The caller supplies expected_type to every request and binds the resulting value itself. This example chooses syntactic type matching as its policy; other implementations may use the expectation to configure emission.

use prebindgen_flat::{bind_fragment, same_type, Conversion, InputConversion, Result, Wire, WireKind, WireNode, wire_definitions};
use proc_macro2::TokenStream;
use quote::quote;
use syn::{parse_quote, Type};

enum Carrier { OpaquePointer }
impl WireKind for Carrier {
    fn rust_type(&self) -> Type { parse_quote!(*mut ::std::ffi::c_void) }
}
enum SlotRequest<'a> {
    Validate { null_message: &'a str },
    TakeOwnership,
}
struct OwnedBoxInput {
    pointee: Type,
    node: WireNode<Carrier>,
}
fn expect(actual: &Type, expected: &Type) -> Result<()> {
    if same_type(actual, expected) { Ok(()) }
    else { Err("unsupported expected type".into()) }
}
impl Conversion for OwnedBoxInput {
    type Wire = Carrier;
    type Optional = ();
    type Sequence = ();
    type Group = ();
    type Alternatives = ();
    type SlotFragment<'a> = SlotRequest<'a>;
    fn code_fragment_slot(&self, mode: SlotRequest<'_>, expected: &Type)
        -> Result<TokenStream>
    {
        let name = &wire_definitions(std::iter::once(&self.node)).next().unwrap().name;
        let pointee = &self.pointee;
        match mode {
            SlotRequest::Validate { null_message } => {
                expect(&parse_quote!(()), expected)?;
                Ok(quote!({
                    if #name.is_null() { return Err(#null_message.into()); }
                }))
            }
            SlotRequest::TakeOwnership => {
                expect(&parse_quote!(::std::boxed::Box<#pointee>), expected)?;
                // The caller guarantees a live, uniquely owned allocation
                // created by compatible Box::into_raw. Validation alone cannot.
                Ok(quote!(unsafe {
                    ::std::boxed::Box::<#pointee>::from_raw(#name.cast::<#pointee>())
                }))
            }
        }
    }
}
impl InputConversion for OwnedBoxInput {
    fn input_node(&self) -> &WireNode<Carrier> { &self.node }
}
let slot = OwnedBoxInput {
    pointee: parse_quote!(u64), // Supplied by preparation from the source type.
    node: WireNode::Wire(vec![Wire { name: parse_quote!(raw_value), kind: Carrier::OpaquePointer }]),
};
let validation = slot.code_fragment_slot(
    SlotRequest::Validate { null_message: "null owned handle" }, &parse_quote!(()))?;
let expected = parse_quote!(::std::boxed::Box<u64>);
let value = slot.code_fragment_slot(SlotRequest::TakeOwnership, &expected)?;
let binding = bind_fragment(&parse_quote!(argument), &expected, value)?;
let _: syn::Block = syn::parse2(quote!({ #validation; #binding }))?;
let raw_parameter = wire_definitions(std::iter::once(slot.input_node())).next().unwrap();
assert_eq!(raw_parameter.name, "raw_value");
