Expand description

One self-sufficient JNI value and its conversion information.

Niche availability is mutable state for the current slot. Consuming or suppressing a niche must not restore the variant’s initial availability. Use the variant constructors to initialize it, and Self::set_niche to check updates.

pub fn is_reference(&self) -> bool

Whether the native input is a JNI reference rather than a copyable scalar.

Handles are integers, so this returns false for them. Rust i128/u128 arrive as byte-array references, so this returns true for those scalars.

pub fn read_array_element( &self, array: &TokenStream, index: usize, ) -> TokenStream

Generate an expression reading a checked, boxed field of a Java Object[].

The expression returns Result<rust_type()>, without applying Rust-domain validation or acquiring handles. Boolean inputs are normalized to u8. Reference fields preserve Java null for optional/inactive values. The caller supplies the environment template parameter and owns local refs.

Source

pub fn output_object(&self, value: &TokenStream) -> TokenStream

Generate a Java object expression from a prepared output, boxing primitives.

This accepts the representation in OutputPlan::values, not a native input: text/bytes are optional Rust payloads, i128/u128 are encoded bytes, handles are allocation pointers, and rows are optional JNI arrays. The expression can fail through ?, uses the environment template parameter, and returns a local reference owned by the caller’s frame. It does not commit any ownership transfer.

Source

pub fn output_argument(&self, value: &TokenStream, local: &Ident) -> JniArgument

Generate one JNI method argument from the same prepared output as Self::output_object, leaving JVM primitives unboxed.

local must be a fresh identifier for this argument’s Java object. Emit the returned statements before its value and keep references alive through the invocation. The caller supplies environment, validates the method signature, and commits ownership only after successful delivery. A custom generator can render both fragments with its JniContext:

use prebindgen_conversions::TemplateContext;
use prebindgen_jni::{JniContext, JniWire};
use quote::quote;
let context = JniContext {
    environment: syn::parse_quote!(env),
    acknowledgement: syn::parse_quote!(accepted),
    domain_output: syn::parse_quote!(domain_output),
    is_domain_error: false,
    output_committed: quote!(),
};
let argument = JniWire::text().output_argument(
    &quote!(prepared_text), &syn::parse_quote!(java_text));
let statements = context.render(&argument.statements)?;
let value = context.render(&argument.value)?;
// Emit statements, invoke with value, then release the local frame.
