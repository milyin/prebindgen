Expand description

Compose the opt-in staged protocol as a fallible expression. result_type is the wrapper result type inside Result<_, String>.

Generators choosing this helper use address alias checks and one shared acknowledgement. Other generators can compose their own request protocols. This is deliberately outside Flat: none of these phases are required by its traits.
