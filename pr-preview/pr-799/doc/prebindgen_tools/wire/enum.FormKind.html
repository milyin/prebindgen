Enum FormKind

pub enum FormKind<W> {
    Wire(Wire<W>),
    Via(Box<Form<W>>),
    Parts(Vec<(Seg, Form<W>)>),
    Optional {
        presence: Option<Wire<W>>,
        inner: Box<Form<W>>,
    },
    Sum {
        tag: Wire<W>,
        alts: Vec<Vec<(Seg, Form<W>)>>,
    },
    Seq {
        wires: Vec<Wire<W>>,
        elem: Box<Form<W>>,
    },
}
Expand description

The ways a value can cross. Every one but FormKind::Wire is a composition of other forms.

Variants§

§

Wire(Wire<W>)

The value is one wire.

§

Via(Box<Form<W>>)

The value is converted to another source type, which crosses as this.

§

Parts(Vec<(Seg, Form<W>)>)

The value is taken apart: each part crosses on its own wires, in order. A record’s fields; () has no parts.

§

Optional

Some(inner) or None. Without a presence wire, the inner wires themselves tell absence (a null pointer).

Fields

§presence: Option<Wire<W>>
§inner: Box<Form<W>>
§

Sum

A tag selecting one alternative; every alternative’s fields have wires, those not taken hold placeholders. Indexed by alternative.

Fields

§tag: Wire<W>
§alts: Vec<Vec<(Seg, Form<W>)>>
§

Seq

A sequence on wires; each element relates to them as elem. The element’s own wires are per-element locals, not boundary slots.

Fields

§wires: Vec<Wire<W>>
§elem: Box<Form<W>>
