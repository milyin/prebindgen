prebindgen_registry

Module chain 

Source
Expand description

Shared converter-chain composition for recipe shapes.

Adapters choose an intermediate representation and implement its bridge operations. The registry owns the source-value walk and child-call/error propagation. Source TypeRefs remain opaque until Chain::render is called by the final Rust writer with RustWriter.
