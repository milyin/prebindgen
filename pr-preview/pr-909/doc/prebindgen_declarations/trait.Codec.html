Expand description

Interpret adapter-specific trees into the fixed schema’s parameter/result slots. Adapters select their operation vocabularies and dispatch to concrete helpers. Optional features reject unsupported work or decline a specialization. All operations run during generation; the returned fragments run in the library.

fn output_return_reference( &self, _flat: &Flat<Self::Schema>, _reference: &TypeReference, _extra: &Self::Extra, _wire: Ident, _value: TokenStream, ) -> Result<Option<CodecOutputPlan<Self>>>

Convert a reference supplied directly by the Rust return value.

Unlike observing an owned value through a getter, this reference already has the source function’s lifetime contract. Adapters may expose it as a non-owning foreign pointer. reference preserves the referent and mutability; value produces exactly that Rust reference. This also applies inside optional and successful Result returns and to getter results whose receiver remains alive. Callback arguments supplied as references also use this hook: their loan lasts only for the foreign invocation. The foreign caller must preserve the referenced storage and Rust aliasing rules. No runtime lifetime tracking is implied.

Return None to use ordinary borrowed leaf conversion (the default).

Source

fn output_borrowed_sequence( &self, _flat: &Flat<Self::Schema>, _ty: &Type, _extra: &Self::Extra, _wire: Ident, _value: TokenStream, _element: &ResolvedOutput<Self>, _delivery: SequenceDelivery, _temporary: bool, ) -> Result<Option<CodecOutputPlan<Self>>>

Select an address-preserving representation of a borrowed collection.

Called before element conversion when a sequence is borrowed and neither its own policy nor an enclosing projection explicitly permits copying. value is a reference to the collection; element is its resolved output recipe. An adapter may return a non-owning view or reject an unsupported borrow instead of allocating converted rows. None retains ordinary sequence conversion, which may be required by the foreign representation. temporary means the receiver backing this observation is destroyed after the generated call; a view must not escape that receiver.

fn output_owner( &self, _flat: &Flat<Self::Schema>, _ty: &Type, _extra: &Self::Extra, _wire: Ident, _value: TokenStream, ) -> Result<Option<(CodecOutputPlan<Self>, TokenStream)>>

Place an owned value in its final foreign allocation before getter views.

Returns its owning output conversion and a Rust *mut ty expression from which getter receivers can be borrowed. That address must remain valid across conversion, delivery and ownership commit. Until commit, the plan must reclaim the allocation on failure. The default keeps ordinary output conversion and observation-before-move ordering.
