Expand description

Generation context shared by nested adapter conversion operations. It holds source metadata and a deterministic name scope, not an operation vocabulary.

Fields§

§input_role: Cell<InputRole>

Whether the input supplies a function parameter or callback result.

§flat: &'a Flat<C::Schema>

Source declarations and adapter metadata.

§codec: &'a C

Interpreter for this adapter’s operations.

§state: C::CompileState

Adapter-specific state for this compilation scope.
