Crate prebindgen_declarations 

Source
Expand description

Declaration language and composition for preparing conversion slots.

Declarations::resolve produces a request-free Flat<Resolved<C>> that owns all data needed by compile_resolved. Input and output trees keep separate operation vocabularies; InputNode::Arrow and OutputNode::Arrow expose reverse-direction domains structurally. Declarations::fill, bind_input and bind_output use the same resolver and compiler for individual occurrences. Compiled slots retain wires and Rust code for emission. Generation is owned by the language generator; this crate owns only declaration resolution and slot preparation. Each Wire carries the adapter’s own description in Wire::kind. Reusable value and boxed-allocation leaves live in prebindgen-conversions.
