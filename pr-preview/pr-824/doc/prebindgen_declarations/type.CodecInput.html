Fields§

§fallible: bool

Whether validation or construction can return a binding error. This excludes panics and allocation aborts. Composition preserves child flags.

§context: PhantomData<fn(&<C as Codec>::Context)>

Context type supplied by the language generator at emission.

§node: WireNode<<C as Codec>::Wire, <C as Codec>::Chain, <C as Codec>::Branch>

Authoritative value tree. Adapter metadata records native encoding choices; physical parameters are derived from this tree when the generator emits its signature.

§acknowledgement: Option<TokenStream>

Shared receipt-channel setup or acknowledgement, if this input needs one.

§validation: TokenStream

Validate this value before using it. Compiled recipes also acquire and construct validated children here, keeping initialized values under RAII.

§acquire: TokenStream

Infallible acquisition of this leaf after its validation and alias checks. Empty for compiled recipes that already prepare their values eagerly.

§resources: Vec<Resource>

Active foreign resources whose identities must be checked across all arguments.

§statements: TokenStream

Construct this value from acquired inputs, including source constructor calls.

§argument: TokenStream

Prepared value expression assigned to the caller-supplied target after statements.
