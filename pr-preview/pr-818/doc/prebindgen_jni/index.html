Crate prebindgen_jni 

Source
Expand description

Generate Rust/JNI wrappers and Kotlin bindings from conversion slots. Supported declarations include package!, ptr_class!, data_class!, fun!, expansion declarations, .name(), source selection, package prefix and native initialization. Declaration processing fills occurrence slots before wrappers are generated.
