pub unsafe fn drop_pointer<T: Send>(raw: i64) -> Result<()>
Expand description

Reclaim one JNI allocation and drop its source value.

Null or misaligned addresses return an error. The Send bound supports destruction from whichever JVM thread closes the generated handle.

§Safety

raw must be the untagged address returned by Box::into_raw for a live Box<Allocation<T>>, with the exact matching T. The caller must hold exclusive access: no borrows or other frees may overlap this call. The allocation must never be used again after success. Encoding validation does not detect stale pointers or mismatched types.

use prebindgen_jni_runtime::{Allocation, drop_pointer};
let raw = Box::into_raw(Box::new(Allocation { value: 7u64 }));
// SAFETY: this is the exact allocation type and its sole owner; it is freed once.
unsafe { drop_pointer::<u64>(raw as i64)?; }
