Expand description

Language-specific leaf conversions. Recursive composition stays in this declaration compiler.

A leaf is a source type the adapter converts itself: a value copied across the boundary or an object kept in Rust. prebindgen-conversions provides helpers for both representations. The adapter chooses by type; a recipe only says where the leaves are.

Input leaves must validate without consuming in validation, then acquire ownership without failure or source calls in acquire. Each acquired value needs an ordinary Rust owner so later failures drop it. statements can construct arguments from those owners. Every input wire must retain the supplied activation condition. Output leaves keep ownership in Rust locals until their infallible commit runs after successful delivery.

§Implementing a codec

This minimal codec uses Rust values as its carriers. It illustrates converter construction without a foreign ABI or object storage. A language adapter additionally writes wrappers and chooses native and destination-language carrier types for its wire kinds.

use prebindgen_flat::{Result, validate_bindings};
use prebindgen_conversions::value;
use prebindgen_declarations::{
    Codec, CodecInput, CodecOutput, Declarations,
    Bindings, fun, expand_param, expand_return, bind_input, Input,
};
use proc_macro2::TokenStream;
use quote::quote;
use syn::{Ident, Type};

use prebindgen_declarations::Condition;
fn carrier(kind: value::Value) -> Type {
    match kind {
        value::Value::Scalar(p) => p.rust_type(),
        value::Value::Text => syn::parse_quote!(String),
        value::Value::Bytes => syn::parse_quote!(Vec<u8>),
    }
}
struct RustCarriers;
impl Codec for RustCarriers {
    type Niche = ();
    type Group = ();
    type Extra = ();
    type Context = ();
    type Input = CodecInput<Self>;
    type Output = CodecOutput<Self>;
    type Wire = Type; // The Rust carrier type is the complete wire description.

    fn optional_group(&self, _: Ident, _: Ident, _: Option<()>) {}
    fn field_group(&self, _: Ident) {}
    fn fields_group(&self) {}
    fn niche(&self, _: &Self::Wire) -> Option<()> { None }
    fn set_niche(&self, _: &mut Self::Wire, _: Option<()>) {}
    fn selector(&self, _: &()) -> Self::Wire { syn::parse_quote!(i32) }
    fn consumes(&self, _: &Type, _: &()) -> bool { false }
    fn input_leaf(
        &self, ty: &Type, _: &(), wire: Ident, var: Ident, active: &Condition,
    ) -> Result<CodecInput<Self>> {
        let kind = value::Value::of(ty).ok_or("only values cross this codec")?;
        let decode = quote!(#wire.clone());
        value::input(ty, wire, var, &active.rust(), decode, carrier(kind))
    }
    fn output_leaf(
        &self, ty: &Type, _: &(), wire: Ident, v: TokenStream, borrowed: bool,
    ) -> Result<CodecOutput<Self>> {
        let kind = value::Value::of(ty).ok_or("only values cross this codec")?;
        value::output(ty, wire, v, borrowed, |v| v, carrier(kind))
    }
}

let source = syn::parse_file(r#"
    pub fn from_i32(value: i32) -> i64 { value as i64 }
    pub fn to_i32(value: &i64) -> i32 { *value as i32 }
    pub fn echo(value: i64) -> i64 { value }
"#)?;
let mut flat = Bindings::<Type>::parse(
    source.items.into_iter().map(|item| (item, Default::default())),
)?;
let defaults = Declarations::new(&flat, vec![
    expand_param!(i64).variant(fun!(from_i32)).variant_self().into(),
    expand_return!(i64).field(fun!(to_i32)).field_self().into(),
])?;
defaults.fill(&mut flat, &RustCarriers, &fun!(echo), &())?;
let function = flat.function("echo")?;
// Input: selector, constructor argument, direct value. Output: two values.
assert_eq!(function.params[0].ty.slot.as_ref().unwrap().layout.len(), 3);
assert_eq!(function.ret.slot.as_ref().unwrap().layout.len(), 2);
// Replace just this parameter's converter; later default filling preserves it.
bind_input(&mut flat, &RustCarriers, "echo", "value", &Input::Leaf, &())?;
defaults.fill(&mut flat, &RustCarriers, &fun!(echo), &())?;
validate_bindings(&flat)?;
let input = flat.function("echo")?.params[0].ty.slot.as_ref().unwrap();
assert_eq!(input.layout.len(), 1);
assert_eq!(prebindgen_flat::type_key(&input.layout[0].kind), "i64");
assert!(input.resources.is_empty()); // No foreign ownership in this codec.

Complete adapter-owned metadata for a parent node in the wire tree. The shared compiler creates it through the group hooks below and never interprets it. Use () when no group information is needed.

fn optional_group( &self, presence: Ident, discriminator: Ident, niche: Option<Self::Niche>, ) -> Self::Group

Describe an optional value in the adapter’s own metadata format. presence is the normalized 0/1 binding used by payload conditions. discriminator names a descendant wire; niche is its reserved absent representation, or None when a separate flag is the first child. With a flag, presence and discriminator name that same wire.

Source

fn field_group(&self, name: Ident) -> Self::Group

Describe one named source field, whose subtree may contain any number of wires.

Source

fn fields_group(&self) -> Self::Group

Describe a record or unit value’s ordered collection of field subtrees. The shared helpers check field-name uniqueness before calling this hook.

Source

fn selector(&self, extra: &Self::Extra) -> Self::Wire

Describe an i32 selector tag or optional presence flag.

Selector arm indices start at zero; optional flags use 0 and 1. A codec may advertise excluded negative values as niches for enclosing options. A newly added flag retains its own niches; inactive payload wires do not. extra is the occurrence data of the conversion that contains the selector.

Source

fn consumes(&self, ty: &Type, extra: &Self::Extra) -> bool

Whether a leaf output consumes the current source value.

This must agree with Self::output_leaf. It governs move ordering and double-consumption rejection in Output::Combine, not input ownership. A non-consuming leaf receives a shared reference with borrowed set.

§Arguments
  • ty — owned source type of the value being delivered.
  • extra — occurrence data of the conversion, as passed to bind_output.
Source

fn input_leaf( &self, ty: &Type, extra: &Self::Extra, wire: Ident, var: Ident, active: &Condition, ) -> Result<CodecInput<Self>>

Prepare a leaf input of source type ty using occurrence data extra.

All fallible checks belong in InputPlan::validation; do not consume values there. Return a generation error when this type or access mode is unsupported.

§Arguments
  • ty — the source parameter type at this position, as written: T, &T or &mut T.
  • extra — occurrence data of the conversion, as passed to bind_input or Declarations::fill.
  • wire — fresh identifier for the boundary parameter this leaf adds. A leaf that needs more wires or locals derives their names from it.
  • var — fresh identifier for the Rust local that holds the converted value. InputPlan::argument normally refers to it.
  • active — the selector arms under which this leaf is used. Copy it to every returned wire and resource, and guard validation and acquisition with it.
Source

fn niche(&self, wire: &Self::Wire) -> Option<Self::Niche>

The unused representation currently available on this wire. Initialize it when creating the wire and return the state last written by set_niche. Never offer a representation already used by an inner option or accepted as a present leaf payload. It may describe one value or a set.

Source

fn set_niche(&self, wire: &mut Self::Wire, niche: Option<Self::Niche>)

Update the unused representation stored in a wire’s own description. The compiler calls this after reserving a niche or disabling a conditional wire. Codecs must preserve this update in their wire description. A codec with no niches can implement this as a no-op and always return None from niche.

Source

fn output_leaf( &self, ty: &Type, extra: &Self::Extra, wire: Ident, value: TokenStream, borrowed: bool, ) -> Result<CodecOutput<Self>>

Prepare delivery of the Rust expression value as one or more wires.

Keep unpublished allocations under Rust ownership and transfer them only in OutputPlan::commit. Return a generation error for unsupported conversions. Install final delivery in Codec::finish_output, rather than on nested leaf plans; recursive composition rejects leaf delivery.

§Arguments
  • ty — the owned source type of the value.
  • extra — occurrence data of the conversion, as passed to bind_output or Declarations::fill.
  • wire — fresh identifier for the delivered value. A leaf that needs more wires or locals derives their names from it.
  • value — Rust expression producing the value to deliver.
  • borrowed — true when value is a shared reference to ty, such as a record field observed in place; do not move out of it. false when value is owned.

Preserve a logical path in private preparation metadata when the codec needs it. The final converter decides how to use this mapping; Flat never interprets it. Called from the innermost component outward; prepend each segment to its path.

fn output_projected( &self, ty: &Type, extra: &Self::Extra, wire: Ident, value: TokenStream, projection: &Projection, ) -> Result<CodecOutput<Self>>

Convert a leaf with explicit ownership, independently of its usual policy.

The compiler supplies either an owned value or a shared reference according to projection.mode. The default supports leaves without field overrides.

fn result_error( &self, _ty: &Type, _message: TokenStream, _extra: &Self::Extra, ) -> Result<TokenStream>

Adapt a source-error message to this language’s error channel.

message evaluates to an owned String; the returned expression must also produce a String. It may first report an adapter-specific error, such as throwing a JVM exception. The compiler then returns Err from the active fallible call before success-output preparation or ownership commit. The default rejects Result error routing rather than guessing a policy.

Source

fn is_present( &self, _wire: &Self::Wire, _niche: &Self::Niche, _value: TokenStream, ) -> Result<TokenStream>

Recognize presence without decoding the payload. Called on original inner metadata. The expression must be total and side-effect-free for every initialized wire value, including inactive placeholders; it must not dereference raw pointers. It returns false for every representation reserved by this niche.

Source

fn remaining_niche( &self, _wire: &Self::Wire, _niche: &Self::Niche, ) -> Option<Self::Niche>

Remaining excluded representation after reserving niche for one optional layer. The compiler stores the result in the wire through set_niche. Returning None exhausts this domain; enclosing options then use another wire or a flag.

Source

fn absent_value( &self, _wire: &Self::Wire, _niche: Option<&Self::Niche>, _input: bool, ) -> Result<TokenStream>

Inert wire expression used for an absent payload, optionally using a niche.

Source

fn finish_input( &self, _plan: &mut CodecInput<Self>, _extra: &Self::Extra, ) -> Result<()>

Complete a composed parameter plan before it is stored in a slot. Called once per bound parameter, including records and selectors.

Source

fn finish_output( &self, _plan: &mut CodecOutput<Self>, _extra: &Self::Extra, ) -> Result<()>

Complete a composed result plan, including unit and multi-wire results. Install call-level delivery here, after all output expressions are known.
