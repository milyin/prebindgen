Struct OutputRows 

Source 
pub struct OutputRows<T: Copy> { /* private fields */ }
Expand description

Final row storage that reclaims owned wire fields if output conversion fails.

Rows are Copy foreign representations; their owned fields need a generated destructor rather than Rust’s ordinary field destruction. Storage is allocated once at its final length. Completed rows need no separate ownership queue.

pub unsafe fn new(length: usize, release: unsafe fn(&T)) -> Self

Allocate final storage and register destruction of completed rows.

§Safety

release must reclaim exactly the additional resources owned by a completed row, including nested row allocations, and skip borrowed fields. It must contain destructor panics per field so other fields are reclaimed. The generated initializer must transfer each row’s resources exactly once before calling Self::commit_row.

Source

pub unsafe fn write_next(&mut self, row: T)

Store the next row before transferring its resources to this guard.

§Safety

Fewer than len() rows must have completed. The row’s resources must remain owned by the initializer until Self::commit_row. Do not change completed rows or retain references to this storage across a write.

Source

pub unsafe fn commit_row(&mut self)

Take cleanup responsibility for the row most recently written.

§Safety

The next row must have been written, and all its owned resources must have transferred to this guard. No fallible or unwinding operation may separate the resource transfer from this call. Commit each row once.
