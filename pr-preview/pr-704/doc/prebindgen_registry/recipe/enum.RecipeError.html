Cycle

A recipe’s parts reach the recipe’s own crossing.

The path is a chain of keys because it may pass through a callback, and so swap directions.

NotAConstructor

A constructor was named where what it returns is not the recipe type.

The constructing twin of NotAnAccessor. A Result<T, E> return counts as building a T, because that is where a construction’s fallibility is read from.

Fields

§func: Ident

WrongShape

A shape was declared for a type that cannot take it: Optional on a type that is not an Option, Sequence on one that is not a run, or Invoke on one that is not a callback.

The arity shapes read their inner type off the crossing rather than stating it, so this is where a mismatch surfaces.

Fields

§recipe: RecipeKey

The row whose shape is wrong.

§shape: &'static str

The shape as declared.

§wanted: &'static str

What the type would have had to be.

NotAProduct

Fields

§recipe: RecipeKey

UnknownRecipe

Where the value crosses.

§

NoSuchRecipe

A caller named a recipe row the table does not have.

Distinct from UnknownRecipe, which is a site asking for one. This is a caller naming a row directly, where there is no site to name — an adapter checking a recipe it declared conditionally, and getting the condition wrong.

Fields

§recipe: RecipeKey

The complete key the caller asked for.

§

Rebound

Two declarations of equal precedence bound one site to different recipes.

Fields

§site: Site

The site both named.

§origin: Origin

The precedence they share.

§

ComposedType

A part yields a different Rust type from the one its edge needs.

The type half of the composition contract; Composition is the ownership half. Both are checked at every part, this one first: a part producing the wrong value is wrong however it is held.

Every part, in the full sense — a product’s fields and constructor arguments, an optional’s value, a run’s element, and a callback’s arguments. Each is a crossing the recipe reaches, and each is checked in the one place the driver reaches one.

Fields

§site: Site

The part’s own site.

§part: usize

Which part of the recipe.

§wanted: TypeKey

What the edge requires: a constructor’s parameter, a field, an accessor’s receiver, an optional’s value, a run’s element, or a callback argument.

§got: TypeKey

What the part’s fragment says it produces.

§

Composition

A part yields something the edge it feeds cannot consume.

Fields

§site: Site

The part’s own site.

§part: usize

Which part of the recipe.

§wanted: Mode

How the edge requires it held: a product’s declared parameter or field mode, an optional’s value, the mode a collection lends its elements in, or a callback argument’s own.

§got: Mode

What the part’s fragment produces.

§

Validity

A site needs a value that outlives the call and got a borrowed one.

Fields

§site: Site

Where the value crosses.

§needed: Validity

The weakest validity the site’s role accepts.

§got: Validity

What the root fragment produces.

§

CallbackShape

A callback crossing was declared with a shape other than Shape::Invoke.

Converting the arguments is what makes a callable callable, so taking it apart is the only thing an adapter can do with one.

Fields

§recipe: RecipeKey

The invalid callback row.
