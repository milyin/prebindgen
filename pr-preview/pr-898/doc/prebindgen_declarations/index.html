Source
Expand description

Declaration language and composition for preparing conversion slots.

Declarations::fill, bind_input and bind_output build conversions directly in a Bindings model. Recipes and codec input data are used only during construction; slots retain wires and code needed by wrapper writers. Generation is owned by the language generator; this crate owns only declaration resolution and slot preparation. Each Wire carries the adapter’s own description in Wire::kind. Reusable value and boxed-allocation leaves live in prebindgen-conversions.
