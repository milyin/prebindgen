1//! Where a node came from: the syntax it was built from, and the source that
2//! syntax arrived in.
3//!
4//! One uniform property of **every** node in the model — item, parameter,
5//! field, variant, type, array extent alike. Some levels know less than others
6//! (a field has no line of its own), but the shape does not change with the
7//! level, so nothing has to copy a piece of provenance downward by hand.
8

16/// The syntax a node was built from, plus where that syntax came from.
17///
18/// # Why the two travel together
19///
20/// `syn` tokens normally carry spans, so in principle the syntax alone could
21/// answer "where was this written". Not here: the proc-macro serializes each
22/// marked item as a **string** into JSONL, and `build.rs` re-parses it, so every
23/// span in the captured spelling points into an anonymous buffer.
24/// [`SourceLocation::from_span`] captures file, line and column at
25/// macro-expansion time — while real rustc spans still exist — precisely because
26/// they cannot survive that trip.
27///
28/// # Why the location is shared
29///
30/// One captured record is one item, so there is exactly one location per item
31/// and none of its own for any component. An item and everything inside it —
32/// parameters, fields, variants, types, extents — therefore point at the *same*
33/// [`SourceLocation`], which is both the honest answer and the cheap one: a
34/// struct with twenty fields keeps one location, not twenty copies of a path.
35///
36/// `Rc` rather than `Arc`: this holds `syn` values, which are `!Send`, so the
37/// model can never cross a thread boundary and an atomic refcount would only
38/// cost. [`TypeKey`] made the same call for
39/// the same reason.
40///
41/// # The rule about origins
42///
43/// > A reference carries a name; the declaration carries the origin.
44///
45/// `location.crate_name` here is the crate whose source this node was written
46/// *in* — the use site. It is never part of a referenced item's identity:
47/// [`TypeId`](super::TypeId) is a name alone, because `#[prebindgen]` names live
48/// in one flat namespace. [`ConstId`](super::ConstId) is not an exception — the
49/// crate it records is the const's *declaring* crate, obtained by lookup, and
50/// that is exactly what lets an array extent refuse a const from another source.
51/// # Structured syntax access is sealed
52///
53/// The crate-private `spell` operation produces tokens and nothing else, which is all
54/// generated Rust ever needed. The typed node is reachable only inside this crate,
55/// and the field itself is `pub(super)`. `Debug` deliberately prints only the
56/// location: formatting an origin must not become an ungated spelling or syntax-tree
57/// API.
58///
59/// It was a public field returning a `syn` node to anyone who asked.
60/// Outside this crate, rendering requires an explicit
61/// [`RustEmitter`](crate::RustEmitter) implementation; no raw syntax accessor is
62/// public.
63#[derive(Clone)]
64pub struct Origin<S> {
65    /// The exact tokens this node was built from.
66    ///
67    /// `pub(super)` is the seal: inside the model this is the syntax being
68    /// lowered, classified and round-tripped, and reading it is the work. Outside,
69    /// see [`spell`](Self::spell) and [`as_syn`](Self::as_syn).
70    pub(super) syntax: S,
71    /// The captured item this node belongs to, shared with every sibling.
72    pub location: Rc<SourceLocation>,
73}
74
75impl<S> fmt::Debug for Origin<S> {
76    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
77        f.debug_struct("Origin")
78            .field("location", &self.location)
79            .finish_non_exhaustive()
80    }
81}
82
83impl<S> Origin<S> {
84    pub fn new(syntax: S, location: Rc<SourceLocation>) -> Self {
85        Self { syntax, location }
86    }
87
88    /// The node as `syn` — **the escape**.
89    ///
90    /// Every place that takes the source apart instead of asking the model comes
91    /// through here, and `pub(crate)` keeps it inside the flat model and its
92    /// rendering protocol.
93    ///
94    /// Naming it is not an accusation. An emitter assembling a `syn::Item`, or a
95    /// signature the generated crate must restate node for node, legitimately
96    /// needs the node. What it stops is reaching for one *by default*.
97    pub(crate) fn as_syn(&self) -> &S {
98        &self.syntax
99    }
100
101    /// The crate this node's source was written in.
102    ///
103    /// The **use site**, not the declaring crate of anything it names.
104    pub fn crate_name(&self) -> Option<&str> {
105        self.location.crate_name.as_deref()
106    }
107
108    /// The same location over different syntax — for building a component's
109    /// origin from the item's.
110    pub fn with<T>(&self, syntax: T) -> Origin<T> {
111        Origin {
112            syntax,
113            location: Rc::clone(&self.location),
114        }
115    }
116}

118impl Origin<syn::Type> {
119    /// This type's identity as a table key — the same answer
120    /// [`TypeRef::key`](super::TypeRef::key) gives for a reading.
121    ///
122    /// Here because a **declaration** is an `Origin<syn::Type>`: the type a
123    /// build script wrote, carried with a placeless location. Asking it for its
124    /// identity is not reaching for the node, and it should not have to be
125    /// spelled as one — every `TypeKey::from_type(decl.as_syn())` was a keying
126    /// operation wearing an escape's clothes.
127    pub fn key(&self) -> TypeKey {
128        TypeKey::from_type(&self.syntax)
129    }
130}

132impl<S: ToTokens> Origin<S> {
133    /// The node's tokens, for generated Rust to spell.
134    ///
135    /// **The only output route, and deliberately not `ToTokens`.** Implementing
136    /// that trait would make `quote!(#node)` work — and hand every consumer
137    /// `to_token_stream().to_string()` with it, which is a classifier's input in
138    /// a spelling's clothing. A `TokenStream` interpolates just as well one `let`
139    /// earlier, and the string, if a site really wants one, is now a two-call
140    /// pattern that says so.
141    ///
142    /// It does not make a token string *impossible* — `spell().to_string()`
143    /// reaches one, and the ledger still lists that as open. What it makes is
144    /// **visible**: `.to_token_stream().to_string()` was indistinguishable from
145    /// the same call on a type an adapter built itself.
146    ///
147    /// Crate-private: rendering leaves this crate only through a `RustEmitter`
148    /// implementation supplied by a collecting pipeline.
149    pub(crate) fn spell(&self) -> proc_macro2::TokenStream {
150        self.syntax.to_token_stream()
151    }
152}
153
154impl Origin<syn::Type> {
155    /// A **declared** type's tokens.
156    ///
157    /// Public where `Origin::spell` is sealed, and the difference is what `S`
158    /// is. An `Origin<syn::ItemFn>`'s tokens re-parse to the captured item, so
159    /// handing them out is the item door under another name — that one is
160    /// [`RustEmitter`](crate::RustEmitter)'s to open. An
161    /// `Origin<syn::Type>` in an adapter's declaration holds a type the
162    /// **build script wrote**, which was never captured syntax and which #280
163    /// leaves the model no way to have a reading for.
164    ///
165    /// Still a token route, and still one C3 has to account for when
166    /// the callback renderer spells a `TypeRef`: a
167    /// declaration is an identity (`key()`), and the two sites that spell one
168    /// do it to splice `#target` into generated Rust.
169    pub fn declared_spelling(&self) -> proc_macro2::TokenStream {
170        self.spell()
171    }
172}
