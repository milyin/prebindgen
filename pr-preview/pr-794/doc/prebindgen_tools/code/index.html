Input
The Rust that rebuilds a source value from its wires, read by name: what Crossing::decode makes of an In crossing.
Output
The Rust that turns a source value into its wires: what Crossing::encode makes of an Out crossing. It converts whatever value it is given (Self::apply, Self::bind) and evaluates to the wire values, a tuple of them in wire order when there are several.
