4//! # prebindgen-tools
5//!
6//! Building blocks for a prebindgen **language adapter**. Applications that
7//! only want bindings use the `prebindgen-c` or `prebindgen-jni` adapter.
8//!
9//! An adapter writes *generated elements* — functions, types, constants —
10//! around the elements of the [`Flat`](prebindgen_flat::Flat) model, plus the
11//! foreign code that uses them. Values cross between the two on **wires**:
12//! the parameters, return values and fields of the generated elements, typed
13//! by a closed set the adapter owns ([`WireType`]).
14//!
15//! ## Decisions, then code
16//!
17//! How a value crosses is decided before any code is written, and the
18//! decision is a tree the model already has the shape of: the type.
19//!
20//! 1. **Ways** ([`Ways`]): every way a type *may* cross, registered once.
21//!    A [`Way`] holds the model item that fixes what lies below it — a
22//!    struct crosses [`Way::Fields`] with one part per field, a type built by
23//!    a function [`Way::Constructed`] with one part per parameter — so a way
24//!    cannot be registered with parts its item does not have.
25//! 2. **Choices** ([`Choices`]): which way each *occurrence* takes, in one
26//!    direction — a default per type, replaced at chosen [`Place`]s. A
27//!    [`WayId`] is typed by the directions its way can serve, so a
28//!    constructor cannot be chosen for a value leaving Rust.
29//! 3. **Crossing** ([`resolve`]): one occurrence's type walked layer by
30//!    layer, the chosen way installed at each node, down to the wires — a
31//!    [`Crossing`]. Its [`Node`]s are built only by resolving, so their
32//!    children are the type's: a [`Fields`] node has a crossing per field of
33//!    its struct, an [`Optional`] one of the option's inner type. A
34//!    crossing is typed by its [`Direction`], so a node only one direction
35//!    has cannot occur in the other. What the model leaves open — which
36//!    values cross whole, on which wire, how an option tells absence, which
37//!    wires carry a sequence — the adapter answers through [`Lower`].
38//! 4. **Code**: [`Crossing::decode`] turns an [`In`] crossing into the Rust
39//!    that rebuilds the value from its wires ([`Input`]), and
40//!    [`Crossing::encode`] an [`Out`] crossing into the Rust that produces
41//!    them ([`Output`]). The adapter writes only what one wire holds — with
42//!    the wire itself, as a [`Whole`] — and a sequence's loop
43//!    ([`Decode`], [`Encode`]); every composition is the crossing's.
44//!
45//! The same crossing serves both sides of the boundary: its
46//! [`wires`](Crossing::wires) are the generated element's parameters, and
47//! the foreign-side writer reads its nodes to produce or unpack the same
48//! wires in the same order.
49//!
50//! ## Example
51//!
52//! A struct `Point` registered three ways — as its fields, whole as a
53//! handle, and built by `point_new` — crossing each way at a different
54//! parameter:
55//!
56//! ```
57//! use prebindgen::SourceLocation;
58//! use prebindgen_flat::{flat::{ScalarKind, Type, TypeRef}, Flat};
59//! use prebindgen_tools::{
60//!     resolve, Choices, Code, Crossing, Decode, In, Input, Lower, Place, Presence, Seg,
61//!     Sequence, Shape, Ways, Whole, Wire, WireType,
62//! };
63//! use proc_macro2::TokenStream;
64//! use quote::quote;
65//!
66//! // The adapter's wire types.
67//! #[derive(Clone, Debug)]
68//! enum W { Long, Handle }
69//! impl WireType for W {
70//!     fn rust(&self) -> TokenStream {
71//!         match self { W::Long => quote!(i64), W::Handle => quote!(*mut ::core::ffi::c_void) }
72//!     }
73//!     fn placeholder(&self) -> TokenStream {
74//!         match self { W::Long => quote!(0), W::Handle => quote!(::core::ptr::null_mut()) }
75//!     }
76//! }
77//!
78//! let source = syn::parse_file("
79//!     pub struct Point { pub x: i64, pub y: i64 }
80//!     pub fn point_new(x: i64) -> Point { Point { x, y: 0 } }
81//!     pub fn draw(p: Point) {}
82//!     pub fn keep(p: Point) {}
83//!     pub fn build(p: Point) {}
84//! ").unwrap();
85//! let location = SourceLocation { crate_name: Some("src".into()), ..Default::default() };
86//! let flat = Flat::builder()
87//!     .items(source.items.into_iter().map(|i| (i, location.clone())))
88//!     .build().unwrap();
89//! let Some(Type::Struct(point)) = flat.declared_type("Point") else { unreachable!() };
90//!
91//! // 1. Ways: every way `Point` may cross, each checked against the model.
92//! let mut ways = Ways::new();
93//! let fields = ways.fields(point);
94//! let handle = ways.whole(point.type_ref(), ());
95//! let built = ways.constructed(flat.function("point_new").unwrap()).unwrap();
96//!
97//! // 2. Choices: the fields everywhere, but a handle for `keep`'s `p` and
98//! //    the constructor for `build`'s. (`built` is a `WayId<In>`: it cannot
99//! //    be chosen for a `Choices<Out>`.)
100//! let param = |f: &str| Place::new(f).at(Seg::Param("p".into()));
101//! let mut choices = Choices::<In>::new();
102//! choices.choose(&ways, fields).unwrap();
103//! choices.choose_at(param("keep"), handle);
104//! choices.choose_at(param("build"), built);
105//!
106//! // 3. What the model leaves to the boundary: which values cross whole,
107//! //    on which wire, read by which code.
108//! struct Boundary<'a, 'f> { ways: &'a Ways<'f, ()>, choices: &'a Choices<In> }
109//! impl<'f> Lower<'f, In> for Boundary<'_, 'f> {
110//!     type Wire = W;
111//!     type Leaf = ();
112//!     type Error = String;
113//!     fn ways(&self) -> &Ways<'f, ()> { self.ways }
114//!     fn choices(&self) -> &Choices<In> { self.choices }
115//!     fn whole(&self, _: &TypeRef, shape: Shape<'_, &()>, place: &Place)
116//!         -> Result<Option<Whole<W, In>>, String>
117//!     {
118//!         let wire = |t| Wire::new(place.ident(), t);
119//!         Ok(match shape {
120//!             Shape::Scalar(ScalarKind::I64) => {
121//!                 Some(Whole::<W, In>::new(wire(W::Long), |w| Code::new(quote!(#w))))
122//!             }
123//!             // `Point`, where its chosen way is whole.
124//!             Shape::Declared { .. } => Some(Whole::<W, In>::new(wire(W::Handle), |w| {
125//!                 Code::new(quote!(*::std::boxed::Box::from_raw(#w as *mut src::Point)))
126//!             })),
127//!             _ => None,
128//!         })
129//!     }
130//!     fn presence(&self, _: &Crossing<'f, W, In>, place: &Place)
131//!         -> Result<Presence<W, In>, String> { Err(format!("{place}: no options")) }
132//!     fn sequence(&self, _: &Crossing<'f, W, In>, place: &Place)
133//!         -> Result<Vec<Wire<W>>, String> { Err(format!("{place}: no sequences")) }
134//!     fn tag(&self, place: &Place) -> Result<Wire<W>, String> {
135//!         Err(format!("{place}: no sums"))
136//!     }
137//! }
138//!
139//! // 4. The code the crossing leaves to the adapter: here, none.
140//! struct Codec;
141//! impl<'f> Decode<'f, W> for Codec {
142//!     type Error = String;
143//!     fn sequence(&self, at: &Crossing<'f, W, In>, _: &Sequence<'f, W, In>, _: Input)
144//!         -> Result<Code, String> { Err(format!("{}: no sequences", at.place())) }
145//! }
146//!
147//! // Resolve each function's `p`, then read its wires and its Rust.
148//! let boundary = Boundary { ways: &ways, choices: &choices };
149//! let cross = |f: &str| {
150//!     let p = &flat.function(f).unwrap().params[0];
151//!     let crossing = resolve(&boundary, &p.ty, param(f)).unwrap();
152//!     let wires: Vec<String> = crossing.wires().iter().map(|w| w.name.to_string()).collect();
153//!     (wires, crossing.decode(&Codec).unwrap().expr().to_string())
154//! };
155//! let (wires, rust) = cross("draw");
156//! assert_eq!(wires, ["p_x", "p_y"]);
157//! assert_eq!(rust, quote!(src::Point { x: p_x, y: p_y }).to_string());
158//! let (wires, _) = cross("keep");
159//! assert_eq!(wires, ["p"]);
160//! let (wires, rust) = cross("build");
161//! assert_eq!(wires, ["p_x"]);
162//! assert_eq!(rust, quote!(src::point_new(p_x)).to_string());
163//! ```
164//!
165//! `tests/toy_adapter.rs` is a complete adapter in this style, with both
166//! directions, options, sums, conversions and the foreign side.
167//!
168//! ## Other tools
169//!
170//! Generated code names a source item by its
171//! [`ItemName`](prebindgen_flat::flat::ItemName), which the flat model
172//! qualifies when it is built: splicing a function's `name` writes
173//! `source_crate::make`. A whole source type is never spelled by the adapter,
174//! except through [`callback_arg_types`]. [`RustFile`] collects and writes the
175//! generated Rust.

186/// Custom conversions: a source type that crosses as another type.
187///
188/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
189/// says that `Millis` never crosses as itself: it crosses as `u64` — the
190/// **representation** — and these two functions convert.
191///
192/// Each direction is a function (a flat item, or a binding-local path with a
193/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
194/// `TryInto`). A function returning `Result` makes its direction fallible;
195/// the error is reported through its `Display`.
196///
197/// [`Conversion::resolve`] checks the declaration against the model; the
198/// adapter does it once, while planning, and registers the
199/// [`ResolvedConversion`] as a way for the source type
200/// ([`Ways::converted`]). A crossing of that type is then a
201/// [`Converted`] node over the crossing of the representation.
202pub mod convert {
203    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Via};
204}

242/// use quote::quote;
243///
244/// let source = syn::parse_file(
245///     "pub struct Payload; pub fn on(f: impl Fn(&Payload) + Send + Sync + 'static) {}",

274/// One level of a type's structure, with any adapter declaration for that type.
275///
276/// [`resolve`] reads each layer of a type with it, and hands the layer to the
277/// adapter's [`Lower::whole`] to ask whether the value crosses whole there.
278/// [`shape()`] answers the same way for every adapter. It first asks the adapter whether the complete type has a
279/// declaration, then returns a built-in shape when it does not. Each adapter
280/// recurses with one `match` over [`Shape`].
281///
282/// For example, `shape(&payload_type, shape_declared)` returns
283/// [`Shape::Declared`] when the callback returns a declaration for `Payload`.
284/// For `Option<Payload>`, it returns [`Shape::Option`] when the callback has
285/// no declaration for the whole option; the adapter then calls [`shape()`]
286/// on its inner type.
287///
288/// A shape describes source structure; the adapter uses it to choose its
289/// wire for a value that crosses whole. An adapter can declare a type such as `Vec<u8>` as a whole, while an undeclared
290/// container exposes child types for further calls.
291/// [`Access`] describes by-value use or borrowing; [`SequenceKind`] and
292/// [`TextKind`] identify the source container independently of access.
293/// `Cow` remains an explicit wrapper around its inner type.
294///
295/// [`shape()`] documents declaration precedence, the handling of common
296/// borrows, and which unsupported forms return errors.
297/// A successful call only classifies the current layer: an adapter must
298/// still handle undeclared names and errors encountered in its children.
299///
300/// ```
301/// use prebindgen::SourceLocation;
302/// use prebindgen_flat::{Flat, flat::{TypeKind, TypeRef}};
303/// use prebindgen_tools::{shape, Access, Shape};
304/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
305/// let flat = Flat::builder()
306///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
307///     .build().unwrap();
308/// let ty = &flat.function("send").unwrap().params[0].ty;
309/// // The callback has no declaration for the whole Option.
310/// let Shape::Option(inner) = shape::<&str>(ty, |_| None)
311///     .unwrap() else { panic!("expected Option") };
312/// // The callback finds Payload inside the borrow; Declared retains &Payload.
313/// assert!(matches!(
314///     shape(inner, |candidate: &TypeRef| match candidate.kind() {
315///         TypeKind::Named { id, .. } if id.name == "Payload" => Some("handle"),
316///         _ => None,
317///     }).unwrap(),
318///     Shape::Declared { ty, declaration: "handle" }
319///         if std::ptr::eq(ty, inner) && Access::of(ty) == Access::Shared
320/// ));
321/// // Missing adapter configuration is a shape the adapter must handle.
322/// assert!(matches!(
323///     shape::<()>(inner, |_| None).unwrap(),
324///     Shape::Undeclared("Payload")
325/// ));
326/// ```
327pub mod shape {
328    pub use crate::api::shape::{shape, Access, SequenceKind, Shape, TextKind};
329}
