Expand description

Emit a resolved registry, assembling the generated Rust file from a frozen Assembly.

The assembly is what the adapter’s compilation produced: one final artifact per item the file will contain, already deduplicated and in registry-owned dependency order. Handing artifacts over instead of a converter table is what frees an adapter to emit a conversion the table could not hold — several functions for one crossing, or one occupying more than a single wire value.

out_path may be relative (resolved against OUT_DIR by prebindgen) or absolute. Returns the path actually written.
