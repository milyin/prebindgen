Expand description

Which way a value crosses. A Crossing is typed by it, so a node only one direction can have — a value built by a function, say — cannot appear in the other.

Required Associated Types§

type Constructed<'f, W: WireType>: Debug

A value built from crossing arguments: Constructed into Rust, Never out of it.

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
