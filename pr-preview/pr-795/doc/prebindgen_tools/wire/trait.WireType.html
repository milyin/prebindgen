Expand description

The adapter’s closed set of boundary types — one enum per adapter.

A variant may say more than its Rust type does: JNI’s jlong is a Kotlin Long, a ULong or a handle of some class, and each is its own variant. The foreign-side writer reads that meaning off the wire, so it never has to repeat a decision that an override or a default made for it.
