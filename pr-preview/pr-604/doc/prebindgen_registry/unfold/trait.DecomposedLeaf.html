Expand description

What the walk needs to know about one delivered leaf.

The adapter’s own leaf carries far more — its wire type, its JNI or C encoding, its projection — and none of that reaches here.

fn is_field_read(&self) -> bool

Whether the last step reaching it is a field read rather than a call.

Derived from Self::reach, so no implementation can disagree with its own path — and the answer decides whether the reached place is cloned, which is an ownership decision rather than a spelling.
