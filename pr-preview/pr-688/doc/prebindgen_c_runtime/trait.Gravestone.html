Expand description

An inline-opaque value type with a representable gravestone (empty / moved-from) state.

The user implements only the logic — what an empty, safely-droppable value of the Rust type is (Self::rust_gravestone). The opaque-side Self::gravestone (the surface the generated consume/take converters call to write back a moved-from slot) is provided automatically via Transmute, so no hand-written unsafe/transmute is needed.

There is no is_gravestone: the generated destructor drops the slot unconditionally, which is safe precisely because the gravestone is itself a valid, safely-droppable value (e.g. Sample::empty(), an empty ZBytes).
