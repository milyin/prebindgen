Expand description

One final artifact of the generated Rust file.

Resolution decides what the artifact is and what it depends on; this trait is the one thing the artifact still owes the writer — the Rust items it becomes. Self::render runs at the final writing boundary, with the crate::RustWriter used for the rest of final Rust emission and with no access to a live Registry, so an artifact cannot resume resolution while the file is being assembled.

fn key(&self) -> ArtifactKey

Semantic identity, owned by the registry rather than by the Rust symbol final emission will choose.

Source

fn calls(&self) -> Vec<ArtifactKey>

The artifacts this one’s body calls.

Deliberately without a default: an artifact that calls nothing says so by returning an empty vector, and one that gains a call has to answer the question again. These edges are what proves the file complete — see WriteError::UnreachedDependency — so an unanswered one is a silently weaker check rather than a compile error.

Provided Methods§

Source

fn reachable(&self) -> bool

Whether the generated adapter surface reaches this artifact. Validation-only artifacts return false: they are still rendered so that a caller of one can be reported, but they do not reach the file.

Source

fn provides(&self) -> Vec<ArtifactKey>

The identities this artifact’s items answer for.

Defaults to its own — the common case, where one artifact renders the items of one identity. An artifact that renders another identity’s item too says so here, which is how a dependency on that identity is satisfied. The C callback artifact does exactly that: it renders the Invoke helper of a converter operation whose own fragment deliberately carries no artifact.
