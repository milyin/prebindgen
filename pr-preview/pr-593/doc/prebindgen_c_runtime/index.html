The Transmute and Gravestone runtime traits for inline-opaque by-value FFI types.

Unlike the rest of core, these are runtime traits: they are implemented on the opaque counterpart of an inline-by-value Rust type and called from the extern "C" converters that prebindgen’s experimental C adapter emits for a value_opaque declaration.

An inline-opaque type is passed across the C ABI by value (no Box): the Rust value’s bytes live directly inside a #[repr(C, align(_))] opaque struct of identical size/alignment. Transmute is the (autogenerated) glue that moves a value between the two representations; Gravestone adds the logical empty/moved-from state on top, which the user supplies.

Because C “moves” by bitwise copy, a moved-from value still occupies the caller’s slot; a gravestone is the empty, safely-droppable state written back into that slot after the live value is moved out, so a later destructor call is a harmless no-op.
