Expand description

Language-specific leaf conversions. Recursive composition stays in this declaration compiler.

A leaf is a source type the adapter converts itself: a value copied across the boundary or an object kept in Rust. prebindgen-conversions provides helpers for both representations. The adapter chooses by type; a recipe only says where the leaves are.

Input leaves must validate without consuming in validation, then acquire ownership without failure or source calls in acquire. Each acquired value needs an ordinary Rust owner so later failures drop it. statements can construct arguments from those owners. Every input wire must retain the supplied activation condition. Output leaves keep ownership in Rust locals until their infallible commit runs at the selected protocol’s transfer point. Buffered delivery commits after all foreign delivery succeeds; an explicit visitor protocol can transfer each prepared element at callback entry.

Source-aware hooks receive the authoritative Flat model. Read configured type, field, function and module metadata there instead of retaining parallel indexes in the codec or passing copies through Extra. Pure wire-composition hooks need no model access. Unresolved recipes remain temporary preparation inputs.

§Implementing a codec

This minimal codec uses Rust values as its carriers. It illustrates converter construction without a foreign ABI or object storage. A language adapter additionally writes wrappers and chooses native and destination-language carrier types for its wire kinds.

use prebindgen_flat::{Result, Wire, validate_bindings};
use prebindgen_conversions::{value};
use prebindgen_declarations::{
    Codec, CodecInput, CodecOutput, Declarations,
    Bindings, fun, expand_param, expand_return, bind_input, Input,
};
use proc_macro2::TokenStream;
use quote::quote;
use syn::{Ident, Type};

use prebindgen_declarations::Condition;
fn carrier(kind: value::Value) -> Type {
    match kind {
        value::Value::Scalar(p) => p.rust_type(),
        value::Value::Text => syn::parse_quote!(String),
        value::Value::Bytes => syn::parse_quote!(Vec<u8>),
    }
}
struct RustCarriers;
impl Codec for RustCarriers {
    type Schema = prebindgen_conversions::PlanSchema<Type>;
    type Niche = ();
    type Chain = ();
    type Branch = ();
    fn group_metadata(&self) {}
    type Extra = ();
    type Context = ();
    type Wire = Type; // The Rust carrier type is the complete wire description.

    fn optional_metadata(&self, _: Ident, _: Ident, _: Option<()>, _: &[Wire<Type>]) -> Result<()> {Ok(())}
    fn alternatives_metadata(&self, _: &Wire<Type>) -> Result<()> {Ok(())}
    fn field_group(&self, _: Ident) {}
    fn fields_group(&self) {}
    fn optional_niche(&self, _: &prebindgen_flat::WireNode<Self::Wire>) -> Option<prebindgen_declarations::NicheReservation<()>> {None}
    fn retire_niches(&self, _: &mut prebindgen_flat::WireNode<Self::Wire>, _: Option<&prebindgen_declarations::NicheReservation<()>>) -> Result<()> {Ok(())}
    fn niche(&self, _: &Self::Wire) -> Option<()> { None }
    fn set_niche(&self, _: &mut Self::Wire, _: Option<()>) {}
    fn selector(&self, _: &()) -> Self::Wire { syn::parse_quote!(i32) }
    fn consumes(&self, _flat: &prebindgen_flat::Flat<Self::Schema>, _: &Type, _: &()) -> bool { false }
    fn input_leaf(
        &self, _flat: &prebindgen_flat::Flat<Self::Schema>, ty: &Type, _: &(), wire: Ident, var: Ident, active: &Condition,
    ) -> Result<CodecInput<Self>> {
        let kind = value::Value::of(ty).ok_or("only values cross this codec")?;
        let decode = quote!(#wire.clone());
        value::input(ty, wire, var, &active.rust(), decode, carrier(kind))
    }
    fn output_leaf(
        &self, _flat: &prebindgen_flat::Flat<Self::Schema>, ty: &Type, _: &(), wire: Ident, v: TokenStream, borrowed: bool,
    ) -> Result<CodecOutput<Self>> {
        let kind = value::Value::of(ty).ok_or("only values cross this codec")?;
        value::output(ty, wire, v, borrowed, |v| v, carrier(kind))
    }
}

let source = syn::parse_file(r#"
    pub fn from_i32(value: i32) -> i64 { value as i64 }
    pub fn to_i32(value: &i64) -> i32 { *value as i32 }
    pub fn echo(value: i64) -> i64 { value }
"#)?;
let mut flat = Bindings::<Type>::parse(
    source.items.into_iter().map(|item| (item, Default::default())),
)?;
let defaults = Declarations::new(&flat,
    vec![expand_param!(i64).variant("from_i32").into()],
    vec![expand_return!(i64).field("to_i32").field_self().into()],
    vec![],
)?;
defaults.fill(&mut flat, &RustCarriers, &fun!(echo), &())?;
let function = flat.function("echo")?;
// Input: one constructor argument. Output: two projected values.
assert_eq!(prebindgen_flat::wire_definitions(std::iter::once(&function.params[0].ty.slot.as_ref().unwrap().node)).count(), 1);
assert_eq!(prebindgen_flat::wire_definitions(std::iter::once(&function.ret.slot.as_ref().unwrap().outcomes.success)).count(), 2);
// Replace just this parameter's converter; later default filling preserves it.
bind_input(&mut flat, &RustCarriers, "echo", "value", &Input::Leaf, &())?;
defaults.fill(&mut flat, &RustCarriers, &fun!(echo), &())?;
validate_bindings(&flat)?;
let input = flat.function("echo")?.params[0].ty.slot.as_ref().unwrap();
assert_eq!(prebindgen_flat::wire_definitions(std::iter::once(&input.node)).count(), 1);
assert_eq!(prebindgen_flat::type_key(&prebindgen_flat::wire_definitions(std::iter::once(&input.node)).next().unwrap().kind), "i64");
assert!(input.resources.is_empty()); // No foreign ownership in this codec.

fn group_metadata(&self) -> Self::Branch

Describe an ordered set of conversion components. Constructors, output accessors and combinations retain this group with one component. Constructors retain an empty group when there are no arguments. Source record fields instead use Codec::fields_group.

Source

fn optional_metadata( &self, presence: Ident, discriminator: Ident, niche: Option<Self::Niche>, controls: &[Wire<Self::Wire>], ) -> Result<Self::Chain>

Describe an optional value in the adapter’s own metadata format. presence is the normalized 0/1 binding used by payload conditions. discriminator names a descendant wire; niche is its reserved absent representation, or None when a separate flag is an inline control wire. With a flag, presence and discriminator name that same wire. The supplied controls stay in the tree. Borrow them to validate the encoding; metadata must not retain wire descriptors. Return an error when they cannot form the adapter’s flag or niche representation; failed preparation preserves existing slots.

Describe one named source field, whose subtree may contain any number of wires.

fn selector(&self, extra: &Self::Extra) -> Self::Wire

Describe an i32 selector tag or optional presence flag.

Selector arm indices start at zero; optional flags use 0 and 1. A codec may advertise excluded negative values as niches for enclosing options. A newly added flag retains its own niches; inactive payload wires do not. extra is the occurrence data of the conversion that contains the selector.

fn consumes( &self, flat: &Flat<Self::Schema>, ty: &Type, extra: &Self::Extra, ) -> bool

Whether a leaf output consumes the current source value.

This must agree with Self::output_leaf. It governs move ordering and double-consumption rejection in Output::Combine, not input ownership. A non-consuming leaf receives a shared reference with borrowed set.

§Arguments
  • ty — owned source type of the value being delivered.
  • extra — occurrence data of the conversion, as passed to bind_output.

fn input_leaf( &self, flat: &Flat<Self::Schema>, ty: &Type, extra: &Self::Extra, wire: Ident, var: Ident, active: &Condition, ) -> Result<CodecInput<Self>>

Prepare a leaf input of source type ty using occurrence data extra.

All fallible checks belong in InputPlan::validation; do not consume values there. Return a generation error when this type or access mode is unsupported.

§Arguments
  • ty — the source parameter type at this position, as written: T, &T or &mut T.
  • extra — occurrence data of the conversion, as passed to bind_input or Declarations::fill.
  • wire — fresh identifier for the boundary parameter this leaf adds. A leaf that needs more wires or locals derives their names from it.
  • var — fresh identifier for the Rust local that holds the converted value. InputPlan::argument normally refers to it.
  • active — the selector arms under which this leaf is used. Copy it to every returned wire and resource, and guard validation and acquisition with it.

fn retire_niches( &self, _payload: &mut WireNode<Self::Wire, Self::Chain, Self::Branch>, _reservation: Option<&NicheReservation<Self::Niche>>, ) -> Result<()>

Remove niche offers from inactive values. Retain only the reservation’s donor with its remaining domain, when one was selected.

fn output_leaf( &self, flat: &Flat<Self::Schema>, ty: &Type, extra: &Self::Extra, wire: Ident, value: TokenStream, borrowed: bool, ) -> Result<CodecOutput<Self>>

Prepare delivery of the Rust expression value as one or more wires.

Keep unpublished allocations under Rust ownership and transfer them only in OutputPlan::commit. Return a generation error for unsupported conversions. Install final delivery in Codec::finish_output, rather than on nested leaf plans; recursive composition rejects leaf delivery.

§Arguments
  • ty — the owned source type of the value.
  • extra — occurrence data of the conversion, as passed to bind_output or Declarations::fill.
  • wire — fresh identifier for the delivered value. A leaf that needs more wires or locals derives their names from it.
  • value — Rust expression producing the value to deliver.
  • borrowed — true when value is a shared reference to ty, such as a record field observed in place; do not move out of it. false when value is owned.

fn finish_input( &self, _plan: &mut CodecInput<Self>, _extra: &Self::Extra, ) -> Result<()>

Complete a composed parameter plan before it is stored in a slot. Called once per bound parameter, including records and selectors. The tree is complete when this hook runs. Edits to it or its metadata are immediately visible to adapter operations; no secondary layout needs refreshing. The compiler validates the tree before installing the finished slot.

Source

fn finish_output( &self, _plan: &mut CodecOutput<Self>, _extra: &Self::Extra, ) -> Result<()>

Complete a composed result plan, including unit and multi-wire results. Install call-level delivery here, after all output expressions are known. The logical schema already includes the composed payload and error channels. Edits to the tree or its adapter metadata are preserved and validated.
