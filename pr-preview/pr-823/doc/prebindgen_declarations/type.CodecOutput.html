Fields§

§fallible: bool

Whether preparation or delivery can return a binding error, excluding panics and allocation aborts. Adapters must mark custom fallible code.

§context: PhantomData<fn(&<C as Codec>::Context)>

Context type supplied by the language generator at emission.

§delivery: Delivery

Delivery and return code prepared with this result slot.

§outcomes: Outcomes<WireNode<<C as Codec>::Wire, <C as Codec>::Chain, <C as Codec>::Branch>>

Authoritative success/error value tree. Adapter metadata on its nodes records explicit native encodings without duplicating payload subtrees.

§commit: TokenStream

Complete transfers for the selected protocol. Buffered outputs commit after foreign delivery succeeds; explicit visitor protocols can commit each element at callback entry during preparation.

§statements: TokenStream

Code producing owned output temporaries and evaluating observations before moves.

§values: Vec<(Ident, TokenStream)>

Prepared success expressions keyed by their destination binding names. Adapters choose packet/row order from the tree and match these by name.
