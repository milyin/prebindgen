Expand description

Which place within an item a site is.

Variants§

§

Param

One parameter of an exported function.

Identified by position and not by name: a Site is a map key, so anything on it has to be something two callers cannot spell differently. The parameter’s name is the model’s, reached through owner.

Fields

§index: usize

Position in the parameter list.

§

Receiver

The value a method is called on.

§

Return

What the function returns.

§

Error

The Err arm of a Result.

§

CallbackArg

One argument the Rust side passes out through a callback.

Swaps direction: Rust holds the value and pushes it out, so the argument is deconstructed even though it sits in a parameter list.

A root role, like Return and Param: it names an argument of the callback in one exported function, so it is what an adapter passes to Compiler::site when it compiles that argument itself. It is deliberately not what the driver asks at while compiling a callback recipe — a recipe is shared by every function whose callback has the same signature, so a per-function answer could not apply to it. Inside a recipe the driver asks at Part, which is keyed by the recipe.

Fields

§param: usize

Which parameter of the exported function is the callback.

§arg: usize

Which argument of that callback.

§

ExpansionLeaf

One leaf of an expanded parameter.

An expand_param! declaration replaces one source parameter with several values, each crossing on its own. They are not Params: that index is the position in the source parameter list, and an expansion’s leaves all belong to the one parameter that expanded — so numbering them as parameters would name positions the function does not have and attach one parameter’s site to another’s crossing (#622 review).

Shaped like CallbackArg because the question is the same one: which parameter, and which value within it.

Fields

§param: usize

Which parameter of the exported function expanded.

§leaf: usize

Which leaf of that expansion.

§

Part

One part of another crossing’s recipe.

Fields

§recipe: RecipeKey

The globally unique row that names this part.

§arm: Option<usize>

Which alternative, for a part inside a Shape::Choice arm; None for a product’s own part.

Load-bearing rather than decorative: every arm numbers its parts from zero, so part 0 of a two-armed sum names two different parts of two different types. Without the alternative there is no key that tells them apart, and a binding written for one silently collides with the other.

§index: usize

The part’s position within the recipe — or within its arm.

§

Const

A #[prebindgen] constant’s value.
