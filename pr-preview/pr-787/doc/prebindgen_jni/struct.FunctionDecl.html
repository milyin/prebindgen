pub fn split_on_param(self, param: impl Into<String>) -> Self

Emit typed overloads for each variant of this parameter’s input expansion (ExpandParamDecl), beside the selector form: one overload takes the constructor’s arguments, another the handle. The parameter must have an input expansion (the type’s own, or one given with Self::expand_param); splitting several parameters emits every combination.

Source

pub fn expand_param( self, param: impl Into<String>, decl: ExpandParamDecl, ) -> Self

Replace the type-level input expansion (ExpandParamDecl) for one parameter. An expansion with only ExpandParamDecl::variant_self makes the parameter a plain handle.

Source

pub fn expand_return(self, decl: ExpandReturnDecl) -> Self

Replace the type-level output expansion (ExpandReturnDecl) for the result. An expansion with only ExpandReturnDecl::field_self makes the result a plain handle.
