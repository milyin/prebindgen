4//! # prebindgen-tools
5//!
6//! Shared type conversion tools for a prebindgen **language generator**.
7//! This is an API prototype: the C and JNI generators are not ported yet.
8//!
9//! An adapter writes *generated elements* — functions, types, constants —
10//! around the elements of the [`Flat`](prebindgen_flat::Flat) model, plus the
11//! foreign code that uses them. Every generated element speaks only in the
12//! adapter's **wire types**: a closed set, one enum per adapter
13//! ([`WireType`]). The tools here are what every adapter needs to get a
14//! source type onto wires and back.
15//!
16//! ## The model
17//!
18//! A source type at a [`Place`] — parameter `p` of `send`, field `x` of it —
19//! crosses in one of a few ways ([`FormKind`]):
20//!
21//! * **directly**, as one wire ([`Input::wire`]);
22//! * **converted** to another source type that crosses instead
23//!   ([`Stage::decode`], [`Stage::encode`]);
24//! * **taken apart** into parts that cross on their own: a record's fields
25//!   ([`Input::record`]), an optional's presence and value
26//!   ([`Input::optional`]), a sum's tag and alternatives ([`Input::sum`]),
27//!   a sequence ([`Input::seq`]).
28//!
29//! Lowering a value builds an [`Input`] (wires → value) or an [`Output`]
30//! (value → wires): the Rust expression *and* the [`Form`] tree recording
31//! which way each layer crossed. The foreign-side writer walks that tree,
32//! so it follows the decisions made — defaults and overrides alike — without
33//! making them again; what a single wire means is in the wire's own type.
34//!
35//! ## Resolving and writing an element
36//!
37//! 1. Implement [`ConversionPolicy`] with your wire enum, rule declarations,
38//!    and destination metadata. Register directional defaults on [`Resolver`].
39//! 2. Create a per-element [`Scope`] with its [`Overrides`]. For every typed
40//!    part, call [`Scope::resolve`] with its type, direction, and [`Place`].
41//! 3. Policy builds a [`ConversionPlan`] with shared [`Input`]/[`Output`]
42//!    combinators, resolving children through that same scope.
43//! 4. Generate destination code from the plan's [`Form`], wire semantics,
44//!    and metadata. Use [`ConversionPlan::with_input`] or
45//!    [`ConversionPlan::emit_output`] for Rust, then [`Scope::finish`] to
46//!    reject overrides that did not name a resolved part.
47//!
48//! Selection is occurrence override → exact type default → policy fallback.
49//! An override is checked against its expected type and direction. The generator
50//! owns generated elements: their kind may differ from the source, they can be
51//! synthetic, or they can group several source elements. See [`mod@resolve`]
52//! for a complete runnable example.
53//!
54//! [`Qualifier`] names source items from the generated crate; [`RustFile`]
55//! collects and writes the generated Rust.
56//!
57//! Fallible conversions use `Result<_, String>`: an expression may use `?`,
58//! and the adapter decides where the error goes ([`Input::result`]).
59

69/// Custom conversions: a source type that crosses as another type.
70///
71/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
72/// says that `Millis` never crosses as itself: it crosses as `u64` — the
73/// **representation** — and these two functions convert. The adapter lowers
74/// the representation like any other type and wraps the resulting wires in
75/// the conversion's stages ([`Stage::apply`]).
76///
77/// A stage is a function (a flat item, or a binding-local path with a
78/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
79/// `TryInto`). A function returning `Result` makes its stage fallible; the
80/// error is reported through its `Display`.
81///
82/// A resolved [`Stage`] composes with the lowering of its representation:
83/// [`Stage::decode`] wraps the representation's [`Input`], [`Stage::encode`]
84/// builds the representation's [`Output`] and wraps it. Either way the result's
85/// [`Form`] is [`FormKind::Via`] over the representation's form.
86pub mod convert {
87    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Stage, Via};
88}

116/// Naming source items from generated Rust code.
117///
118/// The flat model identifies a source item by its flat name, such as
119/// `Payload` or `make`. A binding's generated Rust usually lives in a
120/// different crate, where those names are not automatically in scope.
121/// [`Qualifier`] uses each item's source location to spell a path such as
122/// `source_crate::Payload` or `source_crate::make`. Use it when a wrapper
123/// calls a source function or a conversion names a source type.
124///
125/// ## Choosing a path
126///
127/// [`Qualifier::new`] borrows the model. For each known item,
128/// [`Qualifier::module_of`] reads the crate name recorded in its
129/// [`SourceLocation`](prebindgen::SourceLocation), converting hyphens to
130/// underscores for a Rust path. Items captured from different crates can
131/// therefore receive different prefixes from the same qualifier.
132///
133/// [`Qualifier::with_default_module`] supplies a fallback for **known items
134/// without a recorded crate name**, for example a model assembled directly
135/// from parsed syntax in a test. A recorded crate name takes precedence.
136/// A name absent from the model is left unchanged even when a fallback is
137/// configured; a known item with neither a crate name nor a fallback also
138/// keeps its bare name. The generated crate must be able to resolve the
139/// emitted paths: qualification does not add dependencies or imports, or
140/// discover Cargo dependency aliases.
141///
142/// ## Item paths and type expressions
143///
144/// * [`Qualifier::path`] qualifies one item name, such as the function the
145///   adapter will call.
146/// * [`Qualifier::ty`] walks a complete model type. For example,
147///   `Option<Vec<Payload>>` becomes
148///   `::core::option::Option<::std::vec::Vec<source_crate::Payload>>`.
149///   It qualifies named types inside generic arguments and containers, and
150///   named constants used as array lengths. Standard containers receive
151///   absolute `::core` or `::std` paths; scalar names such as `u32` stay as is.
152/// * [`Qualifier::ty_elided`] provides the same naming for positions such as
153///   closure arguments that cannot refer to a source lifetime parameter.
154///   Its method documentation lists which shapes it elides.
155///
156/// These methods return Rust tokens for the source value's type or path.
157/// The adapter still chooses the wire representation: qualifying
158/// `Payload` does not turn it into a pointer, handle, or mirror struct.
159///
160/// ```
161/// use prebindgen::SourceLocation;
162/// use prebindgen_flat::Flat;
163/// use prebindgen_tools::Qualifier;
164/// use quote::quote;
165///
166/// let source = syn::parse_file(
167///     "pub struct Payload; pub fn make() -> Option<Vec<Payload>> { None }",
168/// ).unwrap();
169/// let location = SourceLocation {
170///     crate_name: Some("source-crate".into()), ..Default::default()
171/// };
172/// let flat = Flat::builder()
173///     .items(source.items.into_iter().map(|item| (item, location.clone())))
174///     .build().unwrap();
175/// let q = Qualifier::new(&flat);
176/// let function = flat.function("make").unwrap();
177/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
178/// let expected: syn::Type = syn::parse_quote!(
179///     ::core::option::Option<::std::vec::Vec<source_crate::Payload>>
180/// );
181/// assert_eq!(syn::parse2::<syn::Type>(q.ty(&function.ret)).unwrap(), expected);
182///
183/// // The fallback does not override the recorded source crate.
184/// let q = q.with_default_module(Some(syn::parse_quote!(crate::source)));
185/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
186/// // A binding-local helper absent from the model stays unqualified.
187/// assert_eq!(q.path(&syn::parse_quote!(local_helper)).to_string(), "local_helper");
188/// ```
189pub mod qualify {
190    pub use crate::api::qualify::Qualifier;
191}

217/// One level of a type's structure, with any adapter declaration for that type.
218///
219/// An adapter lowers a type by recursion: it looks at the outermost layer,
220/// decides what that layer becomes on its boundary, and recurses into what
221/// the layer holds. [`shape()`] answers the first question the same way for
222/// every adapter. It first asks the adapter whether the complete type has a
223/// declaration, then returns a built-in shape when it does not. Each adapter
224/// recurses with one `match` over [`Shape`].
225///
226/// For example, `shape(&payload_type, shape_declared)` returns
227/// [`Shape::Declared`] when the callback returns a declaration for `Payload`.
228/// For `Option<Payload>`, it returns [`Shape::Option`] when the callback has
229/// no declaration for the whole option; the adapter then calls [`shape()`]
230/// on its inner type.
231///
232/// A shape describes source structure; the adapter uses it to build an
233/// [`Input`] or [`Output`] for its chosen wire representation. An adapter
234/// can declare a type such as `Vec<u8>` as a whole, while an undeclared
235/// container exposes child types for further calls.
236/// [`Access`] describes by-value use or borrowing; [`SequenceKind`] and
237/// [`TextKind`] identify the source container independently of access.
238/// `Cow` remains an explicit wrapper around its inner type.
239///
240/// [`shape()`] documents declaration precedence, the handling of common
241/// borrows, and which unsupported forms return errors.
242/// A successful call only classifies the current layer: an adapter must
243/// still handle undeclared names and errors encountered in its children.
244///
245/// ```
246/// use prebindgen::SourceLocation;
247/// use prebindgen_flat::{Flat, flat::{TypeKind, TypeRef}};
248/// use prebindgen_tools::{shape, Access, Shape};
249/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
250/// let flat = Flat::builder()
251///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
252///     .build().unwrap();
253/// let ty = &flat.function("send").unwrap().params[0].ty;
254/// // The callback has no declaration for the whole Option.
255/// let Shape::Option(inner) = shape::<&str>(ty, |_| None)
256///     .unwrap() else { panic!("expected Option") };
257/// // The callback finds Payload inside the borrow; Declared retains &Payload.
258/// assert!(matches!(
259///     shape(inner, |candidate: &TypeRef| match candidate.kind() {
260///         TypeKind::Named { id, .. } if id.name == "Payload" => Some("handle"),
261///         _ => None,
262///     }).unwrap(),
263///     Shape::Declared { ty, declaration: "handle" }
264///         if std::ptr::eq(ty, inner) && Access::of(ty) == Access::Shared
265/// ));
266/// // Missing adapter configuration is a shape the adapter must handle.
267/// assert!(matches!(
268///     shape::<()>(inner, |_| None).unwrap(),
269///     Shape::Undeclared("Payload")
270/// ));
271/// ```
272pub mod shape {
273    pub use crate::api::shape::{shape, Access, SequenceKind, Shape, TextKind};
274}
