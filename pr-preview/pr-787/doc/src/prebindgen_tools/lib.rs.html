4//! # prebindgen-tools
5//!
6//! Building blocks for a prebindgen **language adapter**. Applications that
7//! only want bindings normally use the `prebindgen-c` or `prebindgen-jni`
8//! adapter crate instead.
9//!
10//! An adapter reads the captured [`Flat`](prebindgen_flat::Flat) model,
11//! chooses representations, and generates its own Rust wrappers and foreign
12//! declarations. This crate supplies type inspection and conversion composition;
13//! the adapter owns signatures, layouts, calls, and error handling.
14//!
15//! * [`shape()`] classifies one layer of a type, including adapter declarations.
16//!   The adapter decides which children to visit recursively.
17//! * [`Qualifier`] names source types and items in generated Rust.
18//! * [`Input`] and [`Output`] carry wires and conversion expressions.
19//!   [`Input::combine`], [`Input::optional`] and [`Output::concat`] compose them.
20//! * [`Record`], [`record_in`] and [`record_out`] construct and destructure
21//!   source structs and enum alternatives while preserving field order.
22//! * [`mod@convert`] resolves declared conversions; [`Stage::decode`] and
23//!   [`Stage::encode`] compose them with their representation's conversion.
24//! * [`RustFile`] collects, formats and writes the adapter's generated items.
25//!
26//! Fallible conversions use `Result<_, String>`. The adapter places the
27//! expressions in an error scope and chooses how to report failures. Source
28//! function errors remain part of the source return value and are handled
29//! separately by the adapter.
30

40/// Custom conversions: a source type that crosses as another type.
41///
42/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
43/// says that `Millis` never crosses as itself: it crosses as `u64` — the
44/// **representation** — and these two functions convert. The adapter lowers
45/// the representation like any other type and wraps the resulting wires in
46/// the conversion's stages ([`Stage::apply`]).
47///
48/// A stage is a function (a flat item, or a binding-local path with a
49/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
50/// `TryInto`). A function returning `Result` makes its stage fallible; the
51/// error is reported through its `Display`.
52///
53/// For example, given source functions `millis_from_raw(u64) -> Millis` and
54/// `millis_to_raw(&Millis) -> Result<u64, String>`, an adapter can resolve
55/// both directions before lowering a use of `Millis`:
56///
57/// ```
58/// use prebindgen::SourceLocation;
59/// use prebindgen_flat::Flat;
60/// use prebindgen_tools::{convert, fun, Input, Output, Qualifier, Wire, ident};
61/// use quote::quote;
62/// let source = syn::parse_file(r#"
63///     pub struct Millis(pub u64);
64///     pub fn millis_from_raw(raw: u64) -> Millis { Millis(raw) }
65///     pub fn millis_to_raw(value: &Millis) -> Result<u64, String> { Ok(value.0) }
66/// "#).unwrap();
67/// let flat = Flat::builder()
68///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
69///     .build().unwrap();
70/// let conversion = convert!(Millis)
71///     .input(fun!(millis_from_raw))
72///     .output(fun!(millis_to_raw))
73///     .resolve(&flat).unwrap();
74/// let input = conversion.input.as_ref().unwrap();
75/// let output = conversion.output.as_ref().unwrap();
76/// // Each stage's `repr` is u64; `output.fallible` is true.
77/// assert_eq!(input.repr.spell().to_string(), "u64");
78/// assert!(output.fallible);
79/// let q = Qualifier::new(&flat);
80/// let decoded = input.decode(&q, &conversion.target,
81///     Input::identity(Wire::new(ident!(raw), quote!(u64))),
82///     &ident!(r), quote!());
83/// assert_eq!(decoded.wires.len(), 1);
84/// let encoded = output.encode(&q, &conversion.target, &quote!(value),
85///     &ident!(r), quote!(),
86///     Output::single(Wire::new(ident!(raw), quote!(u64)), quote!(r)));
87/// assert!(encoded.fallible);
88/// ```
89///
90/// An [`Input`] for `u64` is wrapped with [`Stage::decode`]
91/// before the source call; an [`Output`] for `u64` is wrapped
92/// with [`Stage::encode`] after it. A binding-local function can be named
93/// with [`fun!`](crate::fun!) plus [`FnRef::sig`]. See [`Via`] for trait-based alternatives.
94pub mod convert {
95    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Stage, Via};
96}

124/// Naming source items from generated Rust code.
125///
126/// The flat model identifies a source item by its flat name, such as
127/// `Payload` or `make`. A binding's generated Rust usually lives in a
128/// different crate, where those names are not automatically in scope.
129/// [`Qualifier`] uses each item's source location to spell a path such as
130/// `source_crate::Payload` or `source_crate::make`. Use it when a wrapper
131/// calls a source function or a conversion names a source type.
132///
133/// ## Choosing a path
134///
135/// [`Qualifier::new`] borrows the model. For each known item,
136/// [`Qualifier::module_of`] reads the crate name recorded in its
137/// [`SourceLocation`](prebindgen::SourceLocation), converting hyphens to
138/// underscores for a Rust path. Items captured from different crates can
139/// therefore receive different prefixes from the same qualifier.
140///
141/// [`Qualifier::with_default_module`] supplies a fallback for **known items
142/// without a recorded crate name**, for example a model assembled directly
143/// from parsed syntax in a test. A recorded crate name takes precedence.
144/// A name absent from the model is left unchanged even when a fallback is
145/// configured; a known item with neither a crate name nor a fallback also
146/// keeps its bare name. The generated crate must be able to resolve the
147/// emitted paths: qualification does not add dependencies or imports, or
148/// discover Cargo dependency aliases.
149///
150/// ## Item paths and type expressions
151///
152/// * [`Qualifier::path`] qualifies one item name, such as the function the
153///   adapter will call.
154/// * [`Qualifier::ty`] walks a complete model type. For example,
155///   `Option<Vec<Payload>>` becomes
156///   `::core::option::Option<::std::vec::Vec<source_crate::Payload>>`.
157///   It qualifies named types inside generic arguments and containers, and
158///   named constants used as array lengths. Standard containers receive
159///   absolute `::core` or `::std` paths; scalar names such as `u32` stay as is.
160/// * [`Qualifier::ty_elided`] provides the same naming for positions such as
161///   closure arguments that cannot refer to a source lifetime parameter.
162///   Its method documentation lists which shapes it elides.
163///
164/// These methods return Rust tokens for the source value's type or path.
165/// The adapter still chooses the wire representation: qualifying
166/// `Payload` does not turn it into a pointer, handle, or mirror struct.
167///
168/// ```
169/// use prebindgen::SourceLocation;
170/// use prebindgen_flat::Flat;
171/// use prebindgen_tools::Qualifier;
172/// use quote::quote;
173///
174/// let source = syn::parse_file(
175///     "pub struct Payload; pub fn make() -> Option<Vec<Payload>> { None }",
176/// ).unwrap();
177/// let location = SourceLocation {
178///     crate_name: Some("source-crate".into()), ..Default::default()
179/// };
180/// let flat = Flat::builder()
181///     .items(source.items.into_iter().map(|item| (item, location.clone())))
182///     .build().unwrap();
183/// let q = Qualifier::new(&flat);
184/// let function = flat.function("make").unwrap();
185/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
186/// let expected: syn::Type = syn::parse_quote!(
187///     ::core::option::Option<::std::vec::Vec<source_crate::Payload>>
188/// );
189/// assert_eq!(syn::parse2::<syn::Type>(q.ty(&function.ret)).unwrap(), expected);
190///
191/// // The fallback does not override the recorded source crate.
192/// let q = q.with_default_module(Some(syn::parse_quote!(crate::source)));
193/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
194/// // A binding-local helper absent from the model stays unqualified.
195/// assert_eq!(q.path(&syn::parse_quote!(local_helper)).to_string(), "local_helper");
196/// ```
197pub mod qualify {
198    pub use crate::api::qualify::Qualifier;
199}

201/// Records — structs and the alternatives of a sum — taken apart into their
202/// fields and put back together.
203///
204/// The adapter chooses a representation independently of the source shape.
205/// These helpers construct and destructure source values, preserving named or
206/// positional fields, delimiters, and order. Each field may occupy several wires.
207///
208/// ## Example: decompose a record
209///
210/// [`record_in`] combines field inputs in source order and reconstructs the
211/// source's named or tuple form. An adapter normally produces the field
212/// inputs while recursing through [`shape()`](crate::shape()).
213///
214/// ```
215/// use prebindgen::SourceLocation;
216/// use prebindgen_flat::{Flat, flat::Type};
217/// use prebindgen_tools::{Input, Record, Wire,
218///     ident, record_in};
219/// use quote::quote;
220///
221/// let item = syn::parse_quote!(pub struct Point { pub x: i32, pub y: i32 });
222/// let flat = Flat::builder()
223///     .items([(item, SourceLocation::default())])
224///     .build().unwrap();
225/// let Some(Type::Struct(point)) = flat.declared_type("Point") else { panic!() };
226/// let fields = vec![
227///     Input::identity(Wire::new(ident!(x_wire), quote!(i32))),
228///     Input::identity(Wire::new(ident!(y_wire), quote!(i32))),
229/// ];
230/// let input = record_in(Record::Struct(point), &quote!(Point), fields);
231/// assert_eq!(input.wires.len(), 2);
232/// assert_eq!(input.expr.to_string(), "Point { x : x_wire , y : y_wire }");
233///
234/// ```
235pub mod record {
236    pub use crate::api::record::{record_in, record_out, Record};
237}

239/// One level of a type's structure, with any adapter declaration for that type.
240///
241/// An adapter lowers a type by recursion: it looks at the outermost layer,
242/// decides what that layer becomes on its boundary, and recurses into what
243/// the layer holds. [`shape()`] answers the first question the same way for
244/// every adapter. It first asks the adapter whether the complete type has a
245/// declaration, then returns a built-in shape when it does not. Each adapter
246/// recurses with one `match` over [`Shape`].
247///
248/// For example, `shape(&payload_type, shape_declared)` returns
249/// [`Shape::Declared`] when the callback returns a declaration for `Payload`.
250/// For `Option<Payload>`, it returns [`Shape::Option`] when the callback has
251/// no declaration for the whole option; the adapter then calls [`shape()`]
252/// on its inner type.
253///
254/// A shape describes source structure; the adapter uses it to build an
255/// [`Input`] or [`Output`] for its chosen wire representation. An adapter
256/// can declare a type such as `Vec<u8>` as a whole, while an undeclared
257/// container exposes child types for further calls.
258/// [`Access`] describes by-value use or borrowing; [`SequenceKind`] and
259/// [`TextKind`] identify the source container independently of access.
260/// `Cow` remains an explicit wrapper around its inner type.
261///
262/// [`shape()`] documents declaration precedence, the handling of common
263/// borrows, and which unsupported forms return errors.
264/// A successful call only classifies the current layer: an adapter must
265/// still handle undeclared names and errors encountered in its children.
266///
267/// ```
268/// use prebindgen::SourceLocation;
269/// use prebindgen_flat::{Flat, flat::{TypeKind, TypeRef}};
270/// use prebindgen_tools::{shape, Access, Shape};
271/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
272/// let flat = Flat::builder()
273///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
274///     .build().unwrap();
275/// let ty = &flat.function("send").unwrap().params[0].ty;
276/// // The callback has no declaration for the whole Option.
277/// let Shape::Option(inner) = shape::<&str>(ty, |_| None)
278///     .unwrap() else { panic!("expected Option") };
279/// // The callback finds Payload inside the borrow; Declared retains &Payload.
280/// assert!(matches!(
281///     shape(inner, |candidate: &TypeRef| match candidate.kind() {
282///         TypeKind::Named { id, .. } if id.name == "Payload" => Some("handle"),
283///         _ => None,
284///     }).unwrap(),
285///     Shape::Declared { ty, declaration: "handle" }
286///         if std::ptr::eq(ty, inner) && Access::of(ty) == Access::Shared
287/// ));
288/// // Missing adapter configuration is a shape the adapter must handle.
289/// assert!(matches!(
290///     shape::<()>(inner, |_| None).unwrap(),
291///     Shape::Undeclared("Payload")
292/// ));
293/// ```
294pub mod shape {
295    pub use crate::api::shape::{shape, Access, SequenceKind, Shape, TextKind};
296}

298/// Wires and the conversions between wires and source values.
299///
300/// A **wire** is one parameter, field or return slot of the generated
301/// boundary, typed in the generated Rust file: `jlong`, `*const c_char`,
302/// `payload_t`. A source value crosses as zero or more wires, and which
303/// ones is the adapter's decision; these types only carry the decision and
304/// compose it.
305///
306/// * [`Input`] turns wires into a source value — a parameter on its way into
307///   the source function, a field of a struct arriving from the foreign side.
308/// * [`Output`] turns a source value into wires — a return value, a callback
309///   argument, a field of a struct leaving.
310///
311/// Both carry an expression. A **fallible** one may use `?` on a
312/// `Result<_, String>`; whoever places it decides where the error goes (see
313/// [`Input::result`]). Generated conversion helpers follow the same
314/// convention, so a converter written for one position composes into another.
315///
316/// ## Example: one value on two wires
317///
318/// A `u64` can arrive as two `u32` words. [`Input`] keeps the expression together with
319/// the two [`Wire`] declarations so the adapter
320/// can place and evaluate them in the right order:
321///
322/// ```
323/// use prebindgen_tools::{Input, Output, Wire, ident};
324/// use quote::quote;
325///
326/// let hi = Wire::new(ident!(hi), quote!(u32));
327/// let lo = Wire::new(ident!(lo), quote!(u32));
328/// let input = Input::new(vec![hi, lo], quote!(((hi as u64) << 32) | lo as u64));
329/// assert_eq!(input.wires.len(), 2);
330/// assert!(input.result().to_string().contains("Ok"));
331///
332/// let output = Output::new(
333///     vec![Wire::new(ident!(hi), quote!(u32)),
334///          Wire::new(ident!(lo), quote!(u32))],
335///     quote!(((value >> 32) as u32, value as u32)),
336/// );
337/// assert_eq!(output.pattern().to_string(), "(hi , lo)");
338/// ```
339///
340/// For a fallible step, use [`Input::and_then`] or [`Output::fallible`]
341/// and place [`Input::result`] or [`Output::result`] at the point whose
342/// error policy applies. The conversion error type is `String`; the adapter
343/// supplies the fallback or error delivery code.
344pub mod wire {
345    pub use crate::api::wire::{result_expr, Input, Output, Wire};
346}
