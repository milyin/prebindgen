1//! # prebindgen
2//!
3//! A tool for separating the implementation of FFI interfaces from language-specific binding generation,
4//! allowing each to reside in different crates.
5//!
6//! See also: [`prebindgen-proc-macro`](https://docs.rs/prebindgen-proc-macro) for the procedural macros.
7//!
8//! ## Problem
9//!
10//! When creating Rust libraries that need to expose FFI interfaces to multiple languages,
11//! it may be preferable to create separate `cdylib` or `staticlib` crates for each language-specific binding.
12//! This allows you to tailor each crate to the requirements and quirks of its binding generator and to specifisc of the
13//! destination language.
14//! However, `#[no_mangle] extern "C"` functions can only be defined in a `cdylib` or `staticlib` crate, and cannot be
15//! exported from a `lib` crate. As a result, these functions must be duplicated in each language-specific
16//! binding crate. This duplication is inconvenient for large projects with many FFI functions and types.
17//!
18//! ## Solution
19//!
20//! `prebindgen` solves this by generating language-specific proxy code from a common
21//! Rust library crate. This crate is the base of that pipeline: it reads what
22//! `#[prebindgen]` captured and hands out `(syn::Item, [`SourceLocation`])`
23//! pairs through [`Source`] — nothing more. The flat model built over that
24//! stream ships in [`prebindgen-flat`](https://docs.rs/prebindgen-flat); the
25//! language adapters — [`prebindgen-c`](https://docs.rs/prebindgen-c) and
26//! [`prebindgen-jni`](https://docs.rs/prebindgen-jni) — read the model and
27//! generate the binding, writing through
28//! [`prebindgen-tools`](https://docs.rs/prebindgen-tools).
29//!
30//! ## Usage example
31//!
32//! See also example projects on <https://github.com/milyin/prebindgen/tree/main/examples>
33//!
34//! See also the prebindgen-proc-macro documentation for details on how to use the `#[prebindgen]` macro:
35//! <https://docs.rs/prebindgen-proc-macro/latest/prebindgen_proc_macro/>
36//!
37//! The `covertest-kotlin` and `perftest-kotlin` workspace examples are the
38//! references for the JNI/Kotlin path; `example-cbindgen` and `perftest-c`
39//! for C.
40//!
41//! ### 1. In the Common FFI Library Crate (e.g., `example_flat`)
42//!
43//! Mark the types and functions that form your FFI surface with the `prebindgen`
44//! macro. The source crate stays **plain idiomatic Rust** — opaque handles are
45//! ordinary types returned by value, fallible calls return `Result<T, E>`; the
46//! language adapter does the C-ABI lowering, so there is no `#[repr(C)]` here.
47//!
48//! ```rust
49//! // example-flat/src/lib.rs
50//! use prebindgen_proc_macro::{features, prebindgen, prebindgen_out_dir};
51//!
52//! // Export the prebindgen output directory and the enabled features.
53//! pub const PREBINDGEN_OUT_DIR: &str = prebindgen_out_dir!();
54//! pub const FEATURES: &str = features!();
55//!
56//! // An opaque handle — a plain Rust type, returned by value.
57//! pub struct Calculator { value: f64 }
58//!
59//! #[prebindgen]
60//! pub fn calculator_new() -> Calculator { Calculator { value: 0.0 } }
61//!
62//! #[prebindgen]
63//! pub fn calculator_get_value(c: &Calculator) -> f64 { c.value }
64//! ```
65//!
66//! Call [`init_prebindgen_out_dir`] in the crate's `build.rs`:
67//!
68//! ```rust,no_run
69//! // example-flat/build.rs
70//! prebindgen::init_prebindgen_out_dir();
71//! ```
72//!
73//! ### 2. C binding crate
74//!
75//! Depend on the common FFI library (as both a normal and a build dependency) and
76//! drive the `prebindgen-c` crate's `CbindgenBuilder` adapter from `build.rs`:
77//!
78//! ```rust,ignore
79//! // example-cbindgen/build.rs
80//! use syn::parse_quote as pq;
81//!
82//! fn main() {
83//!     let cbindgen = prebindgen_c::Cbindgen::builder()
84//!         .source(example_flat::PREBINDGEN_OUT_DIR)
85//!         .free_memory_function("example_free")
86//!         .mangle_type_name(|base| format!("{base}_t"))
87//!         .opaque_ptr(pq!(Calculator))
88//!         .function(pq!(calculator_new))
89//!         .function(pq!(calculator_get_value)).panic();
90//!
91//!     // Generate, then write the Rust file of `extern "C"` wrappers.
92//!     let bindings_file = cbindgen.build().unwrap().write_rust("example_flat.rs").unwrap();
93//!
94//!     // Pass the generated file to cbindgen for C header generation.
95//!     generate_c_headers(&bindings_file);
96//! }
97//! ```
98//!
99//! Include the generated Rust file in your crate to build the static or dynamic library:
100//!
101//! ```rust,ignore
102//! // lib.rs
103//! include!(concat!(env!("OUT_DIR"), "/example_flat.rs"));
104//! ```
