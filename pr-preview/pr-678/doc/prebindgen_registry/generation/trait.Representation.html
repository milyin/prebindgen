Expand description

Adapter-owned representation vocabulary stored by the shared plan.

Associated values describe semantics, never rendered source items. The registry compares niche identities and treats every other payload as opaque. A payload may retain target-language syntax owned by the adapter. Source Rust syntax remains forbidden until final emission spells an opaque TypeRef.
