One finished v2 generation run: what was planned, what was emitted, and the report that accounts for every declaration.

The run owns its whole pipeline — parsing, resolution, plans, emission and the report. It reads the same model and the same declarations v1 does and shares nothing else with it: no Registry, no fragment store, no resolver, no emitter. That independence is the point of #719, and a dependency edge is how it would be lost. crate::generate is the entry point; this is its result.
