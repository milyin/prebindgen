Struct Cbindgen

pub struct Cbindgen { /* private fields */ }
Expand description

Configure C bindings, using typed opaque pointers for foreign values.

Start with captured source via Self::builder and Self::source, or a flat model via Self::new. With captured source, declare each exported function. In either case, declare each opaque pointee type. Conversion declarations use prebindgen_declarations::Declarations. When reading captured source, add the source crate as both a build dependency and a normal dependency: generation reads its captures, and generated code calls its functions.

use prebindgen_c::{Bindings, Cbindgen};
use prebindgen_declarations::fun;
let source = syn::parse_file("pub fn add(a: i64, b: i64) -> i64 { a + b }")?;
let flat = Bindings::parse(
    source.items.into_iter().map(|item| (item, Default::default())),
)?;
let generated = Cbindgen::new(flat)
    .prefix("demo")
    .function(fun!(add))
    .build()?;
assert!(generated.header.contains("demo_add("));
syn::parse_file(&generated.rust)?;

Non-Result calls return their first boundary value directly and write any additional values through output pointers. Unit returns void. Fallible conversions require explicit Self::panic and abort on failure; source panics also abort. Destructors return void. Result calls report failures through their explicit error output. Each owned input transfers after its own validation and alias checks. Later failures do not restore consumed inputs. References borrow for the call and require the caller to obey Rust aliasing and lifetime rules. Result calls use an optional explicit error output, with owned messages or a declared error record. A success wire with an available niche is returned directly; otherwise the return is bool and success values use output pointers. Unit success needs no output pointer. Consuming Result calls additionally require a size_t ownership output counting consumed owned values in argument, row and field order, including on failure. Owned returned pointers, buffers and errors require their matching destructors. Direct reference returns of opaque types use non-owning pointers: const for shared references and mutable for exclusive references. Options use null for absence. Never destroy or consume these pointers; keep their source storage alive and at a stable address, respecting Rust’s aliasing rules. Mutable loans require exclusive access while in use. Getter expansions retain their existing ownership policy; mutable getter results remain unsupported.

pub fn source(self, path: impl AsRef<Path>) -> Self

Read captures from a source crate’s PREBINDGEN_OUT_DIR, passed as path.

Only declared functions, referenced constructors/getters and required types are selected. Automatic type discovery follows unqualified source names (see Flat::parse_selected). Types referenced only by qualified paths can be selected through Self::opaque_ptr using their unqualified names. Supply exactly one source directory or flat model.

Register a type-wide input or output expansion, built with expand_param! or expand_return!.

Per-function overrides replace this default; duplicate defaults are rejected by Self::build. Registration order does not affect type lookup.

pub fn error_mapper(self, ty: Type, mapper: impl Into<FunctionDecl>) -> Self

Select caller-owned C-string errors (char **error) for Result returns using ty, with a default source error-message mapper. The helper takes exactly E or &E and returns String. A function’s on_error(...) overrides this default. Duplicate resolved types are rejected.

Source

pub fn error(self, name: &str, ty: Type) -> Self

Deliver this declared record error by value through an optional C error output pointer. Its fields use ordinary output declarations. The source type must implement From<String> for binding failures.

Source

pub fn opaque_error(self, ty: Type, mapper: impl Into<FunctionDecl>) -> Self

Deliver an opaque source error as a caller-owned C string through char **error. The mapper takes E or &E and returns String.

pub fn function(self, decl: FunctionDecl) -> Self

Export a function and build its occurrence converters from declarations.

decl names the function, normally with fun!, and carries its overrides.

Function renaming is currently unsupported; exports use the symbol prefix and original source name.

Source

pub fn panic(self) -> Self

Allow binding conversion errors to abort the last declared non-Result function. Required for fallible conversions without a Result error channel. Result functions continue to report errors through their explicit output. Source panics always abort non-Result calls at the C boundary.

§Panics

Panics if no function has been declared.

pub fn new(flat: Bindings) -> Self

Start from a flat model with input and output conversion slots and prefix pb.

flat is the parsed source, with any converters already attached.

Attach converters with prebindgen_declarations::bind_input and prebindgen_declarations::bind_output with CCodec, or fill defaults with Self::function. Every fully bound function in the supplied model is exported.

Defaults to pb. The prefix is validated as an identifier during build.

pub fn opaque_ptr(self, name: &str, ty: Type) -> Self

Declare an opaque C pointee and its typed destructor for a source type.

Selects Box<T> storage for owned values in both directions, including built-in and vector types that otherwise have value/collection defaults. Named opaque types need an explicit pointer or inline-owner declaration. There is no Send requirement. This alone does not export constructors.

§Arguments
  • name — the C name, without the prefix: the header declares the type {prefix}_{name} and the destructor {prefix}_drop_{name}.
  • ty — the source type behind the pointer, as written in the source crate.

pub fn opaque_owned_struct( self, name: &str, ty: Type, layout: OpaqueLayout, ) -> Self

Declare an inline owning C value with generated target storage and drop. T::default() must be a valid, resource-free empty value: the C caller may discard it after a drop or consuming call. Use Self::opaque_owned_struct_with_empty when another empty factory is needed. Types without a resource-free empty state should use Self::opaque_ptr.

Source

pub fn opaque_owned_struct_with_empty( self, name: &str, ty: Type, layout: OpaqueLayout, empty: FunctionDecl, ) -> Self

Declare an inline owner whose empty value is produced by a nullary source function returning exactly this Rust type. The empty value must own no resources, because callers may discard it after destruction or consumption. This avoids a Default bound.

pub fn enum_type(self, name: &str, ty: Type) -> Self

Bind a fieldless source enum as a named int32_t C type and constants. Source integer discriminants are preserved and checked on input. Register the type explicitly; name is the unprefixed C typedef/constant prefix.

pub fn prepare(self) -> Result<Bindings>

Resolve declarations and converters into a complete Flat model.

Does not write files. Returns an error for conflicting sources, invalid or duplicate declarations, unsupported conversions, or missing opaque pointees. Rust layout/trait requirements are checked when the generated Rust compiles.
