What became of a declaration, and why.

Four outcomes, and they are not interchangeable. A capability v2 has not implemented is a Skipped declaration with a code and a path to the site that could not be lowered. Malformed input, a missing declared item, or a bug in the engine are errors — never skips — because a build that quietly reports its own bug as an unsupported feature is a build that cannot be trusted to say what it generated.
