4//! # prebindgen-tools
5//!
6//! Building blocks for a prebindgen **language adapter**. Applications that
7//! only want bindings use the `prebindgen-c` or `prebindgen-jni` adapter.
8//!
9//! An adapter writes *generated elements* — functions, types, constants —
10//! around the elements of the [`Flat`](prebindgen_flat::Flat) model, plus the
11//! foreign code that uses them. Every generated element speaks only in the
12//! adapter's **wire types**: a closed set, one enum per adapter
13//! ([`WireType`]). The tools here are what every adapter needs to get a
14//! source type onto wires and back.
15//!
16//! ## The model
17//!
18//! A value crosses in one of two directions:
19//!
20//! * an [`Input`] turns wires into a source value — for example a parameter
21//!   on its way into the source function;
22//! * an [`Output`] turns a source value into wires — for example a result on
23//!   its way back.
24//!
25//! Each holds the Rust expression that turns one into the other *and* a
26//! [`Form`]: a tree recording how each layer of the type crossed.
27//!
28//! A source type crosses in one of the ways below; its form records which,
29//! as a [`FormKind`].
30//! For each way, the table names the function that builds the [`Input`] and
31//! the one that builds the [`Output`]:
32//!
33//! | The value crosses… | [`Input`] | [`Output`] |
34//! |---|---|---|
35//! | as one wire | [`Input::wire`] | [`Output::wire`] |
36//! | converted to another source type, which crosses instead | [`Input::via`] | [`Output::via`] |
37//! | as a record's fields | [`Input::record`] | [`Output::record`] |
38//! | as an option's presence flag and value | [`Input::optional`] | [`Output::optional`] |
39//! | as a sum's tag and alternatives | [`Input::sum`] | [`Output::sum`] |
40//! | as a sequence | [`Input::seq`] | [`Output::seq`] |
41//! | as any other list of parts | [`Input::parts`] | [`Output::parts`] |
42//!
43//! Some take a description of the type: `record` takes the flat model's
44//! struct and `sum` its enum, while `via` takes the conversion the build
45//! script declared with `convert!`, resolved once into a
46//! [`ResolvedConversion`].
47//!
48//! The foreign-side writer walks the form, so it follows what the adapter
49//! decided for each layer without deciding again. What a single wire means
50//! is in the wire's own type.
51//!
52//! ## Writing an element
53//!
54//! 1. For each part of the element (parameter, result, field), take its
55//!    [`Place`]: where the part sits, such as parameter `p` of `send`, or
56//!    field `x` of that parameter. The place is not stored in the [`Input`]
57//!    or [`Output`]; the adapter passes it along while building them, to
58//!    look up decisions and to name wires ([`Place::ident`]).
59//! 2. Look up how the part crosses with [`Overrides::get`]: the override
60//!    the build script declared for that place, if any, else the default
61//!    for the part's type. [`shape()`] does the lookup layer by layer when
62//!    given it.
63//! 3. Build the part's [`Input`] or [`Output`] one layer at a time: match
64//!    the layer's [`Shape`], call the function the table above gives for
65//!    that way of crossing, and recurse into what the layer holds, extending
66//!    the place as it goes ([`Place::at`]).
67//! 4. Assemble the element from the parts' inputs and outputs, as the next
68//!    section shows.
69//!
70//! [`Qualifier`] names source items from the generated crate; [`RustFile`]
71//! collects and writes the generated Rust.
72//!
73//! ## Using an Input or Output
74//!
75//! An [`Input`] or [`Output`] holds everything the element needs for one
76//! value, on both sides of the boundary:
77//!
78//! * **The element's signature.** [`Input::wires`] and [`Output::wires`]
79//!   list the value's wires in order. [`Wire::decl`] writes one wire as
80//!   `name: Type` for a parameter list; [`WireType::rust`] gives its Rust
81//!   type alone, for a return type or a struct field.
82//! * **The Rust code.** An input's `expr` evaluates to the source value:
83//!   place it where the value is needed, such as an argument of the source
84//!   call. An output's `expr` evaluates to the wire values, one value or a
85//!   tuple in [`Output::wires`] order; [`Output::bind`] writes
86//!   `let <wires> = expr;`, so each wire becomes a local of its own name.
87//! * **Errors.** `fallible` says whether `expr` uses `?` on a
88//!   `Result<_, String>`. Place such an expression in a function returning
89//!   that type, or take [`Input::result`] / [`Output::result`], a `Result`
90//!   value, and route the error yourself.
91//! * **The foreign code.** `form` tells the foreign-side writer how to
92//!   produce the same wires (for an input) or read them (for an output), in
93//!   the same order. What a single wire means is in its [`WireType`]
94//!   variant; records, options, sums and sequences are their [`FormKind`].
95//!
96//! For example, a C-style wrapper for `pub fn twice(n: u64) -> u64`, where
97//! both values cross as an `i64` wire:
98//!
99//! ```
100//! use prebindgen::SourceLocation;
101//! use prebindgen_flat::Flat;
102//! use prebindgen_tools::{Input, Output, Place, Qualifier, Seg, Wire, WireType};
103//! use quote::quote;
104//!
105//! #[derive(Clone, Debug)]
106//! struct Long;
107//! impl WireType for Long {
108//!     fn rust(&self) -> proc_macro2::TokenStream { quote!(i64) }
109//!     fn placeholder(&self) -> proc_macro2::TokenStream { quote!(0) }
110//! }
111//!
112//! let source = syn::parse_file("pub fn twice(n: u64) -> u64 { n * 2 }").unwrap();
113//! let flat = Flat::builder()
114//!     .items(source.items.into_iter().map(|i| (i, SourceLocation::default())))
115//!     .build().unwrap();
116//! let f = flat.function("twice").unwrap();
117//! let element = Place::new("twice");
118//!
119//! // Build: one input for the parameter, one output for the result.
120//! let n = element.at(Seg::Param("n".into())).ident("");
121//! let input = Input::wire(&f.params[0].ty, Wire::new(n.clone(), Long), quote!(#n as u64));
122//! let ret = element.at(Seg::Return).ident("");
123//! let output = Output::wire(&f.ret, Wire::new(ret, Long), quote!(__value as i64));
124//!
125//! // Use: the wires give the signature, the expressions the body.
126//! let params = input.wires().iter().map(|w| w.decl()).collect::<Vec<_>>();
127//! let ret_ty = output.wires()[0].ty.rust();
128//! let callee = Qualifier::new(&flat).path(&f.name);
129//! let (arg, value) = (&input.expr, &output.expr);
130//! let wrapper = quote! {
131//!     pub extern "C" fn twice_wrapper(#(#params),*) -> #ret_ty {
132//!         let __value = #callee(#arg);
133//!         #value
134//!     }
135//! };
136//! let wrapper: syn::ItemFn = syn::parse2(wrapper).unwrap();
137//! assert_eq!(
138//!     quote!(#wrapper).to_string(),
139//!     quote! {
140//!         pub extern "C" fn twice_wrapper(n: i64) -> i64 {
141//!             let __value = twice(n as u64);
142//!             __value as i64
143//!         }
144//!     }.to_string(),
145//! );
146//! ```

157/// Custom conversions: a source type that crosses as another type.
158///
159/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
160/// says that `Millis` never crosses as itself: it crosses as `u64` — the
161/// **representation** — and these two functions convert.
162///
163/// Each direction is a function (a flat item, or a binding-local path with a
164/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
165/// `TryInto`). A function returning `Result` makes its direction fallible;
166/// the error is reported through its `Display`.
167///
168/// [`Conversion::resolve`] checks the declaration against the model; the
169/// adapter does it once, while planning, and keeps the
170/// [`ResolvedConversion`] as its declaration for the source type. When it
171/// builds a value of that type, it passes the conversion to [`Input::via`]
172/// or [`Output::via`], the same way [`Input::record`] takes the flat model's
173/// struct. The adapter builds the representation's [`Input`] or [`Output`]
174/// as for any other type, inside the closure it passes; the result's
175/// [`Form`] is [`FormKind::Via`] over the representation's form.
176pub mod convert {
177    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Via};
178}

206/// Naming source items from generated Rust code.
207///
208/// The flat model identifies a source item by its flat name, such as
209/// `Payload` or `make`. A binding's generated Rust usually lives in a
210/// different crate, where those names are not automatically in scope.
211/// [`Qualifier`] uses each item's source location to spell a path such as
212/// `source_crate::Payload` or `source_crate::make`. Use it when a wrapper
213/// calls a source function or a conversion names a source type.
214///
215/// ## Choosing a path
216///
217/// [`Qualifier::new`] borrows the model. For each known item,
218/// [`Qualifier::module_of`] reads the crate name recorded in its
219/// [`SourceLocation`](prebindgen::SourceLocation), converting hyphens to
220/// underscores for a Rust path. Items captured from different crates can
221/// therefore receive different prefixes from the same qualifier.
222///
223/// [`Qualifier::with_default_module`] supplies a fallback for **known items
224/// without a recorded crate name**, for example a model assembled directly
225/// from parsed syntax in a test. A recorded crate name takes precedence.
226/// A name absent from the model is left unchanged even when a fallback is
227/// configured; a known item with neither a crate name nor a fallback also
228/// keeps its bare name. The generated crate must be able to resolve the
229/// emitted paths: qualification does not add dependencies or imports, or
230/// discover Cargo dependency aliases.
231///
232/// ## Item paths and type expressions
233///
234/// * [`Qualifier::path`] qualifies one item name, such as the function the
235///   adapter will call.
236/// * [`Qualifier::ty`] walks a complete model type. For example,
237///   `Option<Vec<Payload>>` becomes
238///   `::core::option::Option<::std::vec::Vec<source_crate::Payload>>`.
239///   It qualifies named types inside generic arguments and containers, and
240///   named constants used as array lengths. Standard containers receive
241///   absolute `::core` or `::std` paths; scalar names such as `u32` stay as is.
242/// * [`Qualifier::ty_elided`] provides the same naming for positions such as
243///   closure arguments that cannot refer to a source lifetime parameter.
244///   Its method documentation lists which shapes it elides.
245///
246/// These methods return Rust tokens for the source value's type or path.
247/// The adapter still chooses the wire representation: qualifying
248/// `Payload` does not turn it into a pointer, handle, or mirror struct.
249///
250/// ```
251/// use prebindgen::SourceLocation;
252/// use prebindgen_flat::Flat;
253/// use prebindgen_tools::Qualifier;
254/// use quote::quote;
255///
256/// let source = syn::parse_file(
257///     "pub struct Payload; pub fn make() -> Option<Vec<Payload>> { None }",
258/// ).unwrap();
259/// let location = SourceLocation {
260///     crate_name: Some("source-crate".into()), ..Default::default()
261/// };
262/// let flat = Flat::builder()
263///     .items(source.items.into_iter().map(|item| (item, location.clone())))
264///     .build().unwrap();
265/// let q = Qualifier::new(&flat);
266/// let function = flat.function("make").unwrap();
267/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
268/// let expected: syn::Type = syn::parse_quote!(
269///     ::core::option::Option<::std::vec::Vec<source_crate::Payload>>
270/// );
271/// assert_eq!(syn::parse2::<syn::Type>(q.ty(&function.ret)).unwrap(), expected);
272///
273/// // The fallback does not override the recorded source crate.
274/// let q = q.with_default_module(Some(syn::parse_quote!(crate::source)));
275/// assert_eq!(q.path(&function.name).to_string(), quote!(source_crate::make).to_string());
276/// // A binding-local helper absent from the model stays unqualified.
277/// assert_eq!(q.path(&syn::parse_quote!(local_helper)).to_string(), "local_helper");
278/// ```
279pub mod qualify {
280    pub use crate::api::qualify::Qualifier;
281}

296/// One level of a type's structure, with any adapter declaration for that type.
297///
298/// An adapter builds a type's [`Input`] or [`Output`] by recursion: it looks
299/// at the outermost layer,
300/// decides what that layer becomes on its boundary, and recurses into what
301/// the layer holds. [`shape()`] answers the first question the same way for
302/// every adapter. It first asks the adapter whether the complete type has a
303/// declaration, then returns a built-in shape when it does not. Each adapter
304/// recurses with one `match` over [`Shape`].
305///
306/// For example, `shape(&payload_type, shape_declared)` returns
307/// [`Shape::Declared`] when the callback returns a declaration for `Payload`.
308/// For `Option<Payload>`, it returns [`Shape::Option`] when the callback has
309/// no declaration for the whole option; the adapter then calls [`shape()`]
310/// on its inner type.
311///
312/// A shape describes source structure; the adapter uses it to build an
313/// [`Input`] or [`Output`] for its chosen wire representation. An adapter
314/// can declare a type such as `Vec<u8>` as a whole, while an undeclared
315/// container exposes child types for further calls.
316/// [`Access`] describes by-value use or borrowing; [`SequenceKind`] and
317/// [`TextKind`] identify the source container independently of access.
318/// `Cow` remains an explicit wrapper around its inner type.
319///
320/// [`shape()`] documents declaration precedence, the handling of common
321/// borrows, and which unsupported forms return errors.
322/// A successful call only classifies the current layer: an adapter must
323/// still handle undeclared names and errors encountered in its children.
324///
325/// ```
326/// use prebindgen::SourceLocation;
327/// use prebindgen_flat::{Flat, flat::{TypeKind, TypeRef}};
328/// use prebindgen_tools::{shape, Access, Shape};
329/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
330/// let flat = Flat::builder()
331///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
332///     .build().unwrap();
333/// let ty = &flat.function("send").unwrap().params[0].ty;
334/// // The callback has no declaration for the whole Option.
335/// let Shape::Option(inner) = shape::<&str>(ty, |_| None)
336///     .unwrap() else { panic!("expected Option") };
337/// // The callback finds Payload inside the borrow; Declared retains &Payload.
338/// assert!(matches!(
339///     shape(inner, |candidate: &TypeRef| match candidate.kind() {
340///         TypeKind::Named { id, .. } if id.name == "Payload" => Some("handle"),
341///         _ => None,
342///     }).unwrap(),
343///     Shape::Declared { ty, declaration: "handle" }
344///         if std::ptr::eq(ty, inner) && Access::of(ty) == Access::Shared
345/// ));
346/// // Missing adapter configuration is a shape the adapter must handle.
347/// assert!(matches!(
348///     shape::<()>(inner, |_| None).unwrap(),
349///     Shape::Undeclared("Payload")
350/// ));
351/// ```
352pub mod shape {
353    pub use crate::api::shape::{shape, Access, SequenceKind, Shape, TextKind};
354}
