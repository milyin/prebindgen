fn getter( name: impl Into<String>, output: COutput<InRequest, OutRequest>, ) -> Self

Observe a value through a source getter and convert the getter’s result.

The getter takes &T for the current type T; adapters retaining a final output owner may also support &mut T. Its result uses the selected output conversion, including supported reference results.

fn combine( parts: impl IntoIterator<Item = COutput<InRequest, OutRequest>>, ) -> Self

Produce multiple outputs from one value.

parts holds one recipe per view of the value; their wires appear in this order. Binding rejects an empty list or more than one consuming part. The framework uses Codec::output_consumes to order observations before a move, unless Codec::output_owner first retains the final output allocation.
