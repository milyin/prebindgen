1//! What the engine asks a language adapter, and the shapes it answers in.
2//!
3//! Four planning questions — [`Target::select`], [`Target::represent`],
4//! [`Target::boundary`], [`Target::surface`] — plus one rendering call,
5//! [`Target::render_operation`]. Each planning answer is local: it describes
6//! *this* value, *this* call, *this* declaration. The recursion that visits a
7//! struct's fields, the locals, the branches and the wrapper around them all
8//! belong to the registry, which is why a nested struct costs an adapter
9//! nothing.
10//!
11//! Everything here is a **description**. Nothing an adapter returns is
12//! generated text except [`Target::render_operation`]'s single expression and
13//! the [`Artifact`]s it contributes whole.
14//!
15//! # The words the doc comments use
16//!
17//! - The **binding** is the crate a user builds and ships — `zenoh-flat-c`,
18//!   `zenoh-flat-jni` — whose `build.rs` declares what to expose. It is the
19//!   consumer of everything here.
20//! - The **target** is a language together with the calling interface it
21//!   reaches Rust through — C, or Kotlin through JNI — and, in code, the
22//!   adapter implementing [`Target`] for it. The same crate is the
23//!   **frontend** when it faces the binding's `build.rs`, and the target
24//!   adapter when it faces the registry.
25//! - The **registry** is this crate: it plans and asks; the target answers.
26//! - A **source function** is a Rust function in the source crate — the
27//!   `#[prebindgen]`-marked crate the captures come from — that the binding
28//!   asked to expose, with `fun!(ledger_open)` or the like. It is never
29//!   exported itself; it stays where it is and is called. An **exported
30//!   function**, or **wrapper**, is the Rust function the registry generates
31//!   around it: one the target's calling interface can reach, which converts
32//!   what arrives, calls the source function once, and converts what it
33//!   returns. The writer renders every wrapper as an `extern` function under a
34//!   `#[no_mangle]` symbol; what a target decides of its form is in
35//!   [`AbiSpec`] — the convention, the symbol, the signature, its attributes
36//!   and whether it is `unsafe`. A binding exports only wrappers.
37//! - The **wrapper boundary** is the form the wrapper is called through: its
38//!   calling convention, symbol, parameters and return. A **wrapper
39//!   parameter** is one of those parameters, spelled as a `jlong` or a
40//!   `*mut ledger_t`. Everything on the other side of that boundary — the
41//!   Kotlin function that calls the wrapper, the C prototype a caller
42//!   compiles against — is the **foreign** or **public** side.
43//!
44//! This is the first increment (docs/v2). What it carries is the scalar, the
45//! owned struct and the owned opaque handle; the fields the chapters describe
46//! for resources, validity and sequences arrive with the capabilities that need
47//! them, and `docs/v2/implementation.md` lists exactly what is absent.
48

145/// One field of a struct relation, or one argument of a constructor relation.
146#[derive(Clone, Debug)]
147pub struct Part {
148    /// The field's name, absent for a positional field.
149    pub name: Option<String>,
150    /// Its position in the relation, which is its identity when it has no name.
151    pub index: usize,
152    /// Its exact source type.
153    pub ty: TypeRef,
154    /// The `#[cfg]` conditions the source field was written under, which the
155    /// capture reader could not answer — empty in the ordinary case.
156    ///
157    /// A target re-declaring this part as a member of its own struct puts them
158    /// on that member. It must not read them: the registry puts the same
159    /// conditions on every instruction that serves this part, so a member
160    /// declared under them is read under them.
161    pub conditions: Vec<TokenStream>,
162}
163
164impl Part {
165    /// How a diagnostic and a policy lookup address this part.
166    pub fn label(&self) -> String {
167        match &self.name {
168            Some(name) => name.clone(),
169            None => self.index.to_string(),
170        }
171    }
172}

218/// A registered target/intermediate carrier type.
219///

260/// Where an operand's value comes from.
261///
262/// A runtime context — the JNI environment — is an operand like any other, so

273    Error,
274}

352/// An operation the registry itself knows how to render, so a target that
353/// needs one ships no renderer for it.
354///
355/// The three handle operations are here because they are Rust, not C or JNI:
356/// moving a source value onto the heap and back is the same for every target,
357/// and it is the one place a conversion has to spell a *source* type — which
358/// only the registry may do. What differs per target is the carrier the
359/// address is cast to, and that the target states.
360#[derive(Clone, Debug)]
361pub enum StandardOp {
362    /// The result *is* the operand: the carrier and the source value are one
363    /// Rust value. Renders nothing at all.
364    Identity,
365    /// Read a member of an aggregate carrier: `arg0.secs`.
366    ReadMember { member: syn::Member },
367    /// Hand an owned source value to the foreign side as an address:
368    /// `Box::into_raw(Box::new(v)) as <carrier>`. The foreign side owns the
369    /// allocation from here on.
370    IntoRaw { carrier: Box<syn::Type> },
371    /// Take back what [`StandardOp::IntoRaw`] handed out:
372    /// `*Box::from_raw(v as *mut <source>)`. A null address is a binding
373    /// failure carrying a `String`; the handle is consumed either way.
374    FromRaw { source: Box<TypeRef> },
375    /// Drop what [`StandardOp::IntoRaw`] handed out without converting it. A
376    /// null address releases nothing, as `free(NULL)` does. Produces no value.
377    Release { source: Box<TypeRef> },
378}
379
380/// What actually performs an operation.
381///
382/// This is the settled form of the chapters' open question about
383/// registry-supplied operations inside an adapter's payload: a payload is the
384/// adapter's own type, and the standard operations are a variant beside it
385/// rather than something an adapter has to encode.
386#[derive(Clone, Debug)]
387pub enum Operation<P> {
388    Standard(StandardOp),
389    Target(P),
390}
391
392/// One typed operation supplied by a target.
393///
394/// It describes an operation, not a use of one: it names no variable and
395/// belongs to no wrapper, so the same description is applied wherever the
396/// operation is needed.
397#[derive(Clone, Debug)]
398pub struct PrimitiveSpec<P> {
399    pub operands: Vec<OperandSpec>,
400    /// The value available after success, or nothing for an operation that
401    /// produces none.
402    pub result: Option<OperationType>,
403    pub failure: PrimitiveFailure,
404    /// Generated units this operation needs in order to compile.
405    pub dependencies: Vec<Artifact>,
406    pub implementation: Operation<P>,
407}
408
409impl<P> PrimitiveSpec<P> {
410    /// The conversion that renders nothing: the carrier already *is* the source
411    /// value.
412    pub fn identity(ty: OperationType) -> Self {
413        PrimitiveSpec {
414            operands: vec![OperandSpec::value(ty.clone(), Access::Owned)],
415            result: Some(ty),
416            failure: PrimitiveFailure::Infallible,
417            dependencies: Vec::new(),
418            implementation: Operation::Standard(StandardOp::Identity),
419        }
420    }
421
422    /// Hand an owned `source` value out as `carrier` — see
423    /// [`StandardOp::IntoRaw`]. Infallible.
424    pub fn into_raw(source: TypeRef, carrier: WireType) -> Self {
425        PrimitiveSpec {
426            operands: vec![OperandSpec::value(
427                OperationType::Source(source),
428                Access::Owned,
429            )],
430            result: Some(OperationType::Carrier(carrier.clone())),
431            failure: PrimitiveFailure::Infallible,
432            dependencies: Vec::new(),
433            implementation: Operation::Standard(StandardOp::IntoRaw {
434                carrier: Box::new(carrier.ty),
435            }),
436        }
437    }
438
439    /// Take an owned `source` value back from `carrier` — see
440    /// [`StandardOp::FromRaw`]. Fails with a `String` in the binding category
441    /// when the address is null, so a boundary passing handles needs a route
442    /// for that category.
443    pub fn from_raw(carrier: WireType, source: TypeRef) -> Self {
444        PrimitiveSpec {
445            operands: vec![OperandSpec::value(
446                OperationType::Carrier(carrier),
447                Access::Owned,
448            )],
449            result: Some(OperationType::Source(source.clone())),
450            failure: PrimitiveFailure::fallible(
451                OperationType::Carrier(WireType::internal(syn::parse_quote!(String))),
452                FailureCategory::Binding,
453            ),
454            dependencies: Vec::new(),
455            implementation: Operation::Standard(StandardOp::FromRaw {
456                source: Box::new(source),
457            }),
458        }
459    }
460
461    /// Drop a `source` value held behind `carrier` — see
462    /// [`StandardOp::Release`]. Infallible, produces nothing.
463    pub fn release(carrier: WireType, source: TypeRef) -> Self {
464        PrimitiveSpec {
465            operands: vec![OperandSpec::value(
466                OperationType::Carrier(carrier),
467                Access::Owned,
468            )],
469            result: None,
470            failure: PrimitiveFailure::Infallible,
471            dependencies: Vec::new(),
472            implementation: Operation::Standard(StandardOp::Release {
473                source: Box::new(source),
474            }),
475        }
476    }
477
478    /// How many operands this application takes from the enclosing conversion.
479    pub(crate) fn value_operands(&self) -> usize {
480        self.operands
481            .iter()
482            .filter(|operand| matches!(operand.role, OperandRole::Value))
483            .count()
484    }
485
486    /// Whether this application consumes the value it is given.
487    pub(crate) fn consumes_value(&self) -> bool {
488        self.operands.iter().any(|operand| {
489            matches!(operand.role, OperandRole::Value) && operand.access == Access::Owned
490        })
491    }
492
493    pub(crate) fn failure_category(&self) -> Option<FailureCategory> {
494        match &self.failure {
495            PrimitiveFailure::Infallible => None,
496            PrimitiveFailure::Fallible { category, .. } => Some(*category),
497        }
498    }
499}

608/// The boundary of one exported function: how the wrapper the
609/// registry generates around a source function is reached from the target's
610/// side.
611///
612/// The writer renders every wrapper as
613/// `#[no_mangle] <attrs> pub <unsafe> extern "<abi>" fn <symbol>(<params>) -> <ret>`,
614/// and everything in angle brackets is the target's to decide here. The
615/// `#[no_mangle]`, the `pub` and the `fn` are the writer's: a wrapper is
616/// reached by its symbol, and a target that needed another linkage would need
617/// a variant of this type rather than an attribute that fights the one the
618/// writer adds — which the registry refuses (see [`AbiSpec::attrs`]).
619///
620/// This is the specification's `AbiSpec<Payload>` with the payload made
621/// concrete: the "target signature requirements" the chapter leaves open are
622/// the attributes and the safety of the signature, because those are what the
623/// writer has to render and can check, and what V1's JNI wrapper —
624/// `#[allow(..)] pub unsafe extern "C"` — needs beyond the convention and
625/// the symbol.
626#[derive(Clone, Debug)]
627pub struct AbiSpec {
628    /// The `extern` string: `"C"`, `"system"`.
629    pub abi: String,
630    /// The symbol the wrapper is exported under, which the foreign side links
631    /// against. Not the source function's name: the frontend's naming settled
632    /// it.
633    pub symbol: String,
634    /// The wrapper's parameters, in boundary order — the ones serving a source
635    /// parameter and the ones the calling convention adds.
636    pub params: Vec<WrapperParam>,
637    /// The wrapper's return type, absent when it returns nothing.
638    pub ret: Option<WireType>,
639    /// Attributes the wrapper carries beyond `#[no_mangle]`, rendered after
640    /// it: a lint the generated signature would otherwise trip
641    /// (`#[allow(non_snake_case)]`), a target's own marker. Empty for both
642    /// targets today.
643    ///
644    /// Linkage is not the target's to restate: `#[no_mangle]` and
645    /// `#[export_name]` here are contradictory input and fail the build, since
646    /// the writer already exports the wrapper under [`AbiSpec::symbol`].
647    pub attrs: Vec<syn::Attribute>,
648    /// Whether the wrapper is an `unsafe fn`. `false` for both targets today:
649    /// the wrapper checks what it is handed, and a caller owes it nothing a
650    /// safe function cannot state. A convention that makes the caller
651    /// responsible for the pointers it passes says so here, and the foreign
652    /// declaration should say the same.
653    pub unsafety: bool,
654}

707/// A wrapper taking an aggregate is unusable unless the type it names is
708/// emitted too. A target states that with the type, not with the id of the
709/// declaration representing it: at [`Target::surface`] it holds the model's
710/// answer about a value, not the binding's declaration of a type, and the
711/// engine is the side that knows which declaration covers which type.
712#[derive(Clone, Debug, PartialEq, Eq)]
713pub struct Requirement {
714    type_name: String,
715}
716
717impl Requirement {
718    /// What `ty` requires, if it names a type at all — `None` for a scalar or
719    /// anything else with no declared type of its own.
720    pub fn of(ty: &TypeRef) -> Option<Self> {
721        match ty.kind() {
722            TypeKind::Named { id, .. } => Some(Requirement {
723                type_name: id.name.clone(),
724            }),
725            _ => None,
726        }
727    }
728
729    /// The same for a type the target knows by name without holding a
730    /// reference to it.
731    pub fn type_named(name: impl Into<String>) -> Self {
732        Requirement {
733            type_name: name.into(),
734        }
735    }
736
737    /// The type's name, as the model spells it.
738    pub fn type_name(&self) -> &str {
739        &self.type_name
740    }
741}
742
743impl std::fmt::Display for Requirement {
744    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
745        write!(f, "type `{}`", self.type_name)
746    }
747}

767/// Where a conversion sits, for policy lookup and for diagnostics.
768#[derive(Clone, Debug, PartialEq, Eq, Hash, PartialOrd, Ord)]
769pub struct Position {
770    /// The requested output this conversion is reached from.
771    pub declaration: DeclarationId,
772    /// Root to here: `param 0`, then `field secs`.
773    pub path: Vec<String>,
774}
775
776impl Position {
777    pub fn root(declaration: DeclarationId) -> Self {
778        Position {
779            declaration,
780            path: Vec::new(),
781        }
782    }
783
784    pub fn child(&self, step: impl Into<String>) -> Self {
785        let mut path = self.path.clone();
786        path.push(step.into());
787        Position {
788            declaration: self.declaration.clone(),
789            path,
790        }
791    }
792
793    /// This position as a report's dependency path.
794    pub fn dependency_path(&self) -> Vec<String> {
795        std::iter::once(self.declaration.to_string())
796            .chain(self.path.iter().cloned())
797            .collect()
798    }
799}

801/// What `select` is given: the value, the relations available for it, and the
802/// choices recorded for this position.
803pub struct SelectionQuery<'a, Policy> {
804    pub crossing: &'a Crossing,
805    pub position: &'a Position,
806    /// The relations registered for this type: the implicit one, plus any the
807    /// configuration declared. A target picks one; it does not invent one.
808    ///
809    /// There is one per type today, because every relation the increment has is
810    /// implicit. Pinning a relation against the target's choice arrives with the
811    /// second kind — a declared constructor — since with one candidate there is
812    /// nothing to pin.
813    pub candidates: &'a [(RelationId, Relation)],
814    pub policy: &'a Policy,
815}

817/// What `represent` is given: the selected relation, resolved against the
818/// model.
819///
820/// No position, deliberately. A representation is reused wherever a conversion
821/// with the same identity is needed, and that identity is the crossing, the
822/// relation, the effective policy and the children — a target that could answer
823/// differently for two positions would have its second answer silently
824/// bypassed. Varying by position is what a policy recorded at that position is
825/// for.
826pub struct ResolvedShape<'a> {
827    pub crossing: &'a Crossing,
828    pub relation: &'a Relation,
829    /// The struct behind a struct relation, for a target that renders its own
830    /// declaration of it.
831    pub strukt: Option<&'a Struct>,
832}

834/// One already-planned child, as its parent's representation sees it.
835pub struct ChildValue<'a> {
836    pub part: &'a Part,
837    pub layout: &'a Layout,
838}

840/// The planned conversions of one source function's parameters and result,
841/// as the boundary and the public declaration see them.
842///
843/// A wrapper is these conversions around one call: each input is converted
844/// from what the wrapper parameter carries, the source function is called,
845/// and its result is converted for delivery. What the target reads here is
846/// each plan's carrier — the layout a wrapper parameter or return must match —
847/// and the failure categories the boundary has to route.
848pub struct ResolvedValues<'a, P> {
849    /// One plan per source parameter, in [`Function::params`] order, each
850    /// crossing into Rust.
851    pub inputs: Vec<&'a crate::plan::ValuePlan<P>>,
852    /// The plan for the source function's result, crossing out of Rust, or
853    /// `None` when it returns nothing.
854    pub output: Option<&'a crate::plan::ValuePlan<P>>,
855}
856
857impl<P> ResolvedValues<'_, P> {
858    /// Every failure category the planned conversions can raise, sorted.
859    pub fn failure_categories(&self) -> Vec<FailureCategory> {
860        let mut categories: Vec<_> = self
861            .inputs
862            .iter()
863            .chain(self.output.iter())
864            .flat_map(|value| value.failures.iter().copied())
865            .collect();
866        categories.sort();
867        categories.dedup();
868        categories
869    }
870}

872/// The first argument of [`Target::boundary`]: which wrapper the call is about.
873///
874/// For every wrapper it builds, the registry calls
875/// `target.boundary(&site, &values, &policy)` once, and the target returns
876/// the wrapper's shape — symbol, calling convention, parameters,
877/// failure routes — as a [`BoundarySpec`], wrapped in [`TargetSupport`]: a
878/// spec, a reason the target cannot shape this one, or an error. `site` is
879/// this type and says which source function the wrapper exports: the
880/// declaration that requested the export, and the function itself. `values`
881/// is the [`ResolvedValues`] the wrapper converts, `policy` the binding's
882/// configuration for it.
883///
884/// What a target reads from the descriptor: the declaration, for the names in
885/// its refusals and errors; the source function's parameter list, for the
886/// names the wrapper signature keeps; and whether a source function is there
887/// at all. A descriptor with none says the wrapper is a handle's release —
888/// it takes the handle back and drops it (see [`ReprSpec::release`]) — which
889/// the target shapes under the handle *type's* policy rather than a
890/// function's.
891///
892/// Named after the specification's *site*, a value's position in an exported
893/// function: the boundary places each such position on a wrapper parameter or
894/// the return, and this identifies the function the positions belong to.
895pub struct SiteDescriptor<'a> {
896    /// The export this wrapper is for: its Rust origin
897    /// ([`Declaration::rust_origin`]) and the foreign name it was requested
898    /// under ([`Declaration::placement`]). For a release, the handle type's
899    /// own declaration. The exported symbol is not read from here; the
900    /// frontend settled it in the policy.
901    pub declaration: &'a Declaration,
902    /// The source function the wrapper calls once, or `None` for a release.
903    ///
904    /// The target reads its parameter *names*: a wrapper parameter keeps its
905    /// source parameter's name, and one the target adds — a JNI environment,
906    /// a receiver — is named around those. The parameter *types* come from
907    /// the plans in [`ResolvedValues::inputs`], which are in
908    /// [`Function::params`] order.
909    pub function: Option<&'a Function>,
910}

912/// What `surface` is given: the requested public declaration.
913pub struct SurfaceRequest<'a, Policy> {
914    pub declaration: &'a Declaration,
915    pub policy: &'a Policy,
916    pub item: SourceItem<'a>,
917}
918
919impl<Policy> SurfaceRequest<'_, Policy> {
920    /// The `#[cfg]` conditions the captured item behind this request was
921    /// written under, spelled as the source wrote them — empty in the ordinary
922    /// case.
923    ///
924    /// Text rather than tokens, because the registry is what puts a condition
925    /// on the Rust it emits for this declaration. What is left for a target is
926    /// the declaration written in *its* language, which usually cannot state a
927    /// condition at all; saying so in that declaration's documentation is the
928    /// most such a target can do, and is better than saying nothing.
929    pub fn item_conditions(&self) -> Vec<String> {
930        let conditions = match self.item {
931            SourceItem::Struct(strukt) => {
932                crate::emit::Writer.conditions(Conditioned::Struct(strukt))
933            }
934            SourceItem::Function(function) => {
935                crate::emit::Writer.conditions(Conditioned::Function(function))
936            }
937            SourceItem::Extern(opaque) => {
938                crate::emit::Writer.conditions(Conditioned::Extern(opaque))
939            }
940        };
941        conditions
942            .iter()
943            .map(|condition| prebindgen_flat::close_up(&condition.to_string()))
944            .collect()
945    }
946
947    /// The `#[cfg]` conditions of each field of the struct behind this request,
948    /// in field order — empty entries for the ordinary unconditional field, and
949    /// an empty list for a request that is not a struct.
950    ///
951    /// A target declaring a member per field puts its entry on that member. The
952    /// registry puts the same conditions on every instruction that serves the
953    /// field, so a member declared under them is read under them and the
954    /// initializer that consumes the read is written under them too.
955    ///
956    /// Tokens rather than text, unlike [`Self::item_conditions`]: these go into
957    /// the Rust a target contributes.
958    pub fn field_conditions(&self) -> Vec<Vec<TokenStream>> {
959        match self.item {
960            SourceItem::Struct(strukt) => strukt
961                .fields
962                .iter()
963                .map(|field| crate::emit::Writer.conditions(Conditioned::Field(field)))
964                .collect(),
965            SourceItem::Function(_) | SourceItem::Extern(_) => Vec::new(),
966        }
967    }
968}

970/// The captured item a public declaration is made from, as the source model
971/// describes it.
972///
973/// A binding asks for an output by name — a [`Declaration`] such as
974/// `type:Ledger` — and the registry resolves that name in the source model
975/// before it plans anything. This is what it found: the model's own element,
976/// borrowed from the [`Flat`] the run was planned over. A target receives it
977/// as [`SurfaceRequest::item`] when it answers [`Target::surface`].
978///
979/// It is a view over the model and carries nothing of its own. What it adds
980/// is shape: [`Element`] has variants no declaration can resolve to (a guard,
981/// an unsupported item) and nests the type kinds one level down, so a target
982/// matching on it would carry unreachable arms and a second match. This lists
983/// exactly the kinds a resolved declaration can be — a constant and the enums
984/// will add variants — so an adapter's `match` is exhaustive over real cases
985/// and the compiler says when a kind is added.
986///
987/// The variant is a fact about the source, not about the representation: a
988/// struct declared to C as an opaque pointer still arrives as
989/// [`SourceItem::Struct`], and how the target carries it is in
990/// [`SurfaceRequest::policy`]. Read the policy first. A declaration the
991/// binding defines itself ([`Origin::is_binding_local`]) names no captured
992/// item and is refused before `surface` is asked, so nothing here is ever
993/// absent.
994///
995/// [`Flat`]: prebindgen_flat::flat::Flat
996/// [`Element`]: prebindgen_flat::flat::Element
997/// [`Origin::is_binding_local`]: crate::decl::Origin::is_binding_local
998#[derive(Clone, Copy)]
999pub enum SourceItem<'a> {
1000    /// A captured free function, the item behind a `fn:` declaration.
1001    ///
1002    /// The target reads its signature — [`Function::params`] and
1003    /// [`Function::ret`] — to spell the foreign declaration, and pairs each
1004    /// parameter with the already-planned conversion the registry hands over
1005    /// in [`ResolvedValues::inputs`], in the same order. The call itself is
1006    /// not the target's business: the registry places it when it assembles
1007    /// the wrapper, from the [`SiteDescriptor`] it asked [`Target::boundary`]
1008    /// about.
1009    Function(&'a Function),
1010    /// A captured struct with fields the model can inspect, the usual item
1011    /// behind a `type:` declaration.
1012    ///
1013    /// A target declaring one — a `repr(C)` mirror, a Kotlin `data class` —
1014    /// re-declares its fields: [`Struct::fields`], with the `#[cfg]`
1015    /// condition of each in [`SurfaceRequest::field_conditions`]. A struct
1016    /// under a policy that carries it whole crosses as a handle instead, and
1017    /// its fields go unread; the target learns that from the policy, not from
1018    /// this variant. A tuple struct is not this variant at all: its fields
1019    /// are not modelled, and the model declares it as [`SourceItem::Extern`].
1020    Struct(&'a Struct),
1021    /// A captured declaration with nothing behind it — a marked type alias
1022    /// such as `pub type Ledger = crate::ledger::Ledger;`, or a tuple struct —
1023    /// which the source model calls an extern.
1024    ///
1025    /// It has no parts to convert through, so a value of it crosses whole: as
1026    /// an opaque handle, under a policy that names a carrier for the address
1027    /// and a release for it (see [`ReprSpec::release`]). [`Extern::target`]
1028    /// says what the alias pointed at, as text, for a target that wants to
1029    /// recognise one; the model does not classify it. A target with no handle
1030    /// representation refuses this variant, and a data policy on it finds no
1031    /// struct relation to select at all.
1032    Extern(&'a Extern),
1033}

1039/// The language adapter, as the engine sees it.
1040///
1041/// Every method answers a local question about one value, one call or one
1042/// declaration. None of them walks a type, allocates a name, or decides control
1043/// flow: those are the registry's, which is why a second field, a nested struct
1044/// or a third target costs an adapter nothing new.
1045pub trait Target {
1046    /// The choices the frontend recorded, in whatever shape this language's
1047    /// configuration takes. The engine carries it and hands it back.
1048    type Policy;
1049    /// The adapter's own rendering data, retained in the plans and read back by
1050    /// [`Target::render_operation`] and by the adapter's foreign writer.
1051    ///
1052    /// `Clone` because one described operation is applied wherever it is
1053    /// needed: the description is registered once per use site, and the
1054    /// alternative is an adapter allocating its own identities for the registry
1055    /// to trust.
1056    type Payload: Clone;
1057
1058    /// Choose the relation for this value from the ones available.
1059    fn select(&self, query: &SelectionQuery<'_, Self::Policy>) -> TargetSupport<RelationId>;
1060
1061    /// Describe what carries this value and how its parts are accessed.
1062    fn represent(
1063        &self,
1064        shape: &ResolvedShape<'_>,
1065        children: &[ChildValue<'_>],
1066        policy: &Self::Policy,
1067    ) -> TargetSupport<ReprSpec<Self::Payload>>;
1068
1069    /// Describe the wrapper that will export this source function: its
1070    /// interface, and its routes for the failures its conversions can raise.
1071    fn boundary(
1072        &self,
1073        site: &SiteDescriptor<'_>,
1074        values: &ResolvedValues<'_, Self::Payload>,
1075        policy: &Self::Policy,
1076    ) -> TargetSupport<BoundarySpec<Self::Payload>>;
1077
1078    /// Describe one public declaration and what it requires.
1079    fn surface(
1080        &self,
1081        request: &SurfaceRequest<'_, Self::Policy>,
1082        values: &ResolvedValues<'_, Self::Payload>,
1083    ) -> TargetSupport<SurfaceSpec<Self::Payload>>;
1084
1085    /// Render one of this target's operations as a single Rust expression.
1086    ///
1087    /// One expression and nothing around it: no `let`, no `match`, no return.
1088    /// The operands arrive already named by the writer, in the order the
1089    /// operation's specification lists them.
1090    fn render_operation(&self, payload: &Self::Payload, operands: &[syn::Ident]) -> TokenStream;
1091}
