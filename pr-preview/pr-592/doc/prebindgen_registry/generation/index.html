prebindgen_registry

Module generation 

Source
Expand description

Immutable, syntax-free plans shared by registry-driven generators.

Planning may retain an opaque TypeRef, but none of the types in this module can spell it. Adapter-owned associated types describe target representations and operations; the registry owns identity, composition, reachability, ordering, and the contracts that can be checked without Rust source syntax. Those opaque payloads may use syntax for types invented by the target adapter, such as a C wire type; they must not contain source Rust syntax obtained by spelling a TypeRef before final emission.
