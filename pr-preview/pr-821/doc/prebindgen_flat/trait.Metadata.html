Expand description

Metadata attached to the owners in a flat binding model.

A generator supplies one schema with independent payloads for module settings, functions, source types, fields and variants. Conversion occurrences retain their existing independent input/output slot types. The unit schema is useful for source-only inspection. Metadata does not contain a second declaration tree.
