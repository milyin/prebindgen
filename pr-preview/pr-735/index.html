prebindgen

Generate idiomatic multi-language FFI bindings (C, Kotlin/JNI, …) from a single annotated Rust source.

  • prebindgen Separate FFI implementation and language-specific binding into different crates
  • prebindgen-flat The prebindgen flat model: the parser from captured #[prebindgen] records to a flat namespace of elements
  • prebindgen-registry The language-agnostic binding pipeline for prebindgen: registry, type resolution and Rust emission
  • prebindgen-c Experimental C / cbindgen binding generator for prebindgen
  • prebindgen-jni JNI / Kotlin binding generator for prebindgen
  • prebindgen-proc-macro Procedural macros for prebindgen - export FFI definitions for binding generation
  • prebindgen-c-runtime Runtime traits implemented by prebindgen-generated C FFI counterpart types
  • prebindgen-jni-runtime Runtime support helpers called by prebindgen-generated JNI bindings
