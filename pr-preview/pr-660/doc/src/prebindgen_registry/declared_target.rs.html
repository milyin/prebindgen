1//! The one check every declarator owes: a declared function must be **about**
2//! the type it was declared for.
3//!
4//! Both expansion directions ask it — an input constructor must *produce* the
5//! parameter's target, an output accessor must *take* the deconstructor's
6//! source — and each used to carry its own private copy. Two copies is how the
7//! check went missing from a third declarator (prebindgen#223, the P2 from
8//! [#221](https://github.com/milyin/prebindgen/pull/221)): the policy lived in
9//! prose, so a new declarator started with zero checks and nothing noticed.
10//!
11//! **The comparison is shared here; being *asked* is enforced elsewhere.** A
12//! helper alone would not have prevented that defect — a new declarator could
13//! simply not call it. What prevents it is that the signature lookups
14//! (`expand::ctor_signature`, and an adapter's own accessor lookup) take the
15//! expected target as a **parameter** and run this
16//! check themselves. There is no way to obtain a declared function's signature
17//! without naming the type it must match, so the obligation is discharged by
18//! the compiler rather than by remembering.
19
20use crate::registry::TypeKey;
21
22/// A declared function that is not about its declared type.
23///
24/// Deliberately vocabulary-free: it names the two keys that disagreed and
25/// leaves the wording to whichever error type absorbs it, because the two
26/// directions say it differently — a constructor *produces*, an accessor
27/// *takes*. Those messages are the binding author's diagnostics and belong with
28/// their own error enum, not here.
29pub struct TargetMismatch {
30    /// The declared function's ident.
31    pub func: String,
32    /// The type it is actually about.
33    pub actual: String,
34    /// The type it was declared for.
35    pub expected: String,
36}
37
38/// The comparison itself: two [`TypeKey`]s, keyed so that spelling differences
39/// which do not change identity cannot make a correct declaration fail.
40pub fn check_declared_target(
41    func: &syn::Ident,
42    actual: &TypeKey,
43    expected: &TypeKey,
44) -> Result<(), TargetMismatch> {
45    if actual == expected {
46        Ok(())
47    } else {
48        Err(TargetMismatch {
49            func: func.to_string(),
50            actual: actual.to_string(),
51            expected: expected.to_string(),
52        })
53    }
54}
