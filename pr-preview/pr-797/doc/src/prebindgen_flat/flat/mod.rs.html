1//! The prebindgen **source language**: one parser from captured records to
2//! [`Element`]s.
3//!
4//! > Naming: `flat` is the *source* side — the flat API a
5//! > `#[prebindgen]` crate may write. The destination adapters (C, JNI) ship
6//! > as the separate `prebindgen-c` / `prebindgen-jni` crates. They are
7//! > opposite ends of the pipeline.
8//!
9//! ```text
10//! Source(s) ──items──> Flat ──Elements──> adapters
11//!   raw records          parse +               classify off `kind`
12//!   (syn::Item)          validate              spell with `spell()`
13//! ```
14//!
15//! [`FlatBuilder::source`] folds the first arrow in for the common case, so a build
16//! script names one directory and gets elements; [`FlatBuilder::items`] keeps the
17//! arrow itself, for a stream that needs shaping first.
18//!
19//! # What an element is
20//!
21//! Two things at once, and that pairing is the whole design:
22//!
23//! * a **closed model** — [`TypeKind`], the field list, which of the two enum
24//!   shapes an item is — where the type grammar is the accepted Rust syntax and
25//!   the element structure is the concept above it;
26//! * one [`Origin`], carrying the **exact syntax** the node was built from and
27//!   the source it arrived in.
28//!
29//! The `Origin` is uniform: every node has one, at every level — item,
30//! parameter, field, variant, type, array extent. Some levels know less than
31//! others (a field has no line of its own, so it shares its item's), but the
32//! shape does not change with the level, and no level copies a piece of
33//! provenance down from the one above. That copying is what previously let the
34//! same crate name appear under three field names with two meanings.
35//!
36//! So the rule for every consumer is:
37//!
38//! > **Classify off `kind`, spell with [`spell()`](Origin::spell).**
39//!
40//! And the model enforces it rather than asking. [`Origin`]'s syntax is
41//! private, and every route to it — `spell()`, `as_syn()` — is visible only
42//! inside this crate. Matching a `syn::Type` or `syn::Expr` variant outside
43//! this module is a classifier, and issue #211 says classification lives here
44//! alone; the visibility is what makes that hold rather than a convention
45//! anyone has to remember. Code whose job *is* producing Rust reaches the
46//! syntax through [`Emit`](crate::Emit).
47//!
48//! # What earns a variant
49//!
50//! For a **type**, a form something decides on. Two forms an adapter treats
51//! differently are two variants — `&str` and `String` rebuild differently, and
52//! C crosses `Option<Box<T>>` as a pointer — while spelling nobody decides on
53//! is left to the slice:
54//!
55//! | Rust writes | The model says |
56//! |---|---|
57//! | `String`, `str` | [`String`](TypeKind::String), [`Str`](TypeKind::Str) |
58//! | `Vec<T>`, `[T]` | [`Vec`](TypeKind::Vec), [`Slice`](TypeKind::Slice) |
59//! | `Box<T>`, `Cow<'_, T>` | [`Boxed`](TypeKind::Boxed), [`Cow`](TypeKind::Cow) |
60//! | `&mut MaybeUninit<T>` | [`Out`](TypeKind::Out) — an out-parameter slot |
61//! | `&'a T`, `Foo<'a, T>` | `Ref`, `Named` with its type arguments — no lifetime |
62//! | no `->`, `-> ()` | [`TypeKind::Unit`] |
63//! | `*const T` | *rejected* — a source crate is idiomatic Rust; the adapter owns pointers |
64//!
65//! An **element** is not a type, and there the rule is still the concept:
66//!
67//! | Rust writes | The model says | Because |
68//! |---|---|---|
69//! | `struct S;`, `struct S {}` | zero fields | the delimiters are spelling |
70//! | `enum E { A(u8) }` | [`Variant`] | a sum, identified by position |
71//! | `enum E { A = 7 }` | [`Enum`] | a named integer, identified by its value |
72//! | `type X = ..`, `struct X(..)` | [`Extern`] | named here; contents not modelled |
73//!
74//! The two enum shapes are the clearest case of a *concept* splitting where Rust
75//! has one spelling. Both are `enum` and both keep a `syn::ItemEnum`, but a sum's
76//! alternatives are identified by **position** — the mirror an adapter builds
77//! carries no `repr` and numbers its own arms — while a fieldless enum's members
78//! are identified by the **value Rust assigns**, which a C header re-states and a
79//! Kotlin `enum class` entry carries. Neither numbering means anything for the
80//! other shape, so one model covering both would carry a field that is dead in
81//! each direction, and worse than dead: Rust does assign a discriminant to a
82//! sum's alternatives, and using it would be wrong.
83//!
84//! The identities follow the same rule: a nominal type is a [`TypeId`] — a
85//! name — not a `syn::Path`, so nothing downstream has to take a path apart to
86//! learn what a type is. And a name is *all* it is: **a reference carries a
87//! name, the declaration carries the origin**, so the same type never compares
88//! unequal to itself because two source crates mentioned it. The one place a
89//! crate name rides with an identity is [`ConstId`], and that is the const's
90//! *declaring* crate, resolved by lookup — which is exactly what lets an array
91//! extent refuse a const from another source.
92//!
93//! # Why the syntax rides along
94//!
95//! The generated Rust glue is itself a destination artifact, and the only one
96//! that needs syntax fidelity: `B()` must not be re-spelled `B`, `= 0x07` must
97//! not become `= 7`. Carrying the source's own slice is how it gets that —
98//! exactly, and at no modelling cost, so a delimiter and a literal's base need
99//! never become fields.
100//!
101//! # Where acceptance is enforced
102//!
103//! Lowering is **total over the accepted grammar**: a form with no variant in
104//! [`TypeKind`] is a form the language does not accept, so there is no second
105//! acceptance list to drift from it. `MaybeUninit` is accepted only directly
106//! under a `&mut`, which [`Out`](TypeKind::Out) states as one form.
107//!
108//! **Parsing diagnoses; ingestion raises.** Those are two different points, and
109//! the split is what lets one model serve both.
110//!
111//! Parsing never fails on a single item: an item the language cannot express
112//! becomes [`Element::Unsupported`] carrying its diagnosis, and
113//! [`FlatBuilder::build`] returns the model with it in place. Only whole-stream
114//! rules — a duplicate name in the flat namespace — are [`ParseError`]s, because
115//! no declaration can make two items with one name unambiguous. So a consumer
116//! that wants to *inspect* what a source crate marked, refusals included, gets
117//! exactly that from [`Flat::unsupported`].
118//!
119//! An adapter is where the diagnoses are raised.
120//! Building a binding from this model **fails if any element is
121//! `Unsupported`** — all of them at once, so a source crate that needs migrating
122//! sees one list rather than one rebuild per item — and it fails before any
123//! adapter declaration is examined. A binding is built against a model the
124//! frontend could read in full, or it is not built.
125//!
126//! No **marked** item passes through verbatim, because a `#[prebindgen]` crate
127//! marks the items that cross the boundary and leaves the supporting code to the
128//! consumer. The proc-macro already enforces that — a `use`, `mod`, `impl` or
129//! `macro_rules!` cannot be marked at all — so the only item kind left that this
130//! module does not model is a `union`, and it is diagnosed like anything else the
131//! language cannot express.
132//!
133//! The one item that *is* re-emitted verbatim is a [`Guard`] — an anonymous
134//! const, which has no address and so cannot be part of an API addressed by name.
135//! Today these are the feature checks [`Source`](prebindgen::Source) injects on its own
136//! behalf. Modelled rather than dropped because this module must be total over
137//! what it is handed, and a separate element so nothing that consumes the API has
138//! to remember to skip it.
139//!
140//! # Declaring a handle
141//!
142//! `#[prebindgen] pub type X = path::To<Thing>;` declares an [`Extern`]: it gives
143//! a foreign or crate-private type a **name in the flat API** without claiming
144//! anything about its contents. That is what makes the API closable — a handle
145//! enters it deliberately rather than by being mentioned — and it is why a
146//! reference can be required to resolve. A marked tuple struct declares the same
147//! thing, since no adapter has ever crossed its fields.
148//!
149//! # Shapes that must be refused rather than approximated
150//!
151//! An [`Element`] holds what it holds: ordinary parameters, a direct return, no
152//! generic binder. A shape with no slot in that structure cannot be *partly*
153//! accepted — the missing piece would simply be dropped, and silently:
154//!
155//! | Shape | Would become | So |
156//! |---|---|---|
157//! | `async fn` | a function returning `()` | the future is dropped and the export's body never runs |
158//! | `fn f(a: u8, ...)` | a function without the tail | the variadic arguments vanish |
159//! | `struct S<T>`, `fn f<T>()`, `struct S<const N: usize>` | `T` as a nominal reference | a parameter is indistinguishable from an item named `T` |
160//!
161//! All three are [`ItemError`]s, carried like any other refusal and raised by
162//! the adapter. A
163//! **lifetime** binder is not among them: lifetimes are spelling, and the
164//! spelling already travels. Nor is `impl Trait` in argument position — Rust
165//! calls it an anonymous type parameter, but it is not a binder in the syntax,
166//! so the callback form is untouched.

204/// Collects what to parse, then hands over the model.
205///
206/// Carries no configuration about what the language *accepts* — that is a
207/// property of the language, not of the call site. What it carries is **what to
208/// parse**: feed the inputs, then [`build`](Self::build) once.
209///
210/// # Reading a source directory
211///
212/// A build script's whole job, in one expression — the
213/// [`Source`](prebindgen::Source) step included. Pass
214/// `<source_crate>::PREBINDGEN_OUT_DIR`:
215///
216/// ```
217/// # prebindgen::Source::init_doctest_simulate();
218/// use prebindgen_flat::Flat;
219///
220/// let flat = Flat::builder().source("source_ffi").build()?;
221/// assert!(flat.function("test_function").is_some());
222/// assert!(flat.declared_type("TestStruct").is_some());
223/// # Ok::<_, prebindgen_flat::flat::ParseError>(())
224/// ```
225///
226/// # Reading a stream
227///
228/// [`Self::items`] takes any `(syn::Item, SourceLocation)` iterator, so
229/// everything a [`Source`](prebindgen::Source) can express still composes — a group
230/// selection, a renamed dependency, several sources at once. The feeders
231/// accumulate, so mix them freely:
232///
233/// ```
234/// # prebindgen::Source::init_doctest_simulate();
235/// use prebindgen::Source;
236/// use prebindgen_flat::Flat;
237///
238/// // A dependency renamed in Cargo.toml needs the name THIS crate uses, so it
239/// // is configured rather than named by directory.
240/// let helpers = Source::builder("source_ffi").crate_name("helpers").build();
241/// let flat = Flat::builder()
242///     .items(helpers.items_in_groups(&["functions"]))
243///     .build()?;
244/// assert_eq!(flat.functions().count(), 1);
245/// # Ok::<_, prebindgen_flat::flat::ParseError>(())
246/// ```
247///
248/// # Why accumulate, rather than parse each input
249///
250/// The rules that make a parse fail are **whole-stream** rules: one flat
251/// namespace across every ingested crate, one const index an array length may
252/// reach into, one set of source modules to normalize paths against, and every
253/// type reference resolving against every declaration. None can be
254/// decided per input, so every input is in hand before any of it is classified.
255#[derive(Debug, Default, Clone)]
256pub struct FlatBuilder {
257    items: Vec<(syn::Item, SourceLocation)>,
258    default_module: Option<syn::Path>,
259}

261impl FlatBuilder {
262    /// Every `#[prebindgen]` item captured in `dir`.
263    ///
264    /// Sugar for [`Self::items`] over [`Source::items_all`](prebindgen::Source::items_all),
265    /// which is the whole of what a build script normally needs — pass
266    /// `<source_crate>::PREBINDGEN_OUT_DIR`. Reach for a
267    /// [`Source`](prebindgen::Source) directly, and feed it through [`Self::items`],
268    /// only when it needs configuring.
269    ///
270    /// Panics the way [`Source::new`](prebindgen::Source::new) does if `dir` is not
271    /// readable prebindgen output: a build script has nothing to recover with.
272    ///
273    /// ```
274    /// # prebindgen::Source::init_doctest_simulate();
275    /// use prebindgen_flat::Flat;
276    ///
277    /// let flat = Flat::builder().source("source_ffi").build()?;
278    /// assert!(flat.function("test_function").is_some());
279    /// assert!(flat.declared_type("TestStruct").is_some());
280    /// # Ok::<_, prebindgen_flat::flat::ParseError>(())
281    /// ```
282    pub fn source<P: AsRef<std::path::Path>>(self, dir: P) -> Self {
283        let source = prebindgen::Source::new(dir);
284        self.items(source.items_all())
285    }

287    /// The same, for a dependency this crate **renames** in `Cargo.toml`.
288    ///
289    /// The origin recorded at capture time is the dependency's real package name,
290    /// which will not resolve from a crate that refers to it by another name.
291    /// `crate_name` is the name *this* crate uses.
292    ///
293    /// Per directory, deliberately: an override on the whole parse could only fix
294    /// one module, and a flat API may layer several sources.
295    pub fn source_named<P: AsRef<std::path::Path>>(

297        dir: P,
298        crate_name: impl Into<String>,
299    ) -> Self {
300        let source = prebindgen::Source::builder(dir)
301            .crate_name(crate_name)
302            .build();
303        self.items(source.items_all())
304    }

306    /// The module generated code reaches an item by when its capture records
307    /// no crate — a stream fed through [`Self::items`] without a stamp. A
308    /// recorded crate, renamed or not, takes precedence. See [`ItemName`].
309    pub fn default_module(mut self, module: syn::Path) -> Self {
310        self.default_module = Some(module);
311        self
312    }

314    /// Add a captured item stream.
315    ///
316    /// The general feeder: any `(syn::Item, SourceLocation)` iterator, so
317    /// item-level selection and multi-source composition stay upstream where
318    /// they already are. Call it as often as needed; the streams accumulate.
319    ///
320    /// ```
321    /// # prebindgen::Source::init_doctest_simulate();
322    /// use prebindgen::Source;
323    /// use prebindgen_flat::Flat;
324    ///
325    /// let source = Source::new("source_ffi");
326    /// let flat = Flat::builder()
327    ///     .items(source.items_in_groups(&["structs"]))
328    ///     .build()?;
329    /// assert_eq!(flat.types().count(), 1);
330    /// # Ok::<_, prebindgen_flat::flat::ParseError>(())
331    /// ```
332    pub fn items<I>(mut self, items: I) -> Self
333    where
334        I: IntoIterator<Item = (syn::Item, SourceLocation)>,
335    {
336        self.items.extend(items);
337        self
338    }

340    /// Parse everything collected so far into the model.
341    ///
342    /// **Transactional**: an `Err` yields no model at all, so a refused stream
343    /// cannot leave a half-built one behind.
344    ///
345    /// Order-independent: source modules are gathered, consts indexed, and every
346    /// item lowered before any reference is resolved — so a type reference, an
347    /// array length and a cross-source mention may each name something declared
348    /// later, in this input or another.
349    pub fn build(self) -> Result<Flat, ParseError> {
350        let default_module = self.default_module;
351        let mut items = self.items;
352
353        // Pass 0: normalize every item's types to the canonical flat spelling
354        // before a single one is classified. `std::option::Option<T>` is an
355        // `Option`, `source_a::TypeA` is `TypeA`, and `zenoh::Session` is whatever
356        // an alias named it — decisions this module owns, so it must be the one to
357        // see the reduced form. Gathering EVERY module and alias first is what
358        // makes a reference in an earlier item normalize the same as in a later
359        // one.
360        //
361        // The consequence is deliberate and stated on `Origin`: a slice
362        // is the spelling generation must EMIT, which is the normalized one —
363        // the flat namespace is what the generated crate can actually name.
364        let normalization = crate::flat::spelling::Normalization::from_items(&items);
365        for (item, _) in &mut items {
366            crate::flat::spelling::normalize_item_types(item, &normalization);
367        }
368
369        // Pass 1: the consts an array length may name. Unnamed items are
370        // excluded because no length can name one — the same fact that makes
371        // them `Guard`s. This is the one place that tests the spelling rather
372        // than the classification, and it has to: it runs before Pass 2, so no
373        // classification exists yet.
374        let consts = ConstIndex::new(items.iter().filter_map(|(item, loc)| match item {
375            syn::Item::Const(c) if c.ident != "_" => Some((
376                c.ident.to_string(),
377                (*c.expr).clone(),
378                loc.crate_name.clone(),
379            )),
380            _ => None,
381        }));
382
383        // Pass 2: lower, checking the flat namespace as we go.
384        let mut elements: Vec<Element> = Vec::with_capacity(items.len());
385        let mut seen: Vec<(syn::Ident, SourceLocation)> = Vec::new();
386        for (item, loc) in items {
387            // The path generated code reaches the item by: its recorded crate,
388            // else the binding's default.
389            let module = match &loc.crate_name {
390                Some(c) => syn::parse_str::<syn::Path>(&c.replace('-', "_")).ok(),
391                None => default_module.clone(),
392            };
393            let mut element = lower_item(item, loc, &consts);
394            if let Some(name) = element.name_mut() {
395                name.place(module.as_ref());
396            }
397            if let Some(name) = element.name() {
398                if let Some((first_name, first)) = seen.iter().find(|(n, _)| name == n) {
399                    return Err(ParseError::DuplicateName(Box::new(DuplicateName {
400                        name: first_name.clone(),
401                        first: first.clone(),
402                        second: element.location().clone(),
403                        first_crate: first.crate_name.clone(),
404                        second_crate: element.location().crate_name.clone(),
405                    })));
406                }
407                seen.push((name.ident().clone(), element.location().clone()));
408            }
409            elements.push(element);
410        }
411
412        // Pass 3: resolve references, now that every declaration is in hand.
413        resolve_references(&mut elements);
414
415        // Indexed after resolution, because refusing an item can change its kind
416        // (a `Type` becomes `Unsupported`) though never its name.
417        let by_name = elements
418            .iter()
419            .enumerate()
420            .filter_map(|(i, e)| e.name().map(|n| (n.to_string(), i)))
421            .collect();
422        // Frozen here, from the captured stream alone. See the field's docs.
423        let mut source_modules: Vec<String> = Vec::new();
424        for element in &elements {
425            if let Some(crate_name) = element.location().crate_name.as_ref() {
426                let module = crate_name.replace('-', "_");
427                if !source_modules.contains(&module) {
428                    source_modules.push(module);
429                }
430            }
431        }
432        let mut flat = Flat {
433            elements,
434            by_name,
435            source_modules,
436            by_type: std::collections::HashMap::new(),
437        };
438        for i in 0..flat.elements.len() {
439            flat.index_types_of(i);
440        }
441        Ok(flat)
442    }
443}

445/// The flat API: every `#[prebindgen]` item from every ingested source, parsed,
446/// indexed by name, and with every type reference resolved.
447///
448/// # Direct access, not a stream
449///
450/// Names are unique across the whole model — a duplicate is a
451/// [`ParseError::DuplicateName`] — so a name is a complete address, and the
452/// model answers by it. That is what every later stage needs: an adapter asks
453/// what a declared name *is*, rather than scanning a list for it.
454///
455/// # References are already resolved
456///
457/// Every [`TypeKind::Named`] in a surviving element denotes a [`Type`] this model
458/// holds, and [`Self::resolve`] hands it over. An item that named something the
459/// flat API does not declare is [`Element::Unsupported`] with
460/// [`ItemError::UnresolvedType`], exactly like every other refusal — carried
461/// here, raised by the adapter.
462///
463/// Resolving here rather than in the adapters is the point of #211: a dangling
464/// name used to surface much later as an unresolved-converter error, from
465/// whichever adapter happened to look first.
466#[derive(Debug, Default)]
467pub struct Flat {
468    /// Source order, so iteration reports items as the sources were fed.
469    elements: Vec<Element>,
470    /// Module name of every **captured** source, in first-seen order (crate
471    /// names, dashes normalized to underscores). The first doubles as the
472    /// default module for a reference with no recorded origin.
473    ///
474    /// Computed once in [`FlatBuilder::build`] and frozen: it is a property of
475    /// the ingested stream, so a binding-local function added later must not
476    /// extend it — that would change which module an unqualified reference
477    /// resolves against.
478    source_modules: Vec<String>,
479    /// Name → position in [`Self::elements`].
480    ///
481    /// A map rather than a scan because every typed accessor and every
482    /// [`Self::resolve`] routes through it, and later stages resolve references
483    /// in a loop — a linear scan would make that quadratic in the size of the
484    /// API. Positions rather than clones, so there is one copy of each element
485    /// and source order stays available.
486    by_name: std::collections::HashMap<String, usize>,
487    /// Normalized type spelling → this module's reading of it.
488    ///
489    /// Every type the API **mentions** — a parameter, a return, a field, a
490    /// constant's type, and everything nested inside those — keyed so a consumer
491    /// holding a `syn::Type` can ask what the frontend made of it without
492    /// lowering it a second time.
493    ///
494    /// A type mentioned in several places keeps the **first mention in element
495    /// order**, a property of the model rather than of ingestion order.
496    ///
497    /// Unlike [`Self::source_modules`] this *is* extended by
498    /// [`Self::add_local_function`]: a binding-local fn's parameter types have
499    /// readings like any others, and a lookup that missed them would report
500    /// "no reading" for one that exists.
501    by_type: std::collections::HashMap<String, TypeRef>,
502}

504/// A name a lookup can be performed with.
505///
506/// Exists because callers hold different spellings of the same fact: an adapter
507/// walking captured items has a `syn::Ident`, a resolved reference has the
508/// `String` inside a [`TypeId`], and a test has a literal. One accessor takes all
509/// three rather than each call site converting.
510///
511/// **The conversion is moved, not removed.** `proc_macro2::Ident` hashes by
512/// `to_string()` and offers no borrow as `str`, so an `Ident` lookup allocates
513/// wherever it happens; doing it here keeps `&str` and `&String` callers — among
514/// them the per-edge and per-reference lookups in the scan and the resolver —
515/// allocation-free.
516///
517/// Sealed: what may name an element is the language's business, not a caller's.
518///
519/// ```
520/// # prebindgen::Source::init_doctest_simulate();
521/// use prebindgen_flat::flat::Flat;
522///
523/// let flat = Flat::builder().source("source_ffi").build()?;
524/// let ident = quote::format_ident!("test_function");
525///
526/// // The same element, whichever spelling the caller happens to hold.
527/// assert!(flat.function("test_function").is_some());
528/// assert!(flat.function(&ident).is_some());
529/// # Ok::<_, prebindgen_flat::flat::ParseError>(())
530/// ```
531pub trait Name: sealed::Sealed {
532    /// The name as a string, borrowed when the caller already holds one.
533    fn as_name(&self) -> std::borrow::Cow<'_, str>;
534}

709    /// the source said, and stays that way: [`Self::type_ref`]'s index means *every
710    /// type the API mentions*, so growing it with a spelling no source wrote would

838/// Turn every element that names an undeclared type into an
839/// [`Element::Unsupported`], **transitively**.
840///
841/// Runs once every declaration is in hand, so the order sources were fed in does
842/// not matter and a reference may point forward or across crates.
843///
844/// # Why this iterates
845///
846/// Refusing a type *removes a declaration*, which can strand its dependents:
847///
848/// ```ignore
849/// pub struct Broken { pub field: Missing }   // refused: `Missing` undeclared
850/// pub fn use_broken(value: Broken) {}        // `Broken` is now gone too
851/// ```
852///
853/// A single pass against a snapshot of the initial declarations would keep
854/// `use_broken`, and [`Flat::resolve`] would then return `None` for its parameter
855/// — breaking the invariant that a surviving element's references all resolve.
856/// So this runs to a fixed point: each round drops the declarations it refused,
857/// and stops when a round refuses nothing. Chains of any length collapse, in
858/// either declaration order, because the set only ever shrinks.
859fn resolve_references(elements: &mut [Element]) {
860    let mut declared: std::collections::HashSet<String> = elements
861        .iter()
862        .filter_map(|e| match e {
863            Element::Type(t) => Some(t.name().to_string()),
864            _ => None,
865        })
866        .collect();
867
868    loop {
869        let mut refused = Vec::new();
870        for (i, element) in elements.iter().enumerate() {
871            if let Some(unresolved) = first_unresolved(element, &declared) {
872                refused.push((i, unresolved));
873            }
874        }
875        if refused.is_empty() {
876            return;
877        }
878        for (i, unresolved) in refused {
879            // A refused type stops being a declaration, which is what lets the
880            // next round see its dependents as unresolved.
881            if let Element::Type(t) = &elements[i] {
882                declared.remove(&t.name().to_string());
883            }
884            let element = &mut elements[i];
885            let name = element.name().cloned();
886            let origin = Origin::new(
887                element.as_syn(),
888                Rc::clone(match element {
889                    Element::Function(f) => &f.origin.location,
890                    Element::Type(t) => t.location_rc(),
891                    Element::Constant(c) => &c.origin.location,
892                    Element::Guard(g) => &g.origin.location,
893                    Element::Unsupported(u) => &u.origin.location,
894                }),
895            );
896            *element = Element::Unsupported(Unsupported {
897                name,
898                error: Box::new(ItemError::UnresolvedType { name: unresolved }),
899                origin,
900            });
901        }
902    }
903}

905/// Every type slot this element writes, outermost only — a parameter, a return,
906/// a field, a constant's type.
907///
908/// The one place the slots are enumerated, so a new element shape is taught to
909/// every consumer at once instead of drifting between them.
910fn element_type_refs(element: &Element) -> Vec<&TypeRef> {
911    let mut refs: Vec<&TypeRef> = Vec::new();
912    match element {
913        Element::Function(f) => {
914            refs.extend(f.params.iter().map(|p| &p.ty));
915            refs.push(&f.ret);
916        }
917        Element::Constant(c) => refs.push(&c.ty),
918        Element::Type(Type::Struct(s)) => refs.extend(s.fields.iter().map(|f| &f.ty)),
919        Element::Type(Type::Variant(v)) => refs.extend(
920            v.alternatives
921                .iter()
922                .flat_map(|a| a.fields.iter().map(|f| &f.ty)),
923        ),
924        // An enum names nothing, an extern hides what it names, a guard is
925        // emitted verbatim so its types are the consumer's business, and an
926        // unsupported item already has a diagnosis worth keeping.
927        Element::Type(Type::Enum(_) | Type::Extern(_))
928        | Element::Guard(_)
929        | Element::Unsupported(_) => {}
930    }
931    refs
932}

944/// If `ty` is `impl Fn(T1, T2, ...) + Send + Sync + 'static`, return the `Fn`
945/// argument types in declaration order. Otherwise `None`.
946///
947/// A callback **returns nothing**, and that is checked, not assumed: a written
948/// `-> ()` is the same thing spelled out, and any other return is refused.
949/// [`TypeKind::Callback`] has no slot for one, so accepting `impl Fn() -> u8`
950/// would drop a fact a destination language needs — and drop it silently, which
951/// is worse than the refusal.
952///
953/// The callback grammar, and the language's alone: [`TypeKind::Callback`] is
954/// exactly what this accepts, so acceptance cannot drift from classification.
955pub fn extract_fn_trait_args(ty: &syn::Type) -> Option<Vec<syn::Type>> {
956    let syn::Type::ImplTrait(it) = ty else {
957        return None;
958    };
959    let mut args: Option<Vec<syn::Type>> = None;
960    let mut has_send = false;
961    let mut has_sync = false;
962    let mut has_static = false;
963    for bound in &it.bounds {
964        match bound {
965            syn::TypeParamBound::Trait(tb) => {
966                let last = tb.path.segments.last()?;
967                let name = last.ident.to_string();
968                match name.as_str() {
969                    "Fn" => {
970                        let syn::PathArguments::Parenthesized(p) = &last.arguments else {
971                            return None;
972                        };
973                        match &p.output {
974                            syn::ReturnType::Default => {}
975                            syn::ReturnType::Type(_, t) if ty::is_unit_type(t) => {}
976                            syn::ReturnType::Type(..) => return None,
977                        }
978                        args = Some(p.inputs.iter().cloned().collect());
979                    }
980                    "Send" => has_send = true,
981                    "Sync" => has_sync = true,
982                    _ => return None,
983                }
984            }
985            syn::TypeParamBound::Lifetime(lt) if lt.ident == "static" => has_static = true,
986            _ => return None,
987        }
988    }
989    if has_send && has_sync && has_static {
990        args
991    } else {
992        None
993    }
994}

1006/// The two items of a [`ParseError::DuplicateName`].

1011    pub second: SourceLocation,
1012    /// The crate each was marked in. A captured file path is crate-relative
1013    /// (both are `src/lib.rs`), so these are the only unambiguous coordinates

1028                    f,
1029                    "duplicate `#[prebindgen]` name `{}`: first at {}, again at {} — marked items \
1030                     share one flat namespace across all source crates",

1033                    at(&d.second, &d.second_crate)

1042/// Why one item could not be expressed in the language.
1043///
1044/// Carried by [`Element::Unsupported`] rather than raised at parse time: see
1045/// the [module docs](self) on where acceptance is enforced.
1046#[derive(Clone, Debug)]
1047pub enum ItemError {
1048    /// A `self` receiver. `#[prebindgen]` captures free functions only.
1049    UnsupportedReceiver,
1050    /// A parameter pattern that is not a plain name — `(a, b): (u8, u8)`.
1051    UnsupportedParamPattern { pattern: String },
1052    /// A parameter's type is not in the language.
1053    ParamType {
1054        param: syn::Ident,
1055        source: UnsupportedType,
1056    },
1057    /// A return type is not in the language.
1058    ReturnType { source: UnsupportedType },
1059    /// A named struct field's type is not in the language.
1060    FieldType {
1061        field: syn::Ident,
1062        source: UnsupportedType,
1063    },
1064    /// A variant payload's type is not in the language.
1065    VariantFieldType {
1066        variant: syn::Ident,
1067        /// The field's name, or its position for a tuple variant.
1068        field: String,
1069        source: UnsupportedType,
1070    },
1071    /// A const's type is not in the language.
1072    ConstType { source: UnsupportedType },
1073    /// An `async fn`.
1074    ///
1075    /// The most dangerous shape to accept quietly: [`Function`] has a direct
1076    /// return, so an `async fn ping()` lowers as one returning `()`, and a
1077    /// generated wrapper calls it, drops the future and exports a function whose
1078    /// body never runs.
1079    UnsupportedAsync,
1080    /// A C-variadic tail — `fn f(a: u8, ...)`.
1081    ///
1082    /// [`Function`] holds ordinary parameters only, so the tail would simply be
1083    /// dropped from the signature.
1084    UnsupportedVariadic,
1085    /// A type or const generic parameter on the item.
1086    ///
1087    /// The elements have no generic binder, so a `T` in a field or parameter
1088    /// would lower as [`TypeKind::Named`] — an ordinary nominal reference into
1089    /// the flat namespace, indistinguishable from a real item called `T`. That
1090    /// loses the scoping every downstream resolver needs, and no destination
1091    /// language can express an uninstantiated parameter anyway.
1092    ///
1093    /// A lifetime parameter is *not* this: lifetimes are spelling and already
1094    /// travel in the syntax.
1095    UnsupportedGenericParam {
1096        param: String,
1097        /// `a type parameter` / `a const generic parameter`.
1098        kind: &'static str,
1099    },
1100    /// The item names a type the flat API does not declare.
1101    ///
1102    /// The flat API is closed over its own names: a handle enters it through
1103    /// `#[prebindgen] pub type X = ..`, so a name with no declaration is either a
1104    /// missing marker or a typo. Reporting it here replaces discovering it much
1105    /// later as an unresolved converter, from whichever adapter looked first.
1106    UnresolvedType { name: String },
1107    /// A whole item kind the language does not model — a `union`, a type alias.
1108    ///
1109    /// The proc-macro refuses to mark a `use`, `mod`, `impl` or `macro_rules!`
1110    /// at all, so only the kinds it accepts can reach here.
1111    UnsupportedItemKind { kind: &'static str },
1112}

1150                "declares `{param}`, {kind}: the prebindgen source language has no generic \
1151                 binder, so an uninstantiated parameter is indistinguishable from a nominal type \
1152                 of the same name and no destination language can express it — write the \
1153                 concrete types, one marked item per instantiation (a newtype is the usual way)"
1154            ),
1155            ItemError::UnresolvedType { name } if name.contains("::") => write!(
1156                f,
1157                "names the type `{name}`, which the flat API does not declare \u{2014} and being \
1158                 path-qualified it never could, because marked items live in one flat namespace \
1159                 of bare names. Give the type a name here with `#[prebindgen] pub type <Name> = \
1160                 {name};` and refer to that"
1161            ),
1162            ItemError::UnresolvedType { name } => write!(
1163                f,
1164                "names the type `{name}`, which the flat API does not declare \u{2014} mark its \
1165                 declaration `#[prebindgen]`, or, for a foreign or crate-private type used as a \
1166                 handle, give it a name here with `#[prebindgen] pub type {name} = ..;`"
1167            ),
1168            ItemError::UnsupportedItemKind { kind } => write!(
1169                f,
1170                "is {kind}; the prebindgen source language models functions, structs, enums and \
1171                 consts — everything else belongs in the consumer crate"
1172            ),
1173        }
1174    }
1175}

1179/// Lower one captured item. Total: every item becomes an element, and an item
1180/// whose contents the language cannot express becomes [`Element::Unsupported`]
1181/// rather than failing the parse.
1182fn lower_item(item: syn::Item, loc: SourceLocation, consts: &ConstIndex) -> Element {
1183    // One captured record is one item, so this is allocated once and shared by
1184    // the item and every node lowered out of it.
1185    let at = Rc::new(loc);
1186    match item {
1187        syn::Item::Fn(f) => match lower_fn(&f, &at, consts) {
1188            Ok(func) => Element::Function(func),
1189            Err(error) => unsupported(f.sig.ident.clone(), syn::Item::Fn(f), &at, error),
1190        },
1191        syn::Item::Struct(s) => match lower_struct(&s, &at, consts) {
1192            Ok(ty) => Element::Type(ty),
1193            Err(error) => unsupported(s.ident.clone(), syn::Item::Struct(s), &at, error),
1194        },
1195        syn::Item::Enum(e) => match lower_enum(&e, &at, consts) {
1196            Ok(ty) => Element::Type(ty),
1197            Err(error) => unsupported(e.ident.clone(), syn::Item::Enum(e), &at, error),
1198        },
1199        // `#[prebindgen] pub type X = path;` DECLARES an opaque type: it gives a
1200        // foreign or crate-private type a name in the flat API, without claiming
1201        // anything about its contents. That is the only way a handle enters the
1202        // API deliberately, and the reason references can be required to resolve.
1203        syn::Item::Type(t) => match reject_generic_params(&t.generics) {
1204            // `Extern` has no binder and no arity, so a generic alias would be
1205            // accepted as one declaration that `Handle<u8>` then resolves against
1206            // — losing exactly the scoped-parameter distinction every other item
1207            // kind refuses. It is also why `MaybeUninit` needed grammar support
1208            // rather than an alias.
1209            Err(error) => unsupported(t.ident.clone(), syn::Item::Type(t), &at, error),
1210            Ok(()) => {
1211                let target = Some(t.ty.to_token_stream().to_string());
1212                Element::Type(Type::Extern(Extern {
1213                    name: ItemName::bare(t.ident.clone()),
1214                    target,
1215                    origin: Origin::new(syn::Item::Type(t), at),
1216                }))
1217            }
1218        },
1219        // An unnamed const is a `Guard`, not a constant: nothing can name it, so
1220        // it is not part of the API, and several sources' guards coexist because
1221        // none of them has an address to collide on.
1222        syn::Item::Const(c) if c.ident == "_" => Element::Guard(Guard {
1223            origin: Origin::new(c, at),
1224        }),
1225        syn::Item::Const(c) => match lower_type(&c.ty, consts, &at) {
1226            Ok(ty) => Element::Constant(Constant {
1227                name: ItemName::bare(c.ident.clone()),
1228                ty,
1229                origin: Origin::new(c, at),
1230            }),
1231            Err(source) => unsupported(
1232                c.ident.clone(),
1233                syn::Item::Const(c),
1234                &at,
1235                ItemError::ConstType { source },
1236            ),
1237        },
1238        // An item kind the language does not model. The proc-macro accepts only
1239        // six kinds and the five above cover the rest, so in practice this is a
1240        // `union` — never written by any source crate. It is diagnosed rather
1241        // than carried: a `#[prebindgen]` crate marks what crosses the boundary,
1242        // and the code around that belongs to the consumer.
1243        other => {
1244            let (name, kind) = match &other {
1245                syn::Item::Union(u) => (Some(u.ident.clone()), "a union"),
1246                _ => (None, "an item kind"),
1247            };
1248            unsupported(name, other, &at, ItemError::UnsupportedItemKind { kind })
1249        }
1250    }
1251}

1253fn unsupported(
1254    name: impl Into<Option<syn::Ident>>,
1255    syntax: syn::Item,
1256    at: &Rc<SourceLocation>,
1257    error: ItemError,
1258) -> Element {
1259    Element::Unsupported(Unsupported {
1260        name: name.into().map(ItemName::bare),
1261        error: Box::new(error),
1262        origin: Origin::new(syntax, Rc::clone(at)),
1263    })

1266/// Refuse a type or const generic parameter, naming the first one found.
1267///
1268/// Lifetimes pass: they say nothing a destination language can act on, and the
1269/// spelling that needs them is already in the syntax — the same call
1270/// [`lower_type`] makes for a lifetime *argument*.
1271fn reject_generic_params(generics: &syn::Generics) -> Result<(), ItemError> {
1272    for param in &generics.params {
1273        let (name, kind) = match param {
1274            syn::GenericParam::Lifetime(_) => continue,
1275            syn::GenericParam::Type(t) => (t.ident.to_string(), "a type parameter"),
1276            syn::GenericParam::Const(c) => (c.ident.to_string(), "a const generic parameter"),
1277        };
1278        return Err(ItemError::UnsupportedGenericParam { param: name, kind });
1279    }
1280    Ok(())
1281}

1283fn lower_fn(
1284    f: &syn::ItemFn,
1285    at: &Rc<SourceLocation>,
1286    consts: &ConstIndex,
1287) -> Result<Function, ItemError> {
1288    // Shapes `Function` has no slot for, and would therefore drop in silence.
1289    if f.sig.asyncness.is_some() {
1290        return Err(ItemError::UnsupportedAsync);
1291    }
1292    if f.sig.variadic.is_some() {
1293        return Err(ItemError::UnsupportedVariadic);
1294    }
1295    reject_generic_params(&f.sig.generics)?;
1296    let mut params = Vec::with_capacity(f.sig.inputs.len());
1297    for input in &f.sig.inputs {
1298        let pt = match input {
1299            syn::FnArg::Receiver(_) => return Err(ItemError::UnsupportedReceiver),
1300            syn::FnArg::Typed(pt) => pt,
1301        };
1302        let syn::Pat::Ident(pat) = &*pt.pat else {
1303            return Err(ItemError::UnsupportedParamPattern {
1304                pattern: pt.pat.to_token_stream().to_string(),
1305            });
1306        };
1307        let name = pat.ident.clone();
1308        let ty = lower_type(&pt.ty, consts, at).map_err(|source| ItemError::ParamType {
1309            param: name.clone(),
1310            source,
1311        })?;
1312        params.push(Param {
1313            name,
1314            ty,
1315            origin: Origin::new(pt.clone(), Rc::clone(at)),
1316        });
1317    }
1318    // An elided return and a written `-> ()` are the same function. The model
1319    // says so once, here, instead of leaving every consumer to normalize one to
1320    // the other — which is what they all do today, in eight separate copies.
1321    let ret = match &f.sig.output {
1322        syn::ReturnType::Default => TypeRef {
1323            kind: TypeKind::Unit,
1324            origin: Origin::new(syn::parse_quote!(()), Rc::clone(at)),
1325        },
1326        syn::ReturnType::Type(_, t) => {
1327            lower_type(t, consts, at).map_err(|source| ItemError::ReturnType { source })?
1328        }
1329    };
1330    Ok(Function {
1331        name: ItemName::bare(f.sig.ident.clone()),
1332        params,
1333        ret,
1334        origin: Origin::new(f.clone(), Rc::clone(at)),
1335    })
1336}

1338/// Lower a `struct` item to whichever of the two shapes it is.
1339///
1340/// A **tuple struct** is an [`Extern`]: no adapter has ever crossed its fields,
1341/// so they are deliberately not lowered and a field type outside the grammar is
1342/// not an error. Anything else is a product of fields that do cross.
1343fn lower_struct(
1344    s: &syn::ItemStruct,
1345    at: &Rc<SourceLocation>,
1346    consts: &ConstIndex,
1347) -> Result<Type, ItemError> {
1348    reject_generic_params(&s.generics)?;
1349    let fields = match &s.fields {
1350        syn::Fields::Named(named) => {
1351            let mut out = Vec::with_capacity(named.named.len());
1352            for (index, f) in named.named.iter().enumerate() {
1353                let name = f.ident.clone().expect("named fields have idents");
1354                let ty = lower_type(&f.ty, consts, at).map_err(|source| ItemError::FieldType {
1355                    field: name.clone(),
1356                    source,
1357                })?;
1358                out.push(Field {
1359                    name: Some(name),
1360                    index,
1361                    ty,
1362                    origin: Origin::new(f.clone(), Rc::clone(at)),
1363                });
1364            }
1365            out
1366        }
1367        // Its contents are not a boundary surface, so nothing is lowered.
1368        syn::Fields::Unnamed(_) => {
1369            return Ok(Type::Extern(Extern {
1370                name: ItemName::bare(s.ident.clone()),
1371                // A tuple struct IS the definition; it points at nothing.
1372                target: None,
1373                origin: Origin::new(syn::Item::Struct(s.clone()), Rc::clone(at)),
1374            }));
1375        }
1376        syn::Fields::Unit => Vec::new(),
1377    };
1378    Ok(Type::Struct(Struct {
1379        reading: TypeRef::named(&s.ident),
1380        name: ItemName::bare(s.ident.clone()),
1381        fields,
1382        origin: Origin::new(s.clone(), Rc::clone(at)),
1383    }))
1384}

1386/// Lower an `enum` item to whichever of the two shapes it is.
1387///
1388/// **The classification**: any alternative with a field makes it a [`Variant`] —
1389/// a sum, numbered by position. Otherwise it is an [`Enum`] — a named set of
1390/// integers, identified by the value Rust assigns. Both are spelled `enum` in
1391/// Rust and both keep the `syn::ItemEnum`; only what a destination language can
1392/// do with them differs, and that is what the model records.
1393///
1394/// `enum E {}` has no alternative carrying anything, so it is the degenerate
1395/// `Enum`.
1396fn lower_enum(
1397    e: &syn::ItemEnum,
1398    at: &Rc<SourceLocation>,
1399    consts: &ConstIndex,
1400) -> Result<Type, ItemError> {
1401    reject_generic_params(&e.generics)?;
1402
1403    if e.variants.iter().any(|v| !v.fields.is_empty()) {
1404        return Ok(Type::Variant(lower_variant(e, at, consts)?));
1405    }
1406    Ok(Type::Enum(lower_c_enum(e, at)))
1407}

1409/// The payload-carrying shape. Position is the only numbering a sum has, so no
1410/// discriminant is evaluated: the mirror an adapter builds numbers its own arms.
1411fn lower_variant(
1412    e: &syn::ItemEnum,
1413    at: &Rc<SourceLocation>,
1414    consts: &ConstIndex,
1415) -> Result<Variant, ItemError> {
1416    let mut alternatives = Vec::with_capacity(e.variants.len());
1417    for (index, v) in e.variants.iter().enumerate() {
1418        let mut fields = Vec::with_capacity(v.fields.len());
1419        for (field_index, f) in v.fields.iter().enumerate() {
1420            let ty =
1421                lower_type(&f.ty, consts, at).map_err(|source| ItemError::VariantFieldType {
1422                    variant: v.ident.clone(),
1423                    field: match &f.ident {
1424                        Some(id) => id.to_string(),
1425                        None => field_index.to_string(),
1426                    },
1427                    source,
1428                })?;
1429            fields.push(Field {
1430                name: f.ident.clone(),
1431                index: field_index,
1432                ty,
1433                origin: Origin::new(f.clone(), Rc::clone(at)),
1434            });
1435        }
1436        alternatives.push(Alternative {
1437            name: v.ident.clone(),
1438            index,
1439            fields,
1440            origin: Origin::new(v.clone(), Rc::clone(at)),
1441        });
1442    }
1443    Ok(Variant {
1444        reading: TypeRef::named(&e.ident),
1445        name: ItemName::bare(e.ident.clone()),
1446        alternatives,
1447        origin: Origin::new(e.clone(), Rc::clone(at)),
1448    })
1449}

1451/// The fieldless shape. Nothing here can fail to lower — there are no field
1452/// types — so an unevaluable discriminant ends the numeric chain rather than
1453/// refusing the item.
1454fn lower_c_enum(e: &syn::ItemEnum, at: &Rc<SourceLocation>) -> Enum {
1455    let mut values = Vec::with_capacity(e.variants.len());
1456    // Rust's own numbering rule: an explicit `= N` sets the value, an implicit
1457    // one takes the previous plus one, starting at 0.
1458    let mut next: Option<i64> = Some(0);
1459    for (index, v) in e.variants.iter().enumerate() {
1460        let discriminant = match v.discriminant.as_ref() {
1461            Some((_, expr)) => int_literal(expr),
1462            None => next,
1463        };
1464        // `checked_add`: a discriminant at the top of the range is valid Rust
1465        // (`#[repr(u64)] enum E { A = i64::MAX as u64, B }`), so running out of
1466        // `i64` ends the numeric chain exactly as an unevaluable spelling does.
1467        // The spelling is untouched either way — it is in `EnumValue::origin`.
1468        next = discriminant.and_then(|n| n.checked_add(1));
1469
1470        values.push(EnumValue {
1471            name: v.ident.clone(),
1472            index,
1473            discriminant,
1474            origin: Origin::new(v.clone(), Rc::clone(at)),
1475        });
1476    }
1477    Enum {
1478        reading: TypeRef::named(&e.ident),
1479        name: ItemName::bare(e.ident.clone()),
1480        values,
1481        origin: Origin::new(e.clone(), Rc::clone(at)),
1482    }
1483}

1485/// Pull a signed integer out of a literal expression (`5`, `-3`, `0x07`).
1486/// `None` for anything else — a `const`, a path, arithmetic.
1487fn int_literal(expr: &syn::Expr) -> Option<i64> {
1488    i64::try_from(int_literal_wide(expr)?).ok()
1489}
1490
1491/// [`int_literal`] before the range check.
1492///
1493/// The magnitude is parsed **wider than the result** so the sign can be applied
1494/// first: `-9223372036854775808` is `i64::MIN` and a valid Rust discriminant,
1495/// but its magnitude is one past `i64::MAX`, so parsing the digits as `i64`
1496/// would reject the whole literal. A magnitude too large for `i128` fails here
1497/// and is reported as an unevaluable discriminant, which is the existing
1498/// contract for anything the frontend cannot reduce to a number.
1499fn int_literal_wide(expr: &syn::Expr) -> Option<i128> {
1500    match expr {
1501        syn::Expr::Lit(lit) => match &lit.lit {
1502            syn::Lit::Int(int) => int.base10_parse::<i128>().ok(),
1503            _ => None,
1504        },
1505        syn::Expr::Unary(syn::ExprUnary {
1506            op: syn::UnOp::Neg(_),
1507            expr,
1508            ..
1509        }) => int_literal_wide(expr).map(|v| -v),
1510        _ => None,
1511    }
