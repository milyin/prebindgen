4//! # prebindgen-tools
5//!
6//! Building blocks for a prebindgen **language adapter**. Applications that
7//! only want bindings use the `prebindgen-c` or `prebindgen-jni` adapter.
8//!
9//! An adapter writes *generated elements* — functions, types, constants —
10//! around the elements of the [`Flat`](prebindgen_flat::Flat) model, plus the
11//! foreign code that uses them. Values cross between the two on **wires**:
12//! the parameters, return values and fields of the generated elements. Wire
13//! types form a closed set, one enum per adapter ([`WireType`]). The tools
14//! here are what every adapter needs to get a source type onto wires and
15//! back.
16//!
17//! ## The model
18//!
19//! A value crosses in one of two directions:
20//!
21//! * an [`Input`] turns wires into a source value — for example a parameter
22//!   on its way into the source function;
23//! * an [`Output`] turns a source value into wires — for example a result on
24//!   its way back.
25//!
26//! Each holds the Rust expression that turns one into the other *and* a
27//! [`Form`]: a tree recording how each layer of the type crossed.
28//!
29//! A source type crosses in one of the ways below; its form records which,
30//! as a [`FormKind`].
31//! For each way, the table names the function that builds the [`Input`] and
32//! the one that builds the [`Output`]:
33//!
34//! | The value crosses… | [`Input`] | [`Output`] |
35//! |---|---|---|
36//! | as one wire | [`Input::wire`] | [`Output::wire`] |
37//! | converted to another source type, which crosses instead | [`Input::via`] | [`Output::via`] |
38//! | as a record's fields | [`Input::record`] | [`Output::record`] |
39//! | as an option's presence flag and value | [`Input::optional`] | [`Output::optional`] |
40//! | as a sum's tag and alternatives | [`Input::sum`] | [`Output::sum`] |
41//! | as a sequence | [`Input::seq`] | [`Output::seq`] |
42//! | as any other list of parts | [`Input::parts`] | [`Output::parts`] |
43//!
44//! Some take a description of the type: `record` takes the flat model's
45//! struct and `sum` its enum, while `via` takes the conversion the build
46//! script declared with `convert!`, resolved once into a
47//! [`ResolvedConversion`].
48//!
49//! The foreign-side writer walks the form, so it follows what the adapter
50//! decided for each layer without deciding again. What a single wire means
51//! is in the wire's own type.
52//!
53//! ## Using an Input or Output
54//!
55//! An [`Input`] or [`Output`] holds everything the element needs for one
56//! value, on both sides of the boundary:
57//!
58//! * **The element's signature.** [`Input::wires`] and [`Output::wires`]
59//!   list the value's wires in order. [`Wire::decl`] writes one wire as
60//!   `name: Type` for a parameter list; [`WireType::rust`] gives its Rust
61//!   type alone, for a return type or a struct field.
62//! * **The Rust code.** An input's `expr` evaluates to the source value:
63//!   place it where the value is needed, such as an argument of the source
64//!   call. An output converts a value the template hands it:
65//!   [`Output::apply`] evaluates to the wire values, one value or a tuple in
66//!   [`Output::wires`] order, and [`Output::bind`] writes
67//!   `let <wires> = …;`, so each wire becomes a local of its own name.
68//! * **Errors.** `fallible` says whether the conversion uses `?` on a
69//!   `Result<_, String>`. Place such an expression in a function returning
70//!   that type, or take [`Input::result`] / [`Output::result`], a `Result`
71//!   value, and route the error yourself.
72//! * **The foreign code.** `form` tells the foreign-side writer how to
73//!   produce the same wires (for an input) or read them (for an output), in
74//!   the same order. What a single wire means is in its [`WireType`]
75//!   variant; records, options, sums and sequences are their [`FormKind`].
76//!
77//! For example, a C-style wrapper for `pub fn twice(n: u64) -> u64`, where
78//! both values cross as an `i64` wire:
79//!
80//! ```
81//! use prebindgen::SourceLocation;
82//! use prebindgen_flat::Flat;
83//! use prebindgen_tools::{Input, Output, Wire, WireType};
84//! use quote::{format_ident, quote};
85//!
86//! #[derive(Clone, Debug)]
87//! struct Long;
88//! impl WireType for Long {
89//!     fn rust(&self) -> proc_macro2::TokenStream { quote!(i64) }
90//!     fn placeholder(&self) -> proc_macro2::TokenStream { quote!(0) }
91//! }
92//!
93//! // `twice`, captured from the crate `source_crate`.
94//! let source = syn::parse_file("pub fn twice(n: u64) -> u64 { n * 2 }").unwrap();
95//! let location = SourceLocation { crate_name: Some("source_crate".into()), ..Default::default() };
96//! let flat = Flat::builder()
97//!     .items(source.items.into_iter().map(|i| (i, location.clone())))
98//!     .build().unwrap();
99//! let f = flat.function("twice").unwrap();
100//!
101//! // Build: one input for the parameter, on a wire named like it, and one
102//! // output for the result, on a wire named `ret`.
103//! let n = &f.params[0];
104//! let n_name = &n.name;
105//! let input = Input::wire(&n.ty, Wire::new(n_name.clone(), Long), quote!(#n_name as u64));
106//! let output = Output::wire(&f.ret, Wire::new(format_ident!("ret"), Long), |v| quote!(#v as i64));
107//!
108//! // Use: the wires give the signature; the input gives the argument, and
109//! // the output converts the call's result.
110//! let params = input.wires().iter().map(|w| w.decl()).collect::<Vec<_>>();
111//! let ret_ty = output.wires()[0].ty.rust();
112//! // The source function's name: spliced, the qualified path to call; its
113//! // bare identifier, the base for the wrapper's own name.
114//! let callee = &f.name;
115//! let wrapper_name = format_ident!("{}_wrapper", f.name.ident());
116//! let arg = &input.expr;
117//! let result = output.apply(quote!(#callee(#arg)));
118//! let wrapper = quote! {
119//!     pub extern "C" fn #wrapper_name(#(#params),*) -> #ret_ty { #result }
120//! };
121//! let wrapper: syn::ItemFn = syn::parse2(wrapper).unwrap();
122//! assert_eq!(
123//!     quote!(#wrapper).to_string(),
124//!     quote! {
125//!         pub extern "C" fn twice_wrapper(n: i64) -> i64 {
126//!             { let __v = source_crate::twice(n as u64); __v as i64 }
127//!         }
128//!     }.to_string(),
129//! );
130//! ```
131//!
132//! An output can be composed of others. Here `sample` returns a struct, and
133//! [`Output::record`] takes it apart. The struct's fields have different
134//! types, so the closure building each field's output asks [`shape()`] what
135//! the field is and chooses its wire and conversion: an `i64` for the `u64`,
136//! the `f64` as is, a `u8` for the `bool`. Applied to the call, the record
137//! output binds the result once, destructures it, and applies each field's
138//! output to its binding; the wrapper returns the wires as a tuple:
139//!
140//! ```
141//! use prebindgen::SourceLocation;
142//! use prebindgen_flat::{flat::{ScalarKind, Type}, Flat};
143//! use prebindgen_tools::{shape, Input, Output, Shape, Wire, WireType};
144//! use quote::{format_ident, quote};
145//!
146//! // The wire types this example's boundary uses.
147//! #[derive(Clone, Debug)]
148//! enum W { Long, Double, Flag }
149//! impl WireType for W {
150//!     fn rust(&self) -> proc_macro2::TokenStream {
151//!         match self { W::Long => quote!(i64), W::Double => quote!(f64), W::Flag => quote!(u8) }
152//!     }
153//!     fn placeholder(&self) -> proc_macro2::TokenStream { quote!(0) }
154//! }
155//!
156//! let source = syn::parse_file(
157//!     "pub struct Sample { pub id: u64, pub value: f64, pub ok: bool } \
158//!      pub fn sample(n: u64) -> Sample { Sample { id: n, value: n as f64 / 2.0, ok: n > 0 } }",
159//! ).unwrap();
160//! let location = SourceLocation { crate_name: Some("source_crate".into()), ..Default::default() };
161//! let flat = Flat::builder()
162//!     .items(source.items.into_iter().map(|i| (i, location.clone())))
163//!     .build().unwrap();
164//! let f = flat.function("sample").unwrap();
165//! let Some(Type::Struct(sample)) = flat.declared_type("Sample") else { panic!("a struct") };
166//!
167//! // Build: the parameter's input, and the result's record output. Each
168//! // field leaves on a wire named like it, of the type its own type needs.
169//! let n = &f.params[0];
170//! let n_name = &n.name;
171//! let input = Input::wire(&n.ty, Wire::new(n_name.clone(), W::Long), quote!(#n_name as u64));
172//! let output = Output::record(sample, |field| {
173//!     let name = field.name.clone().expect("a named field");
174//!     let wire = |w: W| Wire::new(name.clone(), w);
175//!     Ok(match shape(&field.ty, |_| None::<()>) {
176//!         Shape::Scalar(ScalarKind::U64) => {
177//!             Output::wire(&field.ty, wire(W::Long), |v| quote!(#v as i64))
178//!         }
179//!         Shape::Scalar(ScalarKind::F64) => Output::wire(&field.ty, wire(W::Double), |v| quote!(#v)),
180//!         Shape::Scalar(ScalarKind::Bool) => {
181//!             Output::wire(&field.ty, wire(W::Flag), |v| quote!(#v as u8))
182//!         }
183//!         other => return Err(format!("`{}`: no wire for {other:?}", field.ty)),
184//!     })
185//! }).unwrap();
186//!
187//! // Use: the output's wires give the return type, its conversion of the
188//! // call's result the body.
189//! let params = input.wires().iter().map(|w| w.decl()).collect::<Vec<_>>();
190//! let ret_tys = output.wires().iter().map(|w| w.ty.rust()).collect::<Vec<_>>();
191//! let callee = &f.name;
192//! let wrapper_name = format_ident!("{}_wrapper", f.name.ident());
193//! let arg = &input.expr;
194//! let result = output.apply(quote!(#callee(#arg)));
195//! let wrapper = quote! {
196//!     pub fn #wrapper_name(#(#params),*) -> (#(#ret_tys),*) { #result }
197//! };
198//! let wrapper: syn::ItemFn = syn::parse2(wrapper).unwrap();
199//! assert_eq!(
200//!     quote!(#wrapper).to_string(),
201//!     quote! {
202//!         pub fn sample_wrapper(n: i64) -> (i64, f64, u8) {
203//!             {
204//!                 let __v = source_crate::sample(n as u64);
205//!                 {
206//!                     let source_crate::Sample { id: __f0, value: __f1, ok: __f2 } = __v;
207//!                     let id = { let __v = __f0; __v as i64 };
208//!                     let value = { let __v = __f1; __v };
209//!                     let ok = { let __v = __f2; __v as u8 };
210//!                     (id, value, ok)
211//!                 }
212//!             }
213//!         }
214//!     }.to_string(),
215//! );
216//! ```
217//!
218//! ## Deciding how each layer crosses
219//!
220//! The example decided by itself that a `u64` crosses as one wire. A real
221//! adapter decides per type, following the build script's declarations, and
222//! a type such as `Option<Point>` needs one decision per layer: the
223//! `Option`, then the `Point`, then each of its fields.
224//!
225//! So the adapter builds an input or output by recursion over the type.
226//! [`shape()`] reads the outermost layer as a [`Shape`] — a scalar, an
227//! `Option`, a borrow, a type the adapter declared, and so on. The adapter
228//! calls the function the table above gives for that layer, and recurses
229//! into what the layer holds.
230//!
231//! The adapter keeps its declarations in [`Overrides`]: a default for each
232//! type, and the replacements the build script declared for single places.
233//! A [`Place`] names where a part sits in the element, such as parameter
234//! `p` of `send`, or field `x` of that parameter. The adapter starts from
235//! the place of each parameter or result and extends it as it recurses
236//! ([`Place::at`]). At each layer it asks [`Overrides::get`] with the
237//! current place and type — passing that lookup to [`shape()`] does it —
238//! and names the layer's wires after the place ([`Place::ident`]). The place
239//! only steers the building; it is not stored in the [`Input`] or
240//! [`Output`].
241//!
242//! ## Other tools
243//!
244//! Generated code names a source item by its
245//! [`ItemName`](prebindgen_flat::flat::ItemName), which the flat model
246//! qualifies when it is built: splicing a function's `name` writes
247//! `source_crate::make`. A whole source type is never spelled by the adapter,
248//! except through [`callback_arg_types`]. [`RustFile`] collects and writes the
249//! generated Rust.

260/// Custom conversions: a source type that crosses as another type.
261///
262/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
263/// says that `Millis` never crosses as itself: it crosses as `u64` — the
264/// **representation** — and these two functions convert.
265///
266/// Each direction is a function (a flat item, or a binding-local path with a
267/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
268/// `TryInto`). A function returning `Result` makes its direction fallible;
269/// the error is reported through its `Display`.
270///
271/// [`Conversion::resolve`] checks the declaration against the model; the
272/// adapter does it once, while planning, and keeps the
273/// [`ResolvedConversion`] as its declaration for the source type. When it
274/// builds a value of that type, it passes the conversion to [`Input::via`]
275/// or [`Output::via`], the same way [`Input::record`] takes the flat model's
276/// struct. The adapter builds the representation's [`Input`] or [`Output`]
277/// as for any other type, inside the closure it passes; the result's
278/// [`Form`] is [`FormKind::Via`] over the representation's form.
279pub mod convert {
280    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Via};
281}

351/// One level of a type's structure, with any adapter declaration for that type.
352///
353/// An adapter builds a type's [`Input`] or [`Output`] by recursion: it looks
354/// at the outermost layer,
355/// decides what that layer becomes on its boundary, and recurses into what
356/// the layer holds. [`shape()`] answers the first question the same way for
357/// every adapter. It first asks the adapter whether the complete type has a
358/// declaration, then returns a built-in shape when it does not. Each adapter
359/// recurses with one `match` over [`Shape`].
360///
361/// For example, `shape(&payload_type, shape_declared)` returns
362/// [`Shape::Declared`] when the callback returns a declaration for `Payload`.
363/// For `Option<Payload>`, it returns [`Shape::Option`] when the callback has
364/// no declaration for the whole option; the adapter then calls [`shape()`]
365/// on its inner type.
366///
367/// A shape describes source structure; the adapter uses it to build an
368/// [`Input`] or [`Output`] for its chosen wire representation. An adapter
369/// can declare a type such as `Vec<u8>` as a whole, while an undeclared
370/// container exposes child types for further calls.
371/// [`Access`] describes by-value use or borrowing; [`SequenceKind`] and
372/// [`TextKind`] identify the source container independently of access.
373/// `Cow` remains an explicit wrapper around its inner type.
374///
375/// [`shape()`] documents declaration precedence, the handling of common
376/// borrows, and which unsupported forms return errors.
377/// A successful call only classifies the current layer: an adapter must
378/// still handle undeclared names and errors encountered in its children.
379///
380/// ```
381/// use prebindgen::SourceLocation;
382/// use prebindgen_flat::{Flat, flat::{TypeKind, TypeRef}};
383/// use prebindgen_tools::{shape, Access, Shape};
384/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
385/// let flat = Flat::builder()
386///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
387///     .build().unwrap();
388/// let ty = &flat.function("send").unwrap().params[0].ty;
389/// // The callback has no declaration for the whole Option.
390/// let Shape::Option(inner) = shape::<&str>(ty, |_| None) else {
391///     panic!("expected Option")
392/// };
393/// // The callback finds Payload inside the borrow; Declared retains &Payload.
394/// assert!(matches!(
395///     shape(inner, |candidate: &TypeRef| match candidate.kind() {
396///         TypeKind::Named { id, .. } if id.name == "Payload" => Some("handle"),
397///         _ => None,
398///     }),
399///     Shape::Declared { ty, declaration: "handle" }
400///         if std::ptr::eq(ty, inner) && Access::of(ty) == Access::Shared
401/// ));
402/// // Missing adapter configuration is a shape the adapter must handle.
403/// assert!(matches!(
404///     shape::<()>(inner, |_| None),
405///     Shape::Undeclared("Payload")
406/// ));
407/// ```
408pub mod shape {
409    pub use crate::api::shape::{shape, Access, SequenceKind, Shape, TextKind};
410}
