Where a build script writes what an engine generated, when it must not write to the paths another engine owns.

<manifest_dir>/build/prebindgen/<pipeline>, emptied first: a file the previous run wrote and this one did not must not survive into the compile, which is what makes a shrinking capability set visible instead of stale.

V1 keeps writing the committed source-tree artifacts it always has, so it never calls this; the directory is named after the pipeline anyway, so two engines can never land in one root.
