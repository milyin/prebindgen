CheckAliases

Include this parameter in a call-wide alias check during generation. The standard plan returns (); emit check.emit() after validation and before acknowledgement/acquisition. Custom conversions may also return additional runtime checks as a unit expression.

Fields

§context: &'a C

§check: &'a mut ParameterAliasCheck

Checks shared by all parameters of this call.

§

CheckInternalAliases

Check aliases within an isolated input conversion, such as a callback result. Uses the same fixed/dynamic strategy as the call-wide check, without other parameters. A single address or shared-only accesses need no bookkeeping.
