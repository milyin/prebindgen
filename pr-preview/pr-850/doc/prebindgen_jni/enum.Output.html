Expand description

Resolved operations for converting a source result into boundary outputs. Preparation uses Output<OutputRequest>; plain Output permits no pending requests. Declarations::resolve_output resolves requests against source declarations and defaults. Use Output::into_preparation to embed an explicit subtree in preparation; source-dependent normalization still applies.

use prebindgen_declarations::{Output,OutputRequest};
let resolved: Output = Output::Optional(Box::new(Output::Leaf));
let preparation: Output<OutputRequest> = resolved.into_preparation();

Pending requests cannot be embedded inside a resolved output:

ⓘ
use prebindgen_declarations::{Output,OutputRequest};
let resolved: Output = Output::Optional(Box::new(Output::Request(OutputRequest::Auto)));

Fields observes fields; OwnedFields moves them. Explicit Projected leaves select borrowed or owned conversion independently of type contents.

Explicit source-field conversions in declaration order.

§mode: Option<ProjectionMode>

None follows the occurrence: move owned fields and observe borrowed fields. Some explicitly selects and checks a projection policy.

§

Sequence

Convert collection elements using ordinary or explicitly selected ownership.

Fields

§delivery: SequenceDelivery

Delivery selected before conversion compilation.

§element: Box<Output<P>>

Element conversion, interpreted independently for each item.

§mode: Option<ProjectionMode>

None follows the occurrence’s ownership: move owned values and observe borrowed values. Some explicitly selects and checks a projection policy.

§

Result

Deliver Ok through its recipe and route an owned Err through the codec. An optional mapper takes exactly E or &E and returns String. Without one, the codec must explicitly support preserving the error value. The codec selects how that message reaches the destination’s error channel.

Fields

§ok: Box<Output<P>>

Conversion of the owned success value.

§error: Option<String>

Optional unqualified source message mapper. Without one, the codec must explicitly support the source error value itself.

§

Optional(Box<Output<P>>)

Convert an optional payload without preparing absent values.

§

Leaf

Convert the occurrence type itself with Codec::output_leaf, or Codec::output_return_reference for a direct reference return.

§

Fields(Vec<Output<P>>)

Observe named fields in declaration order; an empty list represents unit.

§

OwnedFields(Vec<Output<P>>)

Move named fields into their output conversions.

§

Projected(Projection)

Convert a leaf with an explicit ownership policy.

§

Into

Call a consuming accessor, then convert its result.

Fields

§function: String

Source accessor taking exactly the owned occurrence type.

§output: Box<Output<P>>

Conversion of its result, retaining any shared-reference ownership.

§

Getter

A shared-borrow accessor, followed by the output conversion of its result.

Fields

§function: String

Source getter taking exactly one shared reference to the current type.

§output: Box<Output<P>>

Conversion of the getter’s result. Shared results retain their borrow while being observed or cloned; they cannot satisfy an owned projection. Rust checks Clone when a borrowed opaque leaf becomes an owning handle.

§

Combine(Vec<Output<P>>)

Produce several views of one value. At most one child may consume it. Observations run before consumption, while wire order follows this list.

pub fn getter(name: impl Into<String>, output: Output<P>) -> Output<P>

Observe a value through a source getter and convert the getter’s result.

The getter takes &T for the current type T; adapters retaining a final output owner may also support &mut T. Its result uses the selected output conversion, including supported reference results.

§Arguments
  • name — unqualified name of the source getter.
  • output — recipe for the getter’s result.
Source

pub fn combine(parts: impl IntoIterator<Item = Output<P>>) -> Output<P>

Produce multiple outputs from one value.

parts holds one recipe per view of the value; their wires appear in this order. Binding rejects an empty list or more than one consuming part. The framework uses Codec::consumes to order observations before a move, unless Codec::output_owner first retains the final output allocation.
