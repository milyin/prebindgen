Fields§

§abi: String

The extern string: "C", "system".

§symbol: String

The symbol the wrapper is exported under.

§context: Vec<ContextParam>

Wrapper parameters no source parameter feeds, before those that do: the JNI environment, the receiver.

§inputs: Vec<Ident>

The names of the wrapper parameters that carry the inputs, in source order — the source’s own names for a function, one name for a release.

§routes: Vec<FailureRoute<<T as Target>::Op>>

One route per failure category the conversions can raise. A category with no route makes the export unsupported.

§attrs: Vec<Attribute>

Attributes beyond #[no_mangle], which the writer owns.

§unsafety: bool

Whether the wrapper is an unsafe fn.

§params: Accepts<<T as Target>::WireClass>

The wire types a wrapper parameter may be.

§ret: Accepts<<T as Target>::WireClass>

The wire types the wrapper may return.
