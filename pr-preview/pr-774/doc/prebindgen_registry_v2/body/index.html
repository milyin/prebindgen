The instructions the registry composes and the common Rust writer renders.

The chapters leave this vocabulary named but undefined (ConversionBodyId, FunctionBodyId); this is the concrete form the first increment settles on. Three instructions cover the scalar and owned-struct paths: apply a target operation, construct a source struct, call the source function. Every value is a ValueId — an identity, not a name. Names are allocated once, by the writer, from definition order, which is why two operations rendered into one wrapper cannot collide.
