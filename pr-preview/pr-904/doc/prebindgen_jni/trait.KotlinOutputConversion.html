Emit destination-side output conversion and rollback for this slot.

Provided Methods§

Source

fn delivery_policy(&self) -> DeliveryPolicy

Allow the adapter to select direct/capture delivery, or preserve an explicitly fixed packet protocol. Custom converters default to fixed.

Source

fn prepare_return_delivery( &self, _context: &JniContext, ) -> Result<Option<Delivery>>

Prepare the selected function-return delivery once, before requesting Rust output fragments. None preserves this converter’s fixed protocol.

Source

fn callback_arguments( &self, _context: &JniContext, _source: &Ident, ) -> Result<Vec<(Ident, TokenStream)>>

Rust wire expressions available inside this converter’s Prepare scope when a retained source callback delivers its arguments.

Source

fn kotlin_sequence_element( &self, context: &KotlinContext<'_>, owners: Option<&str>, ) -> Result<KotlinOutput>

Reconstruct one element delivered through a function’s sequence callback. owners is an existing nested-owner journal, when the shared boundary needs one. Reuse it so partial-row and unread-row cleanup stay coordinated.

Source

fn kotlin_return( &self, context: &KotlinReturnContext<'_>, ) -> Result<KotlinOutput>

Reconstruct an ordinary function result in its selected native transport. Callback-sequence return captures supply their prepared row projection.
