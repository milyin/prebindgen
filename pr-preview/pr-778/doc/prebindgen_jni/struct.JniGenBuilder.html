pub fn package(self, p: PackageDecl) -> Self

Bind classes, functions and constants under one Kotlin package.

Build the PackageDecl with package! and add classes (ptr_class!, data_class!, enum_class!, sealed_class!), functions (fun!) and constants (constant!). A source-defined type a bound function uses must be declared as a class or a conversion; primitives, strings, Option, Vec, arrays, borrows and callbacks need no declaration (see How values cross). examples/covertest-kotlin/build.rs declares every kind.

Source

pub fn convert(self, c: ConvertDecl) -> Self

Let a type cross as another type, through declared functions or From/TryFrom impls: convert!(Millis).input(fun!(from_raw)).output(fun!(to_raw)). Kotlin sees the representation type; see ConvertDecl.

Source

pub fn expand(self, e: impl Into<ExpandDecl>) -> Self

Set a type’s default boundary shape:

  • ExpandReturnDecl (expand_return!) — a result of the type is delivered as its fields to a caller-supplied builder (a folder for a Vec, the handler for an Err, the arguments of a callback);
  • ExpandParamDecl (expand_param!) — a parameter of the type is built by a constructor or passed as a handle, chosen by a selector.

A function overrides either for itself with FunctionDecl::expand_return / FunctionDecl::expand_param.
