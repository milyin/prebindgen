Expand description

The outer layer of a model type, with any declaration the adapter made for it.

Returned by shape(). Child types borrow the input model; they have not been classified recursively. The adapter matches this enum to choose a representation and calls shape() on whichever children it needs. D is the adapter’s declaration type, often borrowed from its registry.
