4//! # prebindgen-tools
5//!
6//! Building blocks for a prebindgen **language adapter**. Applications that
7//! only want bindings normally use the `prebindgen-c` or `prebindgen-jni`
8//! adapter crate instead.
9//!
10//! An adapter reads what `#[prebindgen]` captured as [`Flat`](prebindgen_flat::Flat), the
11//! source model from `prebindgen-flat` (re-exported here as `flat`). It turns
12//! its build script's declarations into a plan of the elements to bind, then writes each
13//! element: the Rust wrapper through a generator here, and whatever the
14//! destination language needs beside it (Kotlin text, for the JNI adapter)
15//! itself. The generators hold no shared plan: each writes one element from
16//! what it is given. [`RustFile`] only collects the resulting Rust items.
17//! The adapter decides which source items to bind, their names, wire types,
18//! and error policy.
19//!
20//! ## Follow one element
21//!
22//! 1. Read the captured model as [`Flat`](prebindgen_flat::Flat). Reject unsupported source
23//!    items with [`check_supported`]. Use [`Qualifier`] when generated Rust
24//!    refers back to a source item.
25//! 2. For each declared item, choose a generator below. Its callback trait
26//!    asks the adapter how values cross the boundary. [`shape()`] and
27//!    [`Shape`] help a callback walk a type one layer at a time.
28//! 3. Describe incoming values with [`Input`] and outgoing values with
29//!    [`Output`]. Each contains its [`Wire`] slots and conversion expression.
30//!    [`Stage`] can wrap either direction in a declared conversion.
31//! 4. Push the generated Rust items into [`RustFile`], then
32//!    [`RustFile::write`] them. The adapter writes any destination-language
33//!    files itself.
34//!
35//! ## Generators
36//!
37//! One generator per kind of Rust item. Each takes the flat element it
38//! wraps and header customizations through a builder, and asks for the
39//! boundary of each value through a small callback trait:
40//!
41//! | Generator | Writes | Callbacks |
42//! |---|---|---|
43//! | [`FunctionWriter`] | an exported wrapper around a [`Function`](prebindgen_flat::flat::Function) | [`FunctionCallbacks`]: the result's return type, out-wires and body; each parameter's wires and wire→value [`Input`]; the failure fragment |
44//! | [`StructWriter`] | a mirror struct of a [`Struct`](prebindgen_flat::flat::Struct), with both conversions | [`FieldCallbacks`]: each field's wires, both directions |
45//! | [`SumWriter`] | a mirror enum of a [`Variant`](prebindgen_flat::flat::Variant), with both conversions | [`FieldCallbacks`] |
46//! | [`ClosureWriter`] | an `impl Fn(..)` closure over a foreign callback | [`ClosureCallbacks`]: each argument's wires ([`Output`]) |
47//!
48//! The generators expect **final** wire types: how a `Vec<Payload>` becomes
49//! a pointer and a length, or a count and a column per field, is the
50//! adapter's answer in its callback. Start at a generator's module page for
51//! the shape it writes and a worked example: [`function`], [`record`],
52//! [`closure`].
53//!
54//! ## Recursion
55//!
56//! A callback answers for a whole type by recursing over its structure.
57//! [`shape()`] reads one layer — an `Option`, a borrow, a sequence, a named
58//! type with the adapter's own setting for it — so every adapter's recursion
59//! is one `match` over [`Shape`]. The answers compose: [`Input`] and
60//! [`Output`] carry an expression plus the wires it reads or produces;
61//! [`record_in`] / [`record_out`] take a struct or a sum alternative apart
62//! into its fields; [`Input::optional`], [`Input::combine`] and
63//! [`Output::concat`] build the rest; [`Stage::decode`] / [`Stage::encode`]
64//! wrap a representation in a declared conversion. A conversion that can
65//! fail uses `?` on `Result<_, String>`, and whoever places it decides where
66//! the error goes.
67//!
68//! ## Everything else
69//!
70//! * [`Qualifier`] — names a flat item from generated code
71//!   (`Payload` → `perftest_flat::Payload`).
72//! * [`names`] — case conversion and identifier helpers.
73//! * [`mod@convert`] — the `convert!` vocabulary: a source type that crosses as
74//!   another type through functions or `From`/`TryFrom` impls.
75//! * [`RustFile`] — the generated file: items in order, formatted, written
76//!   only when changed.
77//!
78//! ## Small complete example
79//!
80//! This toy adapter keeps scalar parameters unchanged. Real C and JNI
81//! adapters provide different [`FunctionCallbacks`] and handle more
82//! [`Shape`] variants. The example uses an in-memory model so the path from
83//! a flat function to generated Rust is visible without a build script.
84//!
85//! ```
86//! use prebindgen::SourceLocation;
87//! use prebindgen_tools::{flat::Flat, FunctionCallbacks, FunctionWriter,
88//!     Input, Qualifier, Return, RustFile, Wire, check_supported};
89//! use prebindgen_tools::flat::flat::TypeRef;
90//! use proc_macro2::TokenStream;
91//! use quote::quote;
92//!
93//! let source = syn::parse_file("pub fn double(n: i64) -> i64 { n * 2 }").unwrap();
94//! let location = SourceLocation {
95//!     crate_name: Some("source_crate".into()),
96//!     ..Default::default()
97//! };
98//! let flat = Flat::builder()
99//!     .items(source.items.into_iter().map(|item| (item, location.clone())))
100//!     .build().unwrap();
101//! check_supported(&flat).unwrap();
102//!
103//! struct Scalar;
104//! impl FunctionCallbacks for Scalar {
105//!     type Error = String;
106//!     fn param(&mut self, name: &syn::Ident, ty: &TypeRef) -> Result<Input, String> {
107//!         Ok(Input::identity(Wire::new(name.clone(), ty.spell())))
108//!     }
109//!     fn ret(&mut self, ret: &TypeRef) -> Result<Return, String> {
110//!         Ok(Return { ty: Some(ret.spell()), wires: vec![], body: quote!(__result) })
111//!     }
112//!     fn fail(&mut self, _: &Return) -> TokenStream {
113//!         quote!(panic!("{__err}"))
114//!     }
115//! }
116//!
117//! let function = flat.function("double").unwrap();
118//! let qualifier = Qualifier::new(&flat);
119//! let wrapper = FunctionWriter::new(function, qualifier.path(&function.name))
120//!     .abi(None).unsafety(false)
121//!     .write(&mut Scalar).unwrap();
122//! let mut file = RustFile::new();
123//! file.push(wrapper);
124//! let generated = file.render();
125//! assert!(generated.contains("fn double(n: i64) -> i64"));
126//! assert!(generated.contains("source_crate::double(n)"));
127//! ```

140/// The closure writer: a Rust `impl Fn(..)` built over a foreign callback.
141///
142/// A source function taking `impl Fn(A, B) + Send + Sync + 'static` needs a
143/// Rust closure that, on every call, turns `A` and `B` into wires and hands
144/// them to the foreign side. The shape is fixed; the adapter supplies the
145/// pieces:
146///
147/// ```text
148/// {
149///     <setup>                                  // once, when the closure is built
150///     move |__a0: A, __a1: B| {
151///         let __res = (|| -> Result<(), String> {
152///             <invoke>                         // binds each argument's wires, calls the foreign side
153///             Ok(())
154///         })();
155///         if let Err(__err) = __res { <on_error> }
156///     }
157/// }
158/// ```
159///
160/// `invoke` receives the arguments' bindings rather than having them placed
161/// ahead of it, so an adapter can run them inside a scope of its own — a
162/// JNI frame whose environment the conversions use.
163///
164/// For instance, a callback taking `i64` can use
165/// [`Output::single`](crate::Output::single) to pass one integer wire. The
166/// adapter's `invoke` closure then emits the foreign call using that wire;
167/// the writer supplies the Rust `move` closure, per-call error scope, and
168/// [`ClosureWriter::on_error`] path.
169///
170/// ```
171/// use prebindgen::SourceLocation;
172/// use prebindgen_tools::{flat::{Flat, flat::{TypeKind, TypeRef}},
173///     ClosureCallbacks, ClosureWriter, Output, Qualifier, Wire};
174/// use proc_macro2::TokenStream;
175/// use quote::{format_ident, quote};
176///
177/// let source = syn::parse_file(
178///     "pub fn register(callback: impl Fn(i64) + Send + Sync + 'static) {}"
179/// ).unwrap();
180/// let flat = Flat::builder()
181///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
182///     .build().unwrap();
183/// let ty = &flat.function("register").unwrap().params[0].ty;
184/// let TypeKind::Callback { args } = ty.kind() else { panic!("expected callback") };
185///
186/// struct Scalar;
187/// impl ClosureCallbacks for Scalar {
188///     type Error = String;
189///     fn arg(&mut self, index: usize, _: &TypeRef, value: &TokenStream)
190///         -> Result<Output, String> {
191///         Ok(Output::single(Wire::new(format_ident!("w{index}"), quote!(i64)), value))
192///     }
193/// }
194/// let closure = ClosureWriter::new(args)
195///     .on_error(quote!(panic!("{__err}")))
196///     .write(&Qualifier::new(&flat), &mut Scalar, |bindings, outputs| {
197///         let wire = &outputs[0].wires[0].name;
198///         quote!(#bindings foreign_callback(#wire);)
199///     }).unwrap();
200/// assert!(closure.to_string().contains("foreign_callback (w0)"));
201/// ```
202pub mod closure {
203    pub use crate::api::closure::{ClosureCallbacks, ClosureWriter};
204}

206/// Custom conversions: a source type that crosses as another type.
207///
208/// `convert!(Millis).input(fun!(millis_from_raw)).output(fun!(millis_to_raw))`
209/// says that `Millis` never crosses as itself: it crosses as `u64` — the
210/// **representation** — and these two functions convert. The adapter lowers
211/// the representation like any other type and wraps the resulting wires in
212/// the conversion's stages ([`Stage::apply`]).
213///
214/// A stage is a function (a flat item, or a binding-local path with a
215/// stated signature) or a standard trait impl (`From`, `Into`, `TryFrom`,
216/// `TryInto`). A function returning `Result` makes its stage fallible; the
217/// error is reported through its `Display`.
218///
219/// For example, given source functions `millis_from_raw(u64) -> Millis` and
220/// `millis_to_raw(&Millis) -> Result<u64, String>`, an adapter can resolve
221/// both directions before lowering a use of `Millis`:
222///
223/// ```
224/// use prebindgen::SourceLocation;
225/// use prebindgen_tools::{convert, fun, flat::Flat, Input, Output,
226///     Qualifier, Wire, ident};
227/// use quote::quote;
228/// let source = syn::parse_file(r#"
229///     pub struct Millis(pub u64);
230///     pub fn millis_from_raw(raw: u64) -> Millis { Millis(raw) }
231///     pub fn millis_to_raw(value: &Millis) -> Result<u64, String> { Ok(value.0) }
232/// "#).unwrap();
233/// let flat = Flat::builder()
234///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
235///     .build().unwrap();
236/// let conversion = convert!(Millis)
237///     .input(fun!(millis_from_raw))
238///     .output(fun!(millis_to_raw))
239///     .resolve(&flat).unwrap();
240/// let input = conversion.input.as_ref().unwrap();
241/// let output = conversion.output.as_ref().unwrap();
242/// // Each stage's `repr` is u64; `output.fallible` is true.
243/// assert_eq!(input.repr.spell().to_string(), "u64");
244/// assert!(output.fallible);
245/// let q = Qualifier::new(&flat);
246/// let decoded = input.decode(&q, &conversion.target,
247///     Input::identity(Wire::new(ident!(raw), quote!(u64))),
248///     &ident!(r), quote!());
249/// assert_eq!(decoded.wires.len(), 1);
250/// let encoded = output.encode(&q, &conversion.target, &quote!(value),
251///     &ident!(r), quote!(),
252///     Output::single(Wire::new(ident!(raw), quote!(u64)), quote!(r)));
253/// assert!(encoded.fallible);
254/// ```
255///
256/// An [`Input`] for `u64` is wrapped with [`Stage::decode`]
257/// before the source call; an [`Output`] for `u64` is wrapped
258/// with [`Stage::encode`] after it. A binding-local function can be named
259/// with [`fun!`](crate::fun!) plus [`FnRef::sig`]. See [`Via`] for trait-based alternatives.
260pub mod convert {
261    pub use crate::api::convert::{Conversion, FnRef, ResolvedConversion, Stage, Via};
262}

285/// The function wrapper writer.
286///
287/// A wrapper is one exported function that receives wires, converts them to
288/// the source function's arguments, calls it, and hands the result back as
289/// wires:
290///
291/// ```text
292/// <attrs>
293/// pub unsafe extern "C" fn <name><generics>(<leading>, <param wires>, <return wires>, <trailing>) -> <return type> {
294///     <prologue>
295///     let <param> = <param input>;          // on failure: <fail>
296///     ...
297///     let __result = <callee>(<params>);
298///     <return body>
299/// }
300/// ```
301///
302/// The writer owns the shape; the adapter owns every decision, through
303/// [`FunctionCallbacks`]: which wires a parameter becomes and how they turn
304/// back into the argument, which wires the result leaves on, and what the
305/// wrapper does when a conversion fails. The builder methods customize the
306/// header and the fixed parts of the body.
307///
308/// The [crate example](crate#small-complete-example) builds one wrapper from
309/// an in-memory [`Flat`](prebindgen_flat::Flat). In an adapter, the
310/// callback's [`FunctionCallbacks::param`] can call
311/// [`shape()`](crate::shape()), convert its result into an [`Input`], and let
312/// [`FunctionWriter::write`] place the wires and conversion at the call site.
313pub mod function {
314    pub use crate::api::function::{
315        error_ident, result_ident, FunctionCallbacks, FunctionWriter, Return, ERROR, RESULT,
316    };
317}

351/// Records — structs and the alternatives of a sum — taken apart into their
352/// fields and put back together.
353///
354/// Two uses, one mechanism:
355///
356/// * **Decomposition** ([`record_in`], [`record_out`]): the record crosses as
357///   the concatenation of its fields' wires, with no type of its own on the
358///   boundary. Recursing into a field that is itself a record gives the
359///   leaf-by-leaf crossing a JVM binding uses.
360/// * **Mirrors** ([`StructWriter`], [`SumWriter`]): the record crosses as a
361///   generated type whose fields are the wires — a `#[repr(C)]` struct or
362///   enum for C — plus the two conversions between it and the source type.
363///
364/// Either way the adapter decides, per field, through [`FieldCallbacks`];
365/// the helpers here only handle the Rust shape of the record: named or
366/// positional fields, the delimiters the source wrote, the order.
367///
368/// ## Example: decompose a record
369///
370/// [`record_in`] combines field inputs in source order and reconstructs the
371/// source's named or tuple form. A callback would normally produce the field
372/// inputs while recursing through [`shape()`](crate::shape()).
373///
374/// ```
375/// use prebindgen::SourceLocation;
376/// use prebindgen_tools::{flat::Flat, flat::flat::{Field, Type},
377///     FieldCallbacks, Input, Output, Record, StructWriter, Wire, ident, record_in};
378/// use proc_macro2::TokenStream;
379/// use quote::quote;
380///
381/// let item = syn::parse_quote!(pub struct Point { pub x: i32, pub y: i32 });
382/// let flat = Flat::builder()
383///     .items([(item, SourceLocation::default())])
384///     .build().unwrap();
385/// let Some(Type::Struct(point)) = flat.declared_type("Point") else { panic!() };
386/// let fields = vec![
387///     Input::identity(Wire::new(ident!(x_wire), quote!(i32))),
388///     Input::identity(Wire::new(ident!(y_wire), quote!(i32))),
389/// ];
390/// let input = record_in(Record::Struct(point), &quote!(Point), fields);
391/// assert_eq!(input.wires.len(), 2);
392/// assert_eq!(input.expr.to_string(), "Point { x : x_wire , y : y_wire }");
393///
394/// // A mirror uses the same field decisions to define a boundary struct
395/// // and the two conversions. Each conversion expression reads a local `v`.
396/// struct Scalar;
397/// impl FieldCallbacks for Scalar {
398///     type Error = String;
399///     fn field_in(&mut self, field: &Field) -> Result<Input, String> {
400///         Ok(Input::identity(Wire::new(field.name.clone().unwrap(), quote!(i32))))
401///     }
402///     fn field_out(&mut self, field: &Field, value: &TokenStream)
403///         -> Result<Output, String> {
404///         Ok(Output::single(
405///             Wire::new(field.name.clone().unwrap(), quote!(i32)), value
406///         ))
407///     }
408/// }
409/// let mirror = StructWriter::new(point, quote!(Point), ident!(PointWire))
410///     .attr(quote!(#[repr(C)]))
411///     .write(&mut Scalar).unwrap();
412/// assert_eq!(mirror.wires.len(), 2);
413/// assert!(mirror.def.to_string().contains("struct PointWire"));
414/// assert!(mirror.input.expr.to_string().contains("let PointWire"));
415/// ```
416pub mod record {
417    pub use crate::api::record::{
418        record_in, record_out, FieldCallbacks, Record, StructMirror, StructWriter, SumMirror,
419        SumWriter,
420    };
421}

423/// One level of a type's structure, read against the adapter's own settings.
424///
425/// An adapter lowers a type by recursion: it looks at the outermost layer,
426/// decides what that layer becomes on its boundary, and recurses into what
427/// the layer holds. [`shape()`] answers the first question the same way for
428/// every adapter — which layer this is, and, for a named type, the setting
429/// the adapter gave that type — so each adapter's recursion is one `match`
430/// over [`Shape`].
431///
432/// For example, if the adapter has declared a binding for `Payload`, then
433/// `shape(&payload_type, |name| settings.get(name))` returns
434/// [`Shape::Declared`] with that setting. For `Option<Payload>`, it returns
435/// [`Shape::Option`] with the inner type; the adapter calls [`shape()`] again
436/// for that inner type. This keeps the adapter's policy in one recursive
437/// match rather than in the flat model.
438///
439/// ```
440/// use prebindgen::SourceLocation;
441/// use prebindgen_tools::{flat::Flat, shape, Access, Shape};
442/// let source = syn::parse_file("pub struct Payload; pub fn send(value: Option<&Payload>) {}").unwrap();
443/// let flat = Flat::builder()
444///     .items(source.items.into_iter().map(|item| (item, SourceLocation::default())))
445///     .build().unwrap();
446/// let ty = &flat.function("send").unwrap().params[0].ty;
447/// let Shape::Option(inner) = shape(ty, |name| (name == "Payload").then_some("handle"))
448///     .unwrap() else { panic!("expected Option") };
449/// assert!(matches!(
450///     shape(inner, |name| (name == "Payload").then_some("handle")).unwrap(),
451///     Shape::Declared { setting: "handle", access: Access::Shared, .. }
452/// ));
453/// ```
454pub mod shape {
455    pub use crate::api::shape::{shape, Access, Holding, Shape};
456}

458/// Wires and the conversions between wires and source values.
459///
460/// A **wire** is one parameter, field or return slot of the generated
461/// boundary, typed in the generated Rust file: `jlong`, `*const c_char`,
462/// `payload_t`. A source value crosses as zero or more wires, and which
463/// ones is the adapter's decision; these types only carry the decision and
464/// compose it.
465///
466/// * [`Input`] turns wires into a source value — a parameter on its way into
467///   the source function, a field of a struct arriving from the foreign side.
468/// * [`Output`] turns a source value into wires — a return value, a callback
469///   argument, a field of a struct leaving.
470///
471/// Both carry an expression. A **fallible** one may use `?` on a
472/// `Result<_, String>`; whoever places it decides where the error goes (see
473/// [`Input::result`]). Generated conversion helpers follow the same
474/// convention, so a converter written for one position composes into another.
475///
476/// ## Example: one value on two wires
477///
478/// A `u64` can arrive as two `u32` words. [`Input`] keeps the expression together with
479/// the two [`Wire`] declarations so [`FunctionWriter`]
480/// can place and evaluate them in the right order:
481///
482/// ```
483/// use prebindgen_tools::{Input, Output, Wire, ident};
484/// use quote::quote;
485///
486/// let hi = Wire::new(ident!(hi), quote!(u32));
487/// let lo = Wire::new(ident!(lo), quote!(u32));
488/// let input = Input::new(vec![hi, lo], quote!(((hi as u64) << 32) | lo as u64));
489/// assert_eq!(input.wires.len(), 2);
490/// assert!(input.result().to_string().contains("Ok"));
491///
492/// let output = Output::new(
493///     vec![Wire::new(ident!(hi), quote!(u32)),
494///          Wire::new(ident!(lo), quote!(u32))],
495///     quote!(((value >> 32) as u32, value as u32)),
496/// );
497/// assert_eq!(output.pattern().to_string(), "(hi , lo)");
498/// ```
499///
500/// For a fallible step, use [`Input::and_then`] or [`Output::fallible`]
501/// and place [`Input::result`] or [`Output::result`] at the point whose
502/// error policy applies. The writer only understands `Result<_, String>`;
503/// the adapter supplies the actual fallback in
504/// [`FunctionCallbacks::fail`].
505pub mod wire {
506    pub use crate::api::wire::{result_expr, Input, Output, Wire};
507}

546/// `into!(Repr)` — the output stage is `Into<Repr>` on the source type.
