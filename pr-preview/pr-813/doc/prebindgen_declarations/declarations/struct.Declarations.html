pub struct Declarations { /* private fields */ }
Expand description

Resolved type defaults used to build boundary converters.

Per-function overrides replace type defaults. Existing converters are preserved unless explicitly overridden. By default unit has no wires and every other type is a leaf, converted by the adapter’s Codec. Recursive expansion cycles are rejected. Recipes are local to Self::fill; only compiled conversion data is attached to Flat. See Codec for a buildable example of constructor alternatives, combined outputs and manual overrides.

pub fn fill<C: Codec>( &self, flat: &mut Flat<C::Input, C::Output>, codec: &C, decl: &FunctionDecl, extra: &C::Extra, ) -> Result<()>

Build one function’s input and output converters from its declarations.

Existing converters are retained unless explicitly overridden. extra is used for every converter built by this call; retained converters are untouched. For different data at individual occurrences, use crate::bind_input and crate::bind_output before filling defaults, or after applying overrides. No construction data is retained for later overrides.

Resolves and compiles all required conversions before modifying any slot. An unknown parameter, recursive expansion, incompatible type or invalid constructor/getter leaves the entire function unchanged.

§Arguments
  • flat — the model holding the function; its slots receive the converters.
  • codec — the adapter’s leaf conversions.
  • decl — the function to export, with its per-parameter and result overrides.
  • extra — occurrence data passed to every codec call made by this fill.
