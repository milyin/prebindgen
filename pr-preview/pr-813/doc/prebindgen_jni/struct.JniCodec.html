Struct JniCodec 

Source 
pub struct JniCodec;
Expand description

Conversions and slot glue used by JniGen. Prepared code explicitly references the emission context’s JNI environment and ownership acknowledgement parameter. Output delivery owns its result local. The writer supplies the error boundary and matching Kotlin protocol. Use with prebindgen_declarations::bind_input and prebindgen_declarations::bind_output to fill Bindings manually.
