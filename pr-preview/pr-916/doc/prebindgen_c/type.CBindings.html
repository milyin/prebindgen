§types: BTreeMap<String, TypeInfo<CType>>

Canonical source types and their metadata. Declared names (including opaque aliases) are keys; built-ins and composites registered through Flat::type_metadata_mut use their qualified type syntax as keys.

§guards: Vec<ItemConst>

Constants every adapter must emit: captured feature guards and generated nonzero-size assertions. Layout assertions run when the bindings compile.
