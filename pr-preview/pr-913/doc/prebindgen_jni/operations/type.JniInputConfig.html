fn selector(arms: impl IntoIterator<Item = Self>) -> Self

Choose between owned representations of the same input type.

arms holds one recipe per alternative; each must produce the input’s type. The caller passes the zero-based index of the chosen alternative in an extra wire ahead of all arms’ wires.

Requires at least one arm. Each arm retains its own wires; this does not merge equivalent wire parameters or generate destination-language overloads.
