Expand description

Build and attach a converter to a named function parameter.

Resolves the occurrence’s source type from flat, checks recipe compatibility, and recursively composes wires and code. Nested conversions use the supplied extra, not data from referenced constructors or getters. Recipes and extra are borrowed only for this call. A failure leaves the existing slot unchanged. Rebinding an occurrence replaces its converter without changing other slots. Generated names are scoped by parameter position, so separate calls cannot collide within the wrapper. Keep the function signature fixed after binding. Check completeness with validate_bindings.

Input binding rejects output recipes:

ⓘ
use prebindgen_tools::{bind_input, Bindings, Codec, Output};
fn wrong<C: Codec>(flat: &mut Bindings<C::Wire>, codec: &C, extra: &C::Extra) {
    bind_input(flat, codec, "foo", "x", &Output::Scalar, extra).unwrap();
