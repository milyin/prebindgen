Validate array pointer encoding and addressable byte length without reading memory. Empty arrays accept null. Nonempty arrays require nonzero-sized elements, nonnull aligned storage and a byte range fitting isize and the address space. The caller must still guarantee the entire range is readable and has valid provenance.
