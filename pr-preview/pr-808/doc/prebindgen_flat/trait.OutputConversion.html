Expand description

A fully prepared output conversion stored in a slot. Metadata and generated names must stay consistent across method calls. Code runs in the environment supplied by the language wrapper writer. Preparation resolves errors before installing the slot; emit_call reads this interface directly, without an intermediate plan. Source-value templates use source_result_expr; custom implementations can use the supplied context directly.
