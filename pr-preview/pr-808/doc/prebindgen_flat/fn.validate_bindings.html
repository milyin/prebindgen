Expand description

Check that every bound function has an input converter for each parameter and an output converter, including unit results.

Functions with entirely empty slots remain source-only helpers. This check neither builds conversions nor changes the model. Adapters call it before writing wrappers. It does not validate code fragments supplied directly by callers.
