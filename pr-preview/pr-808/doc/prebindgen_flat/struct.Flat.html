Struct Flat

    pub functions: BTreeMap<String, Function<I, O>>,
    pub records: BTreeMap<String, Record>,
    pub types: BTreeMap<String, Type>,
    pub guards: Vec<ItemConst>,
    pub representations: Representations<R>,
}
Expand description

Source structure with independently configured input and output conversions.

Every parameter carries Option<I>; every result carries Option<O>. Record fields describe source structure; Self::representations describes destination shapes and explicit component mappings. Conversion implementations remain opaque to wrapper writers. Type-level bounds intentionally prevent non-conversion slot payloads. For source-only inspection, let flat: Flat = Flat::parse(items)? uses default plan types with all slots empty.

Use Flat::parse or Flat::parse_selected to validate source syntax and qualify declared names. Aliases stay opaque. Named types must have nonzero Rust size; generated code must emit Self::guards to enforce that rule.

use prebindgen_flat::{Flat, InputPlan, OutputPlan};
let items = syn::parse_file("pub fn add(x: i64, y: i64) -> i64 { x + y }")?.items;
let flat = Flat::<InputPlan<()>, OutputPlan<()>>::parse(
    items.into_iter().map(|item| (item, Default::default())))?;
assert!(flat.function("add")?.params[0].ty.slot.is_none());

pub fn parse_selected( items: impl IntoIterator<Item = (Item, SourceLocation)>, functions: &[String], types: &[Type], ) -> Result<Self>

Select the source declarations needed by this binding before validating the supported flat subset. Items outside the selection are skipped without validation.

Dependency discovery follows unqualified declared type names in function signatures and record fields transitively. A type referenced only through a qualified path (such as crate::Foo) must also be selected explicitly through types using its unqualified name (Foo), or included by parsing the complete item set with Self::parse. Opaque alias implementations are not inspected. Unnamed constant guards are retained. Selected items are validated by Self::parse.

§Arguments
  • items — captured source items with their locations, as returned by prebindgen::Source::items_all.
  • functions — unqualified names of the functions to keep, including the constructors and getters that declarations refer to.
  • types — further types to keep, with the types they refer to.
Source

pub fn parse( items: impl IntoIterator<Item = (Item, SourceLocation)>, ) -> Result<Self>

Read captured items; only free functions, named records and opaque aliases belong to this subset. Rejects duplicate names, non-public declarations, unsupported signatures and types, and inaccessible record fields.

Input and output slots start at None; no default conversion is required. Unqualified declared types and callable paths are qualified with the captured crate name (or crate if absent). Opaque alias implementations are not inspected. Rust layout and trait requirements are checked later when the generated code compiles.

items are captured source items with their locations, as returned by prebindgen::Source::items_all.

pub fn resolve_type(&self, ty: &Type) -> Result<Type>

Qualify the declared names in ty and validate the supported source-type grammar.

Accepts primitives, declared types, unit, strings, byte vectors/slices and references without explicit lifetimes. A successful result does not mean a consumer can use the type in every position. Aliases remain opaque.

pub fn map_slots<I2: InputConversion, O2: OutputConversion>( self, input: impl FnMut(&Type, Option<I>) -> Result<Option<I2>>, output: impl FnMut(&Type, Option<O>) -> Result<Option<O2>>, ) -> Result<Flat<I2, O2, R>>

Transform input and output data separately, preserving source structure and guards.

Functions are visited by name; within each function, parameters are visited in declaration order, followed by its result. Record declarations pass through unchanged. Stops on the first error.

§Arguments
  • input — called for each parameter with its source type and old input slot; returns the new slot.
  • output — called for each result with its source type and old output slot; returns the new slot.
