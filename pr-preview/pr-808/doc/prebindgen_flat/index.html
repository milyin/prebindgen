Source
Expand description

Source types, self-contained conversion slots, and wrapper code assembly. Parameters and results hold optional conversions constrained by direction-specific traits. Preparation fills slots; generation uses emit_call. Named objects must have nonzero Rust size, including opaque aliases. Their layout is checked by the emitted compile-time guards, independently of the slot data types. Unit remains available for absence of a value.

Functions§

emit_call
Assemble a function call directly from filled slots, without a generator callback. Validates slot completeness, output arity and agreement on shared acknowledgement. The returned code runs inside the wrapper’s fallible boundary, in this order: all validation, alias checks, one acknowledgement, all acquisition, argument construction, source invocation, output preparation, delivery and commit. Input and output contexts must match, even when the function has no parameters.
