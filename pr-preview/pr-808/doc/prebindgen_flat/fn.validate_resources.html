pub fn validate_resources(resources: &[Resource]) -> TokenStream
Expand description

Emit pairwise alias checks across all active input resources.

resources holds the InputPlan::resources of all of one exported function’s parameters together, so that aliases across parameters are found.

Run this code after leaf validation and before any ownership acquisition. Shared/shared pairs and resources whose predicates are not both true do not conflict. Conflicts return Err("conflicting input aliases".into()) from the enclosing wrapper. This does not validate pointer liveness, synchronize threads, or acquire resources; those remain adapter/caller responsibilities.
