Expand description

A fully prepared input conversion stored in a slot. Metadata and generated names must stay consistent across method calls. Code runs in the environment supplied by the language wrapper writer. Preparation resolves errors before installing the slot; emit_call reads this interface directly, without an intermediate plan.

This conversion accepts one opaque pointer wire and constructs a Box<T> argument. Preparation supplies the concrete pointee type as a syn::Type; the converter does not hardcode any wrapped type. It demonstrates every method, including ownership transfer and alias checking.

Context describes the environment that the language generator prepares around the emitted conversion code. The generator defines this type and constructs a value during code generation, then passes it to emit_call or directly to the slot’s methods. Call assembly passes the same context to the input and output conversions. Flat imposes no fields or trait requirements on it.

In this example, the wrapper exposes an ownership-acknowledgement parameter. Context::acknowledged holds that parameter’s Rust identifier. The converter uses it to emit an assignment such as *ownership_taken = true;. The context exists while generating code; it contains the identifier, not the runtime boolean. The generator must declare that parameter in the generated wrapper with the type and meaning expected by the converter.

Preparation stores the conversion-specific information in OwnedBoxInput: the pointee type, wire description and private temporary name. Context supplies wrapper-environment bindings shared by conversions. For another generator, these might include a runtime environment identifier or a helper-function path. The converter already determines how conversion works; context supplies the environment in which its emitted code will run. Changing the acknowledgement parameter’s name therefore needs a different context value, not a rebuilt slot.

The final Rust argument binding is supplied separately as target to InputConversion::construction. Similarly, output methods receive the source-result binding explicitly. Neither binding needs to be stored in context. Converters that need no wrapper-specific environment can use () as their associated Context type.

The wrapper supplies an &mut bool acknowledgement parameter, initially false. Validation or alias-check failure leaves it false and ownership with the caller. After acknowledgement, the wrapper owns the allocation even if later code fails. The pointer must come from a compatible Box::into_raw for the prepared pointee type, remain live, and be used exclusively for this transfer. A null check cannot establish those conditions.

use prebindgen_flat::{Access, InputConversion, Resource, Result, Wire, WireKind};
use proc_macro2::TokenStream;
use quote::quote;
use syn::{parse_quote, Ident, Type};

// The generator defines boundary carriers independently of the wrapped types.
// Any opaque object handle can use this same pointer carrier.
enum WireType {
    OpaquePointer,
}
impl WireKind for WireType {
    fn rust_type(&self) -> Type {
        match self {
            Self::OpaquePointer => parse_quote!(*mut ::std::ffi::c_void),
        }
    }
}

// Generator-owned bindings available to emitted code. This is a code-generation
// value, not a runtime context passed to the wrapped Rust function.
struct Context {
    // Name of the wrapper's &mut bool parameter.
    acknowledged: Ident,
}

// A reusable converter prepared for any supported sized pointee type.
struct OwnedBoxInput {
    pointee: Type,
    wires: [Wire<WireType>; 1],
    // Preparation chooses a private temporary unique within the wrapper.
    owned: Ident,
}
impl InputConversion for OwnedBoxInput {
    type Wire = WireType;
    type Context = Context;

    fn wires(&self) -> &[Wire<WireType>] {
        &self.wires
    }

    fn resources(&self, _: &Context) -> Result<Vec<Resource>> {
        let wire = &self.wires[0].name;
        Ok(vec![Resource {
            identity: quote!(#wire as usize),
            access: Access::Move,
            active: quote!(true),
        }])
    }

    fn validation(&self, _: &Context) -> Result<TokenStream> {
        let wire = &self.wires[0].name;
        Ok(quote! {
            if #wire.is_null() {
                return Err("null owned handle".into());
            }
        })
    }

    fn acknowledgement(&self, context: &Context) -> Result<Option<TokenStream>> {
        let acknowledged = &context.acknowledged;
        // Shared across consuming slots; emit_call emits it once, after checks.
        Ok(Some(quote!(*#acknowledged = true;)))
    }

    fn acquisition(&self, _: &Context) -> Result<TokenStream> {
        let wire = &self.wires[0].name;
        let owned = &self.owned;
        let pointee = &self.pointee;
        // Safety relies on the caller's pointer and ownership contract above.
        Ok(quote! {
            let #owned = unsafe { ::std::boxed::Box::<#pointee>::from_raw(#wire.cast::<#pointee>()) };
        })
    }

    fn construction(&self, _: &Context, target: &Ident) -> Result<TokenStream> {
        let owned = &self.owned;
        Ok(quote!(let #target = #owned;))
    }
}

// Preparation obtains this type from the wrapped signature. Use u64 here
// to demonstrate the converter without introducing an application type.
let slot = OwnedBoxInput {
    pointee: parse_quote!(u64),
    wires: [Wire {
        name: parse_quote!(raw_value),
        kind: WireType::OpaquePointer,
    }],
    owned: parse_quote!(__owned_value),
};
let context = Context { acknowledged: parse_quote!(ownership_taken) };

// Individual phases are available directly. emit_call orders them across
// all input slots, checks resource aliases, and invokes the source function.
assert_eq!(slot.wires().len(), 1);
assert_eq!(slot.resources(&context)?[0].access, Access::Move);
let validation = slot.validation(&context)?;
let acknowledgement = slot.acknowledgement(&context)?;
let acquisition = slot.acquisition(&context)?;
let target = parse_quote!(argument);
let construction = slot.construction(&context, &target)?;
assert_eq!(construction.to_string(),
           quote!(let argument = __owned_value;).to_string());

// Inspect the emitted phases without compiling or executing a foreign pointer.
let phases = quote! {
    #validation
    #acknowledgement
    #acquisition
    #construction
};
let _: syn::Block = syn::parse2(quote!({ #phases }))?;

The converter owns any conditional behavior. Wires describe transport only.

type Context

Wrapper-environment data defined and supplied by the language generator. The value is used during code generation, for example to name runtime parameters or helper functions referenced by emitted code. Use () when no such data is needed. See the trait example for the distinction between context, prepared slot data and the caller-supplied argument binding.

fn construction( &self, context: &Self::Context, target: &Ident, ) -> Result<TokenStream>

Construct the argument after all inputs have been acquired, binding it to target. The caller owns this identifier and passes it to the source function. Emit a let binding in the surrounding scope, so borrowed argument storage remains alive. Converter-private temporaries must not shadow other caller-supplied bindings.

Provided Methods§

Source

fn acknowledgement( &self, _context: &Self::Context, ) -> Result<Option<TokenStream>>

Shared call acknowledgement, after validation and before acquisition. All contributing inputs must return the same token spelling; assembly emits it once. Return None when this input needs no acknowledgement. Slot-local fallible checks belong in validation, not in this shared operation.
