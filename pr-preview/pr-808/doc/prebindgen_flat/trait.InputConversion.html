Expand description

A fully prepared input conversion stored in a slot. Metadata and generated names must stay consistent across method calls. Code runs in the environment supplied by the language wrapper writer. Preparation resolves errors before installing the slot; emit_call reads this interface directly, without an intermediate plan.

This conversion accepts one opaque pointer wire and constructs a Box<Document> argument for a function such as publish(document: Box<Document>). It demonstrates every method, including ownership transfer and alias checking.

The wrapper supplies an &mut bool acknowledgement parameter, initially false. Validation or alias-check failure leaves it false and ownership with the caller. After acknowledgement, the wrapper owns the document even if later code fails. The pointer must come from a compatible Box<Document>::into_raw, remain live, and be used exclusively for this transfer. A null check cannot establish those conditions.

use prebindgen_flat::{Access, InputConversion, Resource, Result, Wire, WireKind};
use proc_macro2::TokenStream;
use quote::quote;
use syn::{parse_quote, Ident, Type};

// The generator defines a closed set of supported boundary carriers.
enum WireType {
    DocumentHandle,
}
impl WireKind for WireType {
    fn rust_type(&self) -> Type {
        match self {
            Self::DocumentHandle => parse_quote!(*mut ::std::ffi::c_void),
        }
    }
}

// Name of the wrapper's &mut bool parameter, supplied during generation.
struct Context {
    acknowledged: Ident,
}

struct DocumentInput {
    wires: [Wire<WireType>; 1],
    // Preparation chooses a private temporary unique within the wrapper.
    owned: Ident,
}
impl InputConversion for DocumentInput {
    type Wire = WireType;
    type Context = Context;

    fn wires(&self) -> &[Wire<WireType>] {
        &self.wires
    }

    fn resources(&self, _: &Context) -> Result<Vec<Resource>> {
        let wire = &self.wires[0].name;
        Ok(vec![Resource {
            identity: quote!(#wire as usize),
            access: Access::Move,
            active: quote!(true),
        }])
    }

    fn validation(&self, _: &Context) -> Result<TokenStream> {
        let wire = &self.wires[0].name;
        Ok(quote! {
            if #wire.is_null() {
                return Err("null document handle".into());
            }
        })
    }

    fn acknowledgement(&self, context: &Context) -> Result<Option<TokenStream>> {
        let acknowledged = &context.acknowledged;
        // Shared across consuming slots; emit_call emits it once, after checks.
        Ok(Some(quote!(*#acknowledged = true;)))
    }

    fn acquisition(&self, _: &Context) -> Result<TokenStream> {
        let wire = &self.wires[0].name;
        let owned = &self.owned;
        // Document is the source Rust type in the generated wrapper's scope.
        // Safety relies on the caller's pointer and ownership contract above.
        Ok(quote! {
            let #owned = unsafe { Box::<Document>::from_raw(#wire.cast::<Document>()) };
        })
    }

    fn construction(&self, _: &Context, target: &Ident) -> Result<TokenStream> {
        let owned = &self.owned;
        Ok(quote!(let #target = #owned;))
    }
}

let slot = DocumentInput {
    wires: [Wire {
        name: parse_quote!(raw_document),
        kind: WireType::DocumentHandle,
    }],
    owned: parse_quote!(__owned_document),
};
let context = Context { acknowledged: parse_quote!(ownership_taken) };

// Individual phases are available directly. emit_call orders them across
// all input slots, checks resource aliases, and invokes the source function.
assert_eq!(slot.wires().len(), 1);
assert_eq!(slot.resources(&context)?[0].access, Access::Move);
let validation = slot.validation(&context)?;
let acknowledgement = slot.acknowledgement(&context)?;
let acquisition = slot.acquisition(&context)?;
let target = parse_quote!(document);
let construction = slot.construction(&context, &target)?;
assert_eq!(construction.to_string(),
           quote!(let document = __owned_document;).to_string());

// Inspect the emitted phases without compiling or executing a foreign pointer.
let phases = quote! {
    #validation
    #acknowledgement
    #acquisition
    #construction
};
let _: syn::Block = syn::parse2(quote!({ #phases }))?;

The converter owns any conditional behavior. Wires describe transport only.

fn construction( &self, context: &Self::Context, target: &Ident, ) -> Result<TokenStream>

Construct the argument after all inputs have been acquired, binding it to target. The caller owns this identifier and passes it to the source function. Emit a let binding in the surrounding scope, so borrowed argument storage remains alive. Converter-private temporaries must not shadow other caller-supplied bindings.

Provided Methods§

Source

fn acknowledgement( &self, _context: &Self::Context, ) -> Result<Option<TokenStream>>

Shared call acknowledgement, after validation and before acquisition. All contributing inputs must return the same token spelling; assembly emits it once. Return None when this input needs no acknowledgement. Slot-local fallible checks belong in validation, not in this shared operation.
