Expand description

A fully prepared input conversion stored in a slot. Metadata and generated names must stay consistent across method calls. Code runs in the environment supplied by the language wrapper writer. Preparation resolves errors before installing the slot; prepare_call reads this interface directly, without an intermediate plan.
