Expand description

Assemble a function call directly from filled slots, without a generator callback. Validates slot completeness, output arity and agreement on shared acknowledgement. The returned code runs inside the wrapper’s fallible boundary, in this order: all validation, alias checks, one acknowledgement, all acquisition, argument construction, source invocation, output preparation, delivery and commit. Input and output contexts must match, even when the function has no parameters.

use prebindgen_flat::{emit_call, Function, InputConversion, OutputConversion, EmissionContext};
struct OtherContext(syn::Ident);
impl EmissionContext for OtherContext {
    fn source_result(&self) -> &syn::Ident { &self.0 }
}
fn incompatible<I, O>(function: &Function<I, O>, context: &syn::Ident)
where I: InputConversion<Context = syn::Ident>,
      O: OutputConversion<Context = OtherContext>,
{
    emit_call(function, context).unwrap();
}
