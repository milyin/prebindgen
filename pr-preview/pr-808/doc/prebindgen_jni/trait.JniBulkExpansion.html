Expand description

Select the JNI bulk carrier for an input or output expansion.

Required Methods§

Source

fn bulk(self) -> Self

Group the expansion in a bulk C-representation carrier. Constructor, getter, ownership and local conversion rules are retained. Ordinary output collections combine expansions into one frame. Callback delivery keeps packing inside each element: bulk Row gives one frame per row of Vec<Row>; bulk Vec<Row> gives one frame per inner collection of Vec<Vec<Row>>.
