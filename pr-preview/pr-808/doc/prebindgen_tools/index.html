Source
Expand description

Conversion composition. Adapters supply leaf codecs; wrappers consume conversion slots.

Declarations::fill, bind_input and bind_output build conversions directly in a Bindings model. Recipes and codec input data are used only during construction; slots retain wires and code needed by wrapper writers. Generation uses Flat::prepare_call and the call emitter in prebindgen-flat; tools owns only declaration resolution and slot preparation. Each Wire carries the adapter’s own description in Wire::kind. value provides conversions for values copied across the boundary and boxed for values kept in Rust-owned allocations.
