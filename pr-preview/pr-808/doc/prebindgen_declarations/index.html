Source
Expand description

Generic source-aware helpers and compilation of adapter-owned conversion trees.

Language adapters own their operations, requests and source-representation policies. Shared DeclFunction and DeclCallback containers hold the caller’s tree types. DeclDefaults stores typed defaults; source helpers resolve constructors, getters, fields, callbacks and local overrides without a shared operation vocabulary. resolve_bindings produces a complete Flat<ResolvedSchema<C>>. compile_resolved compiles that model using the adapter’s Codec. All generation settings and resolved conversions belong to Flat.
