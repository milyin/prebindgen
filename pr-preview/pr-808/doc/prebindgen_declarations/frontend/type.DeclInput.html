pub type DeclInput<InRequest = Infallible, OutRequest = Infallible> = InputNode<DeclInputOps, DeclOutputOps, InRequest, OutRequest>;
Expand description

Input syntax before adapter lowering.

Preparation uses DeclInput<DeclInputRequest, DeclOutputRequest>. Plain DeclInput uses Infallible for both directions, including reverse-direction arrow domains.

ⓘ
use prebindgen_declarations::{DeclInput, frontend::DeclInputBranch, DeclInputRequest};
let resolved: DeclInput = DeclInput::Branch {
    operation: DeclInputBranch::Constructor { function: "make".into() },
    children: vec![DeclInput::Request(DeclInputRequest::Auto)],
};

pub fn constructor( name: impl Into<String>, args: impl IntoIterator<Item = DeclInput<InRequest, OutRequest>>, ) -> Self

Call a named source constructor with the supplied argument recipes.

Binding checks its result type and argument count. Argument validation and ownership acquisition precede the source call.

§Arguments
  • name — unqualified name of a source function whose result type is the input’s type.
  • args — one recipe per parameter of that function, in order.
Source

pub fn selector( arms: impl IntoIterator<Item = DeclInput<InRequest, OutRequest>>, ) -> Self

Choose between owned representations of the same input type.

arms holds one recipe per alternative; each must produce the input’s type. The caller passes the zero-based index of the chosen alternative in an extra wire ahead of all arms’ wires.

Requires at least one arm. Each arm retains its own wires; this does not merge equivalent wire parameters or generate destination-language overloads.
