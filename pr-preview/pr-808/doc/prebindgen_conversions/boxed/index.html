Foreign conversion helpers for adapters using boxed allocations. Adapters select a Storage policy and map BoxedWire data into their own wire kind.

Structs§

BoxedWire
Source type and access mode for a wire carrying a boxed allocation address. This is generation metadata used by adapters to declare pointer/handle types; allocation and conversion construction remain preparation responsibilities.

Storage
Storage chosen by the adapter. A wrapper must expose a value field and allow construction as Wrapper { value }.
