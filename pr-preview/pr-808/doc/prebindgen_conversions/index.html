Reusable boundary conversions and their representation metadata.

These helpers build InputPlan and OutputPlan values. They do not interpret declarations or select functions to export. Adapters may use the helpers during preparation and their wire metadata during generation.

Generated code calls prebindgen-runtime at runtime; this crate itself is used only during binding generation.

Optional expression protocol for stored plans used by the C and JNI adapters. Scoped requests keep prepared temporaries alive while evaluating a continuation. Other generators can define entirely different request enums.
value
Leaf conversions for values the adapter copies across the boundary. Value::of classifies a source type; input and output build the conversion around the adapter’s own decode and encode expressions.
