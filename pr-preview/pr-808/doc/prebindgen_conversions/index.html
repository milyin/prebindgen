Reusable boundary conversions and their representation metadata.

These helpers build prebindgen_flat::InputPlan and prebindgen_flat::OutputPlan values. They do not interpret declarations or select functions to export. Adapters may use the helpers during preparation and their wire metadata during generation.

Generated code calls prebindgen-runtime at runtime; this crate itself is used only during binding generation.

Foreign conversion helpers for adapters using boxed allocations. Adapters select a Storage policy and map BoxedWire data into their own wire kind.

Leaf conversions for values the adapter copies across the boundary. Value::of classifies a source type; input and output build the conversion around the adapter’s own decode and encode expressions.
