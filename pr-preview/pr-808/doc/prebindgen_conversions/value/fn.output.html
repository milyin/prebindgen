    kind: W,
) -> Result<OutputPlan<W, C, G>>
Expand description

Deliver an owned value type. A borrowed value is copied first: scalars by dereference, text and bytes by Clone.

The adapter may adjust the result, for example to defer an allocation’s transfer to commit. The returned plan conservatively sets fallible = true for the adapter-supplied encoding; clear it when that encoding is infallible.

§Arguments

  • ty — the owned source type; it must satisfy Value::of.
  • wire — identifier of the delivered wire, also used for the local holding it.
  • value — Rust expression producing the value.
  • borrowed — true when value is a shared reference to ty, false when it is owned.
  • encode — maps a Rust expression of the owned value to the expression delivered on the wire.
  • kind — the adapter’s Wire::kind for the wire.
