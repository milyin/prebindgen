Resolved outgoing conversion. An optional configuration payload cannot leave a constructible None in the final leaf type:

ⓘ
use prebindgen_c::{COutput,COutputLeafOp};
let _:COutput=COutput::Leaf(COutputLeafOp::ConfigValue(None));
